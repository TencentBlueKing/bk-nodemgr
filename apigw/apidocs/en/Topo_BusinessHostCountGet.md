### Description

- API Version: v3.0.1-alpha.96+.
- Required Permission: `agent_view (View Agent)`, `proxy_view (View Proxy)`. The actual permission check is narrowed by `node_role`.
- Function: Count hosts for each specified business ID and node role.

### URL

POST /api/v3/topo/business/host_count/get

### Request Parameters

| Parameter | Type         | Required | Description                                                                                   |
| --------- | ------------ | -------- | --------------------------------------------------------------------------------------------- |
| bk_biz_id | int64 array  | Yes      | Business ID list. At least one business ID is required                                        |
| node_role | string array | No       | Node role list. Valid values: `blank`, `agent`, `proxy`. Omit this field to include all roles |

### Request Example

Query the Agent host count of business `2` and business `7`.

```json
{
  "bk_biz_id": [2, 7],
  "node_role": ["agent"]
}
```

### Response Example

```json
{
  "code": 0,
  "message": "ok",
  "request_id": "req-123456",
  "data": {
    "items": [
      {
        "bk_biz_id": 2,
        "host_count": 120
      },
      {
        "bk_biz_id": 7,
        "host_count": 35
      }
    ]
  }
}
```

### Response Parameters

| Parameter  | Type   | Description                                          |
| ---------- | ------ | ---------------------------------------------------- |
| code       | int32  | Status code, `0` means success                       |
| message    | string | Response message                                     |
| request_id | string | Request ID                                           |
| error      | object | Error information, empty on success                  |
| permission | object | Permission information, typically empty for this API |
| data       | object | Response data                                        |

#### data

| Parameter | Type  | Description                            |
| --------- | ----- | -------------------------------------- |
| items     | array | Host count list aggregated by business |

#### data.items[n]

| Parameter  | Type  | Description                        |
| ---------- | ----- | ---------------------------------- |
| bk_biz_id  | int64 | Business ID                        |
| host_count | int64 | Number of hosts under the business |

### Notes

- The request and response contract is defined by `proto/backend/api/v3/topo.proto` and `docs/api/swagger/backend/api/v3/topo.swagger.json`.
- If `bk_biz_id` is empty, protocol-layer validation returns a parameter error.
- If `node_role` is omitted, the API counts hosts of all node roles under the specified businesses. When only `agent` or `blank` is specified, the API checks `agent_view (View Agent)`. When only `proxy` is specified, the API checks `proxy_view (View Proxy)`. Mixed roles require the corresponding permissions for the requested roles.
- `items` is generated by aggregating host counts by business ID. Businesses with no matched hosts are usually not included in the returned list.
