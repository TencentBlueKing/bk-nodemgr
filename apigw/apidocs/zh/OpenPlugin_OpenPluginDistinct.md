### 描述

- 该接口提供版本：v3.0.1-alpha.117+。
- 该接口所需权限：system_access（系统访问）、plugin_view（查看插件）。
- 该接口功能描述：查询当前租户可见插件的分组去重值，包括尚未安装到主机的插件；不分页。
- 本接口为 backend 用户态入口，使用用户态身份认证，并检查系统访问权限与用户的插件查看业务范围。

### URL

POST /api/v3/open/plugin/distinct

### 输入参数

请求体为 JSON 对象。

| 参数名称                 | 参数类型 | 必选 | 描述                                                         |
| ------------------------ | -------- | ---- | ------------------------------------------------------------ |
| distinct_field           | object   | 否   | 要查询的去重字段；省略时查询全部支持字段，目前仅支持 `group` |
| exact_include_conditions | object   | 否   | 精确匹配条件                                                 |
| fuzzy_include_conditions | object   | 否   | 模糊匹配条件                                                 |

#### distinct_field

| 参数名称 | 参数类型 | 必选 | 描述                                                                              |
| -------- | -------- | ---- | --------------------------------------------------------------------------------- |
| group    | bool     | 否   | 为 `true` 时查询分组；`distinct_field` 为 `{}` 或 `group` 为 `false` 时不查询分组 |

#### exact_include_conditions

| 参数名称        | 参数类型     | 必选 | 描述                                                     |
| --------------- | ------------ | ---- | -------------------------------------------------------- |
| name            | string array | 否   | 插件名称精确匹配                                         |
| group           | string array | 否   | 插件分组精确匹配；获取分组筛选项时应省略，避免限制可选项 |
| visible_biz_ids | int64 array  | 否   | 业务可见范围，按用户授权收敛；省略时使用用户授权范围     |

#### fuzzy_include_conditions

| 参数名称 | 参数类型     | 必选 | 描述               |
| -------- | ------------ | ---- | ------------------ |
| name     | string array | 否   | 插件名称模糊匹配   |
| pkg_name | string array | 否   | 插件包名称模糊匹配 |

**范围说明**：

- 分组来自插件记录，不依赖主机上的插件进程，也不依赖某一页插件列表。精确与模糊条件共同生效。
- 应传入插件列表正在使用的 `visible_biz_ids`，并在业务选择变化后重新查询分组。
- 业务范围非空时，包含可见业务字段为空、null 或未设置的插件，以及可见业务 ID 数组与有效业务范围数组完全一致的插件；并非按任一业务 ID 相交匹配。
- 用户具有不限业务的权限且未提供业务条件时，不额外限制插件的可见业务范围。受限用户的有效授权范围为空时，返回空分组；权限检查失败时返回权限错误。
- 返回值不保证排序；分组名称不是固定枚举，接口不会补入不存在的 `default` 分组。

### 调用示例

获取业务 `2` 范围内的可见插件分组，不限定当前已选分组。

```json
{
  "distinct_field": { "group": true },
  "exact_include_conditions": { "visible_biz_ids": [2] }
}
```

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "request_id": "req-plugin-distinct",
  "error": null,
  "data": { "group": ["default", "custom"] }
}
```

### 响应参数说明

| 参数名称   | 参数类型 | 描述                    |
| ---------- | -------- | ----------------------- |
| code       | int32    | 状态码，0 表示成功      |
| message    | string   | 请求信息                |
| request_id | string   | 请求 ID                 |
| error      | object   | 错误信息，成功时为 null |
| data       | object   | 去重结果                |

#### data

| 参数名称 | 参数类型     | 描述                                                     |
| -------- | ------------ | -------------------------------------------------------- |
| group    | string array | 匹配插件的分组去重值；无匹配记录或未选择该字段时为空数组 |
