### 描述

- 该接口提供版本：v3.0.1-alpha.86+。
- 该接口所需权限：无。
- 该接口功能描述：触发一次性工作流，清理主机已不存在的遗留进程记录（孤立进程）。

### URL

POST /api/v3/sync/process/clean_orphan

### 输入参数

无业务参数，请提交 JSON 空对象 `{}`。租户 ID 和操作者用户名从已认证的请求上下文获取，两者均不能为空，无需在请求体中传入。

### 使用说明

- 无额外 IAM 操作权限要求；仍需通过接口身份认证。
- 候选条件为进程状态 `unknown`，且进程信息最后同步时间早于 48 小时前；同步时间缺失或为 null 也视为过期，不按托管状态筛选。清理任务先查询本地主机记录，仅对本地已软删除或记录不存在的主机继续查询 CMDB；只有 CMDB 中也不存在该主机时才删除进程。本地或 CMDB 中仍存在主机时保留进程；任一查询失败则当前清理任务报错，不执行删除。
- gen 一次查询符合条件的候选进程，按每批最多 500 条生成清理任务，全部创建后统一激活 trigger。清理任务校验主机是否存在，再通过现有进程删除路径逐条删除孤立记录，不会调用 GSE 停止或卸载进程。
- 接口成功仅表示工作流已创建并激活，不代表清理已完成；清理结果需查看工作流执行记录。

### 调用示例

```json
{}
```

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "request_id": "req-123456",
  "error": null,
  "permission": null,
  "data": {
    "trigger_id": "trig:6c0379fe82b44920a8c49508fb744d72"
  }
}
```

### 响应参数说明

| 参数名称 | 参数类型 | 描述 |
|---------|----------|------|
| code | int32 | 状态码，0 表示工作流已成功创建并激活 |
| message | string | 请求信息 |
| request_id | string | 请求 ID |
| error | object | 错误信息，成功时为空 |
| permission | object | 权限信息 |
| data | object | 响应数据 |

#### data

| 参数名称 | 参数类型 | 描述 |
|---------|----------|------|
| trigger_id | string | 本次一次性工作流的触发器 ID（trigger ID），不表示执行结果 |
