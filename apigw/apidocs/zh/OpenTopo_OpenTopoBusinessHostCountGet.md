### 描述

- 该接口提供版本：v3.0.1-alpha.107+。
- 该接口所需权限：system_access（系统访问）；根据 `node_role` 还需 agent_view（查看 Agent）或 proxy_view（查看 Proxy）。`blank`、`agent` 使用 Agent 权限，`proxy` 使用 Proxy 权限；未指定角色或同时查询两类角色时，取所需权限的授权业务范围交集。
- 该接口功能描述：通过用户态入口，按业务统计符合节点角色条件且在用户授权业务范围内的主机数量。
- 用户身份及租户信息由 API 网关传递，无需在请求体中提供用户名或租户 ID。

### URL

POST /api/v3/open/topo/business/host_count/get

### 输入参数

| 参数名称  | 参数类型     | 必选 | 描述                                                                          |
| --------- | ------------ | ---- | ----------------------------------------------------------------------------- |
| bk_biz_id | int64 array  | 是   | 要统计的业务 ID 列表，不能为空；与用户授权业务范围取交集                      |
| node_role | string array | 否   | 节点角色：`blank`（未安装节点）、`agent`、`proxy`；不传或为空表示不按角色过滤 |

### 调用示例

```json
{
  "bk_biz_id": [2, 3],
  "node_role": ["agent"]
}
```

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "request_id": "req-123456",
  "data": {
    "items": [
      { "bk_biz_id": 2, "host_count": 100 },
      { "bk_biz_id": 3, "host_count": 20 }
    ]
  }
}
```

### 响应参数说明

| 参数名称   | 参数类型 | 描述                                                                        |
| ---------- | -------- | --------------------------------------------------------------------------- |
| code       | int32    | 状态码，`0` 表示成功                                                        |
| message    | string   | 请求结果信息                                                                |
| request_id | string   | 请求 ID                                                                     |
| error      | object   | 错误信息，包含 `system`、`message` 和 `details`（错误码及说明）；成功时为空 |
| permission | object   | 权限申请信息，权限不足时可能返回                                            |
| data       | object   | 响应数据                                                                    |

#### data

| 参数名称 | 参数类型     | 描述                                                           |
| -------- | ------------ | -------------------------------------------------------------- |
| items    | object array | 按业务分组的统计结果；不保证为没有匹配主机的业务补充零计数记录 |

#### data.items[n]

| 参数名称   | 参数类型 | 描述                       |
| ---------- | -------- | -------------------------- |
| bk_biz_id  | int64    | 业务 ID                    |
| host_count | int64    | 符合节点角色条件的主机数量 |

### 说明

- 授权业务范围与请求业务列表没有交集时，返回空 `items`；权限校验失败时返回权限错误。
- 返回顺序不保证与请求的业务 ID 顺序一致。
