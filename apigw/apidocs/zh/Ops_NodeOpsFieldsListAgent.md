### 描述

- 该接口提供版本：v3.0.1-alpha.103+。
- 该接口所需权限：agent_view（查看 Agent）。
- 该接口功能描述：批量查询指定主机的带外管理设置当前值。

### URL

POST /api/v3/node/ops/list_fields/agent

### 输入参数

| 参数名称   | 参数类型    | 必选 | 描述                                                                                             |
| ---------- | ----------- | ---- | ------------------------------------------------------------------------------------------------ |
| bk_host_id | int64 array | 是   | 待查询的主机 ID 列表，数量必须为 1~500 个，元素必须大于 0；重复的主机 ID 会自动去重后查询。 |

**参数说明**：

- 返回的 `items` 条数始终等于请求中 `bk_host_id` 去重后的数量，调用方可据此确认所有目标主机均已解析。
- 任一 `bk_host_id` 未命中（不存在、已删除或不属于当前租户）时，接口返回参数错误，不会返回部分结果；错误详情中会带出全部未命中的主机 ID。
- 响应仅包含带外管理字段；业务、拓扑、内网 IP 等主机信息需通过主机列表等其他接口获取。
- 返回顺序不保证与请求中 `bk_host_id` 的顺序一致。
- 权限校验基于目标主机所属的业务（CMDB 业务）：任一业务缺少所需权限时，整个请求返回无权限错误。
- 本接口不按节点角色过滤结果；与 `/api/v3/node/ops/list_fields/proxy` 的响应结构一致，区别仅在于校验的查看权限（`agent_view` / `proxy_view`）。

### 调用示例

查询两台主机的带外管理设置。

```json
{
  "bk_host_id": [10001, 10002]
}
```

### 响应示例

```json
{
  "code": 0,
  "message": "OK",
  "request_id": "req-1234567890",
  "data": {
    "items": [
      {
        "bk_host_id": 10001,
        "ops_console_host_id": 20001,
        "ops_out_band_type": "string",
        "ops_out_band_protocol": "string",
        "ops_out_band_ip": "10.0.0.1",
        "ops_out_band_port": 22
      }
    ]
  }
}
```

### 响应参数说明

| 参数名称   | 参数类型 | 描述                     |
| ---------- | -------- | ------------------------ |
| code       | int32    | 状态码，0 表示成功       |
| message    | string   | 请求信息                 |
| request_id | string   | 请求 ID                  |
| error      | object   | 错误信息，成功时不返回   |
| permission | object   | 权限信息，无权限时返回   |
| data       | object   | 响应数据                 |

#### data

| 参数名称 | 参数类型     | 描述                                               |
| -------- | ------------ | -------------------------------------------------- |
| items    | object array | 请求中 `bk_host_id` 去重后对应主机的带外管理设置列表 |

#### data.items[n]

| 参数名称              | 参数类型 | 描述                                                                                                                                  |
| --------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| bk_host_id            | int64    | 主机 ID                                                                                                                               |
| ops_console_host_id   | int64    | 主控机主机 ID，由该主机对目标主机执行带外操作（通常为跳板机或运维机，需已安装蓝鲸 GSE Agent）；未设置时为 0                            |
| ops_out_band_type     | string   | 带外设备类型，自由文本：板载带外管理填 `onboard`，外接带外设备填其类型标识（如 `nanokvm`）；未设置时为空字符串                         |
| ops_out_band_protocol | string   | 带外操作使用的通信协议，自由文本：如 `ipmi`（通用标准协议）、`nanokvm-gpio`（针对特定设备的扩展协议）；未设置时为空字符串              |
| ops_out_band_ip       | string   | 设备的带外管理 IP 地址，通常与主机自身 IP 相互独立，需对主控机可达；未设置时为空字符串                                                 |
| ops_out_band_port     | int64    | 带外管理端口，通常使用协议默认端口（如 IPMI 常用 623）；未设置时为 0                                                                   |
