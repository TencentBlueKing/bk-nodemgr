### 描述

- 该接口提供版本：v3.0.1-alpha.105+
- 该接口所需权限：system_access（系统访问）、agent_operate（操作 Agent）、networkunit_use_for_agent（使用管控单元部署 Agent）。
- 该接口功能描述：以用户身份按组将尚未分配管控单元的主机分配到不同管控单元。只更新主机归属，不执行 Agent 安装、升级或重新配置。
- 用户身份由 API 网关认证并传递，请求体不需要用户名或租户参数。`agent_operate` 按所有目标主机所属业务校验，`networkunit_use_for_agent` 按所有目标管控单元校验。

### URL

POST /api/v3/open/node/agent/assign_unit_multi

### 输入参数

| 参数名称 | 参数类型     | 必选 | 描述                               |
| -------- | ------------ | ---- | ---------------------------------- |
| items    | object array | 是   | 分配组列表，不能为空；不允许空元素 |

#### items[n]

| 参数名称          | 参数类型    | 必选 | 描述                                                                   |
| ----------------- | ----------- | ---- | ---------------------------------------------------------------------- |
| bk_host_id        | int64 array | 是   | 本组主机 ID 列表，不能为空；整个请求内主机 ID 不得重复，包括同组内重复 |
| bk_networkunit_id | int64       | 是   | 本组目标管控单元 ID，必须大于等于 `0` 且已存在                         |

每组中的已找到主机须属于同一管控区域，且与本组目标单元的管控区域一致；不同组可属于不同区域。已有管控单元的主机不能通过本接口更换单元，即使当前单元与目标相同也计为失败；不存在的主机也计入失败数量。

所有目标单元及权限先统一校验；通过后按组分配。某组分配失败时其他组仍可能成功，不提供全请求原子性。应读取成功数、失败数和原因；失败原因可能按组或批次汇总，不保证与主机逐一对应。

### 调用示例

```json
{
  "items": [
    { "bk_host_id": [1001, 1002], "bk_networkunit_id": 1 },
    { "bk_host_id": [1003], "bk_networkunit_id": 2 }
  ]
}
```

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "request_id": "req-123456",
  "data": {
    "success_count": 3,
    "failed_count": 0,
    "failed_reasons": []
  }
}
```

### 响应参数说明

| 参数名称   | 参数类型 | 描述                                   |
| ---------- | -------- | -------------------------------------- |
| code       | int32    | 状态码；`0` 不保证所有主机均已分配成功 |
| message    | string   | 请求信息                               |
| request_id | string   | 请求 ID                                |
| error      | object   | 错误信息                               |
| permission | object   | 权限信息                               |
| data       | object   | 所有组的同步汇总结果，不返回工作流 ID  |

#### data

| 参数名称       | 参数类型     | 描述                     |
| -------------- | ------------ | ------------------------ |
| success_count  | int64        | 所有组分配成功的主机总数 |
| failed_count   | int64        | 所有组分配失败的主机总数 |
| failed_reasons | string array | 汇总失败原因             |
