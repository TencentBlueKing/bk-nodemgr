# SSH 连接失败排查指引

安装 Agent 时，如果通过 SSH 探测主机信息的步骤无法连接目标主机，可参考本指引排查。

## 查看失败详情

打开失败任务，在执行日志中查看错误信息，并核对节点管理中配置的目标主机登录地址、SSH 端口、登录用户和认证方式。

主机的 SSH 端口不一定是默认的 22，请以该主机的实际配置为准。

## 连接超时、连接被拒绝或网络不可达

请联系管理员检查：

1. 目标主机是否正常运行，SSH 服务是否监听配置的地址和端口。
2. 节点管理 backend 是否能访问该地址和端口。从个人电脑连接成功，并不代表 backend 也能连接成功。
3. 路由、安全组和防火墙是否允许 backend 连接目标主机。

不要为排查问题直接关闭防火墙，或将 SSH 端口开放到公网。

## 认证失败

请核对：

- 登录用户是否存在、是否允许通过 SSH 登录，以及是否被锁定或已过期。
- 选择的认证方式是否与目标主机 SSH 服务端配置一致。
- 使用密码认证时，节点管理中配置的凭据是否仍然有效。
- 使用私钥认证时，配置的私钥是否与登录用户已授权的公钥匹配，以及目标主机是否接受该密钥。

在节点管理中更新有误的凭据后，重试失败任务。不要在任务备注、截图或支持请求中提供密码或私钥。

## 仍然无法连接

请联系管理员查看目标主机的 SSH 认证日志，并与失败任务的时间进行比对。请求支持时，请提供任务标识、失败时间、错误信息和认证方式，并移除凭据及其他敏感信息。
