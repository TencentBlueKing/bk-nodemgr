## [Version: v3.0.1-alpha.57] - 2026-07-22

Full Changelog: [v3.0.1-alpha.56...v3.0.1-alpha.57](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.56...v3.0.1-alpha.57)

**Release scope**

- Agent: Agent, Plugin, and Package formats remain compatible; node full uninstall supports a skip-callback path for full uninstall scenarios.
- Backend/Control Plane: Topology queries use the brief cache path, host synchronization writes are idempotent, host upsert reuses matched host IDs, and the base MongoDB ORM adds ORM ScanAll.
- API/Documentation: Config policy priority reorder API documentation is added, and topology API documentation is updated for the brief topology response.
- Frontend: Topology callers align with the brief topology response fields.
- Installer/Deployment: Deployment assets should use v3.0.1-alpha.57.

**New features**

- Topology queries switch to the brief cache path to reduce repeated full topology lookups.
- Node full uninstall supports skip-callback handling, and Proxy uninstall aligns with the skip report flow.
- The base MongoDB ORM adds ORM ScanAll for full result scanning in shared DAO code.

**Improvements**

- Host upsert reuses an already matched host ID, reducing duplicate host records during synchronization.
- Config policy priority reorder API documentation is available for API users.

**Bug fixes**

- Host synchronization writes are idempotent, preventing repeated sync attempts from creating inconsistent write results.
- Node full uninstall can skip callback handling when the uninstall workflow requires that path.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- Full uninstall skip-callback and Proxy skip report handling update workflow behavior without changing package format contracts.

**Component dependencies and upgrade prerequisites**

- Upgrade deployment assets with v3.0.1-alpha.57.
- This version does not sync Backend API Gateway resources; API Gateway release metadata remains `2.18.1 / v3.0.1-alpha.56`.
