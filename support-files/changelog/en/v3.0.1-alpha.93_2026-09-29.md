## [Version: v3.0.1-alpha.93] - 2026-09-29

Full Changelog: [v3.0.1-alpha.92...v3.0.1-alpha.93](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.92...v3.0.1-alpha.93)

**Release scope**

- Backend/Control Plane: Improved cross-backend file copy support, synchronized network area changes to CMDB, and fixed Relay SSH client cleanup.
- Frontend: Adjusted frontend permission checks and plugin operation permission control.
- Installer/Deployment: Optimized Node Manager image build inputs, installation dependencies, and installer handling on unsupported platforms, and removed the legacy mock-server and old test harness.

**New features**

- Added cross-backend FileGroup copy support to reuse artifact contents across file services.

**Improvements**

- Optimized Node Manager image packaging and frontend build context inputs to reduce unrelated files in image builds.
- Switched TencentOS 4 deployment to install MongoDB Shell from the official tarball.
- Skipped UPX compression on installer platforms that do not support UPX to avoid blocking package builds.

**Bug fixes**

- Fixed network area changes not being synchronized to CMDB.
- Fixed Relay SSH detection or installation flows not closing SSH clients promptly.
- Fixed a plugin operation permission validation vulnerability and adjusted frontend permission checks.
- Upgraded `amqp091-go`, `go-archive`, `grpc-go`, `opentelemetry-go`, and `quic-go` to resolve security vulnerabilities.

**Agent / Plugin / Package compatibility**

- This version does not change Agent, Plugin, or Package formats.

**Component dependencies and upgrade prerequisites**

- The installation and deployment flow no longer includes the legacy mock-server or old test harness. Environments that depended on those local debugging entry points should use the current test and debug paths retained in this repository.
