## [Version: v3.0.1-alpha.67] - 2026-08-10

Full Changelog: [v3.0.1-alpha.66...v3.0.1-alpha.67](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.66...v3.0.1-alpha.67)

**Release scope**

- Agent: Agent repository guidance is updated, and Agent, Plugin, and Package formats remain compatible.
- Plugin: Windows Plugin endpoint rendering is fixed.
- Package: Repository properties metadata is added, and resource pack view permission checks on the Plugin Package management page are fixed.
- Backend/Control Plane: bkrepo system tenant requests, the tenant ID provider contract, workflow storage scheduler registration, API Gateway release metadata, and API Gateway resources are updated.
- Frontend: Policy configuration page text and Plugin Package management permission checks are improved.
- Installer/Deployment: Deploy policy integration docs and community health docs are added.

**New features**

- The bkrepo system tenant ID provider contract is added, so Backend/Control Plane requests can share the same system tenant source.
- Repository properties metadata is added to keep Package repository information consistent across release and management flows.
- The project error handling skill is added to align Go error handling writing and review rules.
- Community health docs are added to clarify contribution, collaboration, and project governance information.

**Improvements**

- Deploy policy integration docs are added to make deployment policy integration clearer.
- bkrepo system tenant requests now use the shared tenant ID source.
- Agent repository guidance is updated.
- Policy configuration page descriptions are improved.
- API Gateway release metadata is aligned to `3.0.1-alpha.67`.
- API Gateway resources are synced with Chinese and English descriptions for the newly added Package endpoints in this release.

**Bug fixes**

- Workflow storage scheduler registration and nil checks are fixed to improve workflow storage scheduling stability.
- Windows Plugin endpoints now render with loopback, fixing endpoint generation for Windows Plugin access.
- Frontend permission checks for viewing resource packs on the Plugin Package management page are fixed.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This release does not require a Package format upgrade.
- The Windows Plugin endpoint fix does not change the Plugin package format.

**Component dependencies and upgrade prerequisites**

- API Gateway release version is `3.0.1-alpha.67`.
- This release does not introduce new external component dependencies.
- This release does not require extra upgrade prerequisites.
