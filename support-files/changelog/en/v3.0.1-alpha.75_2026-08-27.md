## [Version: v3.0.1-alpha.75] - 2026-08-27

Full Changelog: [v3.0.1-alpha.74...v3.0.1-alpha.75](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.74...v3.0.1-alpha.75)

**Release scope**

- Agent: Agent / Proxy package formats remain compatible.
- Plugin: Package workflow API descriptions were updated for Plugin / Package import and export operations.
- Package: Package workflow documentation now describes asynchronous import/export results and temporary download addresses more clearly.
- Backend/Control Plane: Tenant providers now use storage-backed data, disabled tenants are included in sync diff, and enabled-tenant API naming is aligned.
- Installer/Deployment: File service exporter HTTP configuration, tracing global fallback, biz-scoped node event data ID configuration, Helm versions, API Gateway release metadata, and image versions are aligned to v3.0.1-alpha.75.

**New features**

- Added storage-backed tenant provider support for backend and application services.
- Added biz-scoped node event data ID configuration for node deployment rendering.
- Added file service exporter HTTP server configuration.

**Improvements**

- Tracing now supports global fallback configuration across application, backend, file, and relay services.
- Package workflow API descriptions now cover import/export workflow behavior and result query usage.
- Enabled tenant list naming is aligned across tenant storage and related service paths.

**Bug fixes**

- Disabled tenants are included when tenant sync diffs are calculated.

**Agent / Plugin / Package compatibility**

- Agent / Proxy package versions are aligned with the system version v3.0.1-alpha.75.
- Plugin and Package package formats remain compatible.

**Component dependencies and upgrade prerequisites**

- API Gateway release version / comment are aligned to `3.0.1-alpha.75`.
- API Gateway PackageWorkflow resource descriptions are synchronized with the updated backend swagger summaries.
- Helm chart version, appVersion, server image tag, apigw-sync image tag, and mock-server image tag are aligned to `v3.0.1-alpha.75`.
