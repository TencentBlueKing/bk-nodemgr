## [Version: v3.0.1-alpha.58] - 2026-07-23

Full Changelog: [v3.0.1-alpha.57...v3.0.1-alpha.58](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.57...v3.0.1-alpha.58)

**Release scope**

- Agent: Agent, Plugin, and Package formats remain compatible.
- Backend/Control Plane: Host synchronization queries, AgentID filtering, trigger indexes, and concurrent change checks are improved; SSH installer polling and log reporting are shared across backend and relay paths.
- Frontend: The assign management unit page supports one-click removal of unassigned control units.
- Installer/Deployment: Deployment assets should use v3.0.1-alpha.58.

**New features**

- The assign management unit page adds one-click removal for unassigned control units, reducing manual cleanup work for invalid assignment relationships.

**Improvements**

- Trigger collection category indexes now use `{data.category: 1}` with a non-deleted partial filter, supporting cleanup and active trigger sync while avoiding recreation of the old index.
- Sync host task generation improves AgentID not-empty filtering, reducing inefficient queries caused by empty AgentID conditions.
- The full sync_host Host DB query switches to ScanAllHostWithFields and DAO/storage scan-all paths, avoiding the Count plus UnlimitedPage List pattern for large result sets.
- Backend and relay SSH installer polling, remote log reading, state parsing, timeout handling, and reconnect behavior now share the poller path, making installer log reporting more consistent.

**Bug fixes**

- Host synchronization re-checks host additions and deletions before writing, reducing duplicate writes and mistaken deletes when source data changes concurrently.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This version's synchronization, index, and installer polling changes don't change Agent, Plugin, or Package format contracts.

**Component dependencies and upgrade prerequisites**

- Upgrade deployment assets with v3.0.1-alpha.58.
- This version does not sync Backend API Gateway resources; API Gateway release metadata remains `2.18.1 / v3.0.1-alpha.56`.
