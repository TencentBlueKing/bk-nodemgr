## [Version: v3.0.1-alpha.62] - 2026-07-29

Full Changelog: [v3.0.1-alpha.61...v3.0.1-alpha.62](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.61...v3.0.1-alpha.62)

**Release scope**

- Agent: Agent, Plugin, and Package formats remain compatible.
- Backend/Control Plane: Stopping operation instance Change Stream watch scope and TTL index initialization are improved.
- API Gateway: Backend API Gateway resources are not synced in this version. Release metadata remains `2.18.2 / v3.0.1-alpha.61`.
- Developer Experience: Mongo business integration tests, CodeCC/golint maintenance annotations, and logger package maintenance guidance are updated.
- Installer/Deployment: Deployment assets should use v3.0.1-alpha.62.

**Improvements**

- Stopping operation instance watches are narrowed to the owning Mongo database and collection, reducing unrelated Change Stream events in stop-operation flows.
- Stopping operation instance TTL index creation now runs during DAO initialization, keeping expired stop-operation data cleanup available before upsert traffic.
- Mongo business integration tests now use `testsuite/support` isolated databases, reducing fixed environment coupling for package-level integration testing.
- Logger package maintenance guidance now documents the package scope, logging category rules, structured fields, and operational compatibility surfaces for future changes.
- CodeCC/golint maintenance updates clarify comments, naming, and NOCC annotations without changing runtime behavior.

**Bug fixes**

- Stopping operation instance Change Stream matching now includes namespace constraints, so watchers only react to the intended database and collection.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This version changes Backend maintenance and testing assets only. It does not change package format contracts.

**Component dependencies and upgrade prerequisites**

- Upgrade deployment assets with v3.0.1-alpha.62.
- Backend API Gateway resources are not synced in this version. API Gateway release metadata remains `2.18.2 / v3.0.1-alpha.61`.
- This version does not introduce new component prerequisites for Agent, Plugin, or Package rollout.
