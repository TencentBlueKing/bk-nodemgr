## [Version: v3.0.1-alpha.89] - 2026-09-18

Full Changelog: [v3.0.1-alpha.88...v3.0.1-alpha.89](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.88...v3.0.1-alpha.89)

**Release scope**

- Installer/Deployment: Helm self-monitoring, Grafana data source provisioning, and chart dependency resolution.

**New features**

- Added optional Prometheus self-monitoring configuration in Helm to scrape `/metrics` from the application, backend, and file services.
- Grafana automatically provisions enabled Prometheus and Tempo data sources, using Prometheus as the default when enabled.

**Improvements**

- Standardized Helm configuration examples to use IP placeholders.

**Bug fixes**

- Switched Helm chart dependencies to bundled local charts, removing the need to download these dependencies from external chart repositories during dependency builds.

**Agent / Plugin / Package compatibility**

- This version does not change Agent / Proxy, Plugin, or Package formats.

**Component dependencies and upgrade prerequisites**

- Prometheus and Grafana remain disabled by default and can be enabled as needed. Grafana requires either Tempo or Prometheus to be enabled.
- Prometheus persistence is disabled by default. To retain monitoring data, explicitly enable `prometheus.server.persistentVolume.enabled` and configure persistent storage.
- Restart Grafana after changing embedded data source addresses or ports.
