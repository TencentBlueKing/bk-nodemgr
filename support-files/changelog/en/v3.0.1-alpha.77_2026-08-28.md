## [Version: v3.0.1-alpha.77] - 2026-08-28

Full Changelog: [v3.0.1-alpha.76...v3.0.1-alpha.77](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.76...v3.0.1-alpha.77)

**Release scope**

- Agent: Agent / Proxy package formats remain compatible.
- Plugin: Deploy policy can generate apply subconfig tasks from plugin subconfig templates, and Plugin / Package package formats remain compatible.
- Package: Package workflow APIs and package formats remain compatible.
- Backend/Control Plane: Application API v3 adds deploy_policy list / execute proxy endpoints, and Backend DPMgr supports specify_plugin_sub_config_template expansion.
- Installer/Deployment: Helm versions, API Gateway release metadata, and image versions are aligned to v3.0.1-alpha.77.

**New features**

- Added Application API v3 deploy policy list / execute endpoints for application-side access to existing Backend deploy policy capabilities.
- Added deploy policy support for plugin subconfig templates, allowing apply subconfig tasks to be generated from target hosts and template content.

**Improvements**

- Apply subconfig workflow now preserves ProcessConfig Set and stable configuration instance names for consistent configuration persistence.

**Agent / Plugin / Package compatibility**

- Agent / Proxy package versions are aligned with the system version v3.0.1-alpha.77.
- Plugin and Package package formats remain compatible; the new plugin subconfig template policy does not change existing package formats.

**Component dependencies and upgrade prerequisites**

- API Gateway release version / comment are aligned to `3.0.1-alpha.77`.
- Helm chart version, appVersion, server image tag, apigw-sync image tag, and mock-server image tag are aligned to `v3.0.1-alpha.77`.
- This version does not introduce additional component dependencies.
