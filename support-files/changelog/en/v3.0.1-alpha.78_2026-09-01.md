## [Version: v3.0.1-alpha.78] - 2026-09-01

Full Changelog: [v3.0.1-alpha.77...v3.0.1-alpha.78](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.77...v3.0.1-alpha.78)

**Release scope**

- Agent: Agent / Proxy package formats remain compatible.
- Plugin: Deploy policy adds project-level plugin package and config template placement capabilities, and Plugin / Package package formats remain compatible.
- Package: Package workflow APIs and package formats remain compatible.
- Backend/Control Plane: Backend adds host and process sync timestamps, improves deploy policy filtering, reuses remove subconfig workflows, and supports automatic direct network unit creation for network area 0.
- Installer/Deployment: Helm versions, API Gateway release metadata, API Gateway resources, and image versions are aligned to v3.0.1-alpha.78.

**New features**

- Added deploy policy support for project plugin package placement and project plugin config template placement.
- Added host and process last sync timestamps to API responses for topology and process queries.
- Added automatic direct network unit creation for network area 0.

**Improvements**

- Deploy policy remove subconfig scenarios now reuse the existing remove subconfig workflow.
- Added deployment integration documentation for plugin package placement, plugin config template placement, and init package import.

**Bug fixes**

- Fixed deploy policy count-only list handling when page parameters are omitted.
- Fixed force restart behavior to avoid routing through operate_agent.
- Removed legacy event data ID configuration from deployment values.

**Agent / Plugin / Package compatibility**

- Agent / Proxy package versions are aligned with the system version v3.0.1-alpha.78.
- Plugin and Package package formats remain compatible.

**Component dependencies and upgrade prerequisites**

- API Gateway release version / comment are aligned to `3.0.1-alpha.78`.
- API Gateway resources are synced for the changed Backend deploy_policy, process, and topo API schemas.
- Helm chart version, appVersion, server image tag, apigw-sync image tag, and mock-server image tag are aligned to `v3.0.1-alpha.78`.
- This version does not introduce additional component dependencies.
