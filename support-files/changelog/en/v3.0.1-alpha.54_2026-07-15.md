## [Version: v3.0.1-alpha.54] - 2026-07-15

Full Changelog: [v3.0.1-alpha.53...v3.0.1-alpha.54](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.53...v3.0.1-alpha.54)

**Release scope**

- Agent: Agent, Plugin, and Package formats remain compatible; a Windows SSH Proxy Agent installation flow is added.
- Backend/Control Plane: Windows SSH Proxy Agent installation orchestration is added, and Trigger category queries plus host list operation-time sorting are optimized.
- Relay: Windows SSH environments can now be detected and used to execute Proxy Agent installation.
- Frontend: Network unit base deploy path changes now show a risk prompt.
- Installer/Deployment: Helm chart, service image, API Gateway sync image, and mock-server image align to v3.0.1-alpha.54.

**New features**

- Adds backend orchestration and Relay execution for installing Proxy Agent through Windows SSH environments.
- Adds a frontend risk prompt before changing the base deploy path when the network unit already has nodes with installed Agent.

**Improvements**

- Adds an active/alive partial index for Trigger category queries to improve category filtering performance.
- Removes the generic update-time fallback from host list business operation-time sorting and simplifies related indexes to reduce sort query cost.

**Bug fixes**

- Fixes the default Relay callback/download ports used when assigning Proxy network units so they match the Relay service configuration.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- The Windows SSH Proxy Agent installation capability is an additional flow and does not change existing Agent / Proxy package formats.

**Component dependencies and upgrade prerequisites**

- Upgrade deployment assets with the v3.0.1-alpha.54 Helm chart, service image, API Gateway sync image, and mock-server image.
- This version does not sync API Gateway resources; API Gateway release metadata remains `2.17.1 / v3.0.1-alpha.52`.
