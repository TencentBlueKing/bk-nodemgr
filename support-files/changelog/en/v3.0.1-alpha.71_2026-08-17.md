## [Version: v3.0.1-alpha.71] - 2026-08-17

Full Changelog: [v3.0.1-alpha.70...v3.0.1-alpha.71](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.70...v3.0.1-alpha.71)

**Release scope**
- Agent: Fixed target-version usage for Plugin upgrade deployments so upgrade workflows render the intended version.
- Plugin: Plugin / Plugin V2 deployment rendering now follows the selected target version, while the Plugin package format remains compatible.
- Package: This version does not change Package release semantics or package format.
- Backend/Control Plane: API error responses now display trace-id; UserManager tenant-list requests keep the system-tenant context; node-deployment read errors remain traceable.
- Installer/Deployment: Aligned Helm, API Gateway release metadata, and image versions to v3.0.1-alpha.71.

**Improvements**
- API error messages now display trace-id so operators can locate backend failures by request trace.
- Strategy preview copy was adjusted to make policy confirmation easier to read.

**Bug fixes**
- Plugin upgrade deployment rendering now uses the target version instead of continuing with an unintended version.
- UserManager tenant-list requests keep the system-tenant context, improving tenant-list reads in multi-tenant scenarios.
- Node-deployment read failures preserve the original error semantics so callers can identify the failure cause.

**Agent / Plugin / Package compatibility**
- Agent / Proxy package versions are aligned with the system version v3.0.1-alpha.71.
- Plugin and Package package formats remain compatible.
- This version does not require changes to the existing Plugin package build flow.

**Component dependencies and upgrade prerequisites**
- API Gateway release version / comment are aligned to `3.0.1-alpha.71`.
- Helm chart version, appVersion, server image tag, apigw-sync image tag, and mock-server image tag are aligned to `v3.0.1-alpha.71`.
- This version does not introduce new component dependencies.
