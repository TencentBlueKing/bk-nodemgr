## [Version: v3.0.1-alpha.34] - 2026-06-03

Full Changelog: [v3.0.1-alpha.33...v3.0.1-alpha.34](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.33...v3.0.1-alpha.34)

**Release scope**

- Agent: This release does not change Agent runtime behavior.
- Plugin: Improves plugin name display and operation entry behavior when opening the plugin process page from Agent / Proxy status pages.
- Package: This release does not change Agent / Plugin / Package formats.
- Backend/Control Plane: Adds scheduled host topology relation sync operation and improves offline install configuration output formatting.
- API / Gateway: This release does not change external API contracts, Swagger files, or API Gateway resource definitions.
- Frontend: Optimizes topology diagram layout, area bounds, edge routing, and drag performance.
- Installer/Deployment: Fixes Helm chart rendering for the apigw-sync image repository and tag, and aligns Helm chart version, appVersion, and image tag to v3.0.1-alpha.34.

**New features**

- Added scheduled host topology relation sync operation, using the existing workflow chain to sync CMDB host topology relation data by business.

**Optimizations**

- The plugin process operation page now displays plugin names when opened from Agent / Proxy status pages and keeps the correct install operation semantics for those entries.
- Offline install configuration output is now formatted JSON for better readability.
- Topology diagram layout now improves area height/width calculation, edge avoidance, and drag interaction performance to reduce overlap and lag in complex topologies.

**Bug fixes**

- Fixed Helm chart apigw-sync job image rendering, with separate repository support and fallback to the root image tag when imageTag is empty.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This release does not introduce new Agent / Plugin package upgrade prerequisites.

**Component dependencies and upgrade prerequisites**

- This release does not introduce new external component dependencies.
- Host topology relation sync depends on the existing CMDB integration and backend workflow scheduling capability.
