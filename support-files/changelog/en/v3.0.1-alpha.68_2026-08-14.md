## [Version: v3.0.1-alpha.68] - 2026-08-14

Full Changelog: [v3.0.1-alpha.67...v3.0.1-alpha.68](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.67...v3.0.1-alpha.68)

**Release scope**
- Agent: Added the Windows auto-install workflow and Agent / Proxy batch assign-unit capability.
- Plugin: This version does not change the Plugin package format, and existing Plugin release compatibility remains unchanged.
- Package: Package release visibility now uses hidden-state semantics, with API Gateway resource descriptions synchronized.
- Backend/Control Plane: Added tenant-isolated collections, remote file download, discover registration prevalidation, and API Gateway sync / permission fixes.
- Installer/Deployment: Aligned Helm, API Gateway release metadata, and image versions to v3.0.1-alpha.68, with additional external MongoDB and Redis Cluster deployment documentation.

**New features**
- Added the Windows auto-install workflow to extend Windows Agent installation support.
- Added Agent / Proxy batch assign-unit APIs to reduce the operational cost of assigning multiple nodes.
- Added the remote file download interface and a shared HTTP downloader package.
- Split AccessPoint, NetworkArea, NetworkUnit, and PackageEvent collections by tenant to improve multi-tenant data isolation.
- Added an ensure-default cipher storage interface and preserved custom config context when saving process configs.

**Improvements**
- Changed Package release visibility from `is_visible` to hidden-state semantics, keeping APIs and API Gateway resource descriptions aligned.
- Split metrics dashboard presets to reduce preset dashboard maintenance cost.
- Added or updated discover package, process config, Redis Cluster queue isolation, installation API Gateway permission, and thirdparty API Gateway permission documentation.
- Removed the unused CMDB `searchObject` interface and aligned discover provider naming.

**Bug fixes**
- Added discover register batch prevalidation to reduce invalid requests entering downstream processing.
- Fixed partial retry start index calculation when an operation-level failure occurs.
- Parameterized Helm runtime values to avoid fixing runtime configuration directly in the chart.
- Added tenant id to API Gateway sync requests and switched to the UserManager API Gateway configuration.

**Agent / Plugin / Package compatibility**
- Agent / Proxy package versions are aligned with the system version v3.0.1-alpha.68.
- Plugin package format and existing release compatibility remain unchanged.
- Package release hidden-state API semantics are published through synchronized API Gateway resources; integrators should read visibility state using the new field semantics.

**Component dependencies and upgrade prerequisites**
- API Gateway release version / comment are aligned to `3.0.1-alpha.68`.
- Helm chart version, appVersion, server image tag, apigw-sync image tag, and mock-server image tag are aligned to `v3.0.1-alpha.68`.
- Deployments using external MongoDB or Redis Cluster can use this version's Helm values and queue isolation documentation to review configuration.
