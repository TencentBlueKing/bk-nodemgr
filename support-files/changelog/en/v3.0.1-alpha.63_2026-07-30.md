## [Version: v3.0.1-alpha.63] - 2026-07-30

Full Changelog: [v3.0.1-alpha.62...v3.0.1-alpha.63](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.62...v3.0.1-alpha.63)

**Release scope**

- Agent: Agent, Plugin, and Package formats remain compatible.
- Backend/Control Plane: IAM system token caching, config policy updates, host query indexes, and GSE zone id mapping are improved.
- Frontend: Plugin install parameter configuration now supports copy and paste.
- API Gateway: Backend API Gateway resources are not synced in this version. Release metadata remains `2.18.2 / v3.0.1-alpha.61`.
- Developer Experience: Go toolchain, architecture judgment skill, domain glossary, and control-flow guidance are updated.
- Installer/Deployment: Deployment assets should use v3.0.1-alpha.63.

**New features**

- Plugin install parameter configuration now supports copy and paste, helping reuse filled parameters across multiple plugin configuration entries.
- Installer plugin debug now supports skipping callback steps, reducing external callback dependencies during debugging.
- Architecture judgment skill and domain glossary are added to support future architecture reviews, terminology alignment, and design discussion.

**Improvements**

- Go toolchain is upgraded to 1.25.12, with matching lint, build, setup, and compile configuration updates.
- IAM system tokens are cached in memory, reducing repeated third-party IAM token requests.
- Host query indexes are aligned with current query conditions to improve host list query performance.
- GSE zone id naming is aligned with CMDB idc area semantics, reducing cross-system field ambiguity.
- Control-flow guidance now documents non-arrow flow rules to reduce future Go maintenance complexity.

**Bug fixes**

- Config policy update now avoids update drift, preventing unchanged fields from producing extra differences during update flows.
- GSE zone id and CMDB idc area mapping remain consistent across node deployment and plugin configuration flows.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This version updates Backend, Frontend, Installer, and Developer Experience assets. It does not change package format contracts.

**Component dependencies and upgrade prerequisites**

- Upgrade deployment assets with v3.0.1-alpha.63.
- Backend API Gateway resources are not synced in this version. API Gateway release metadata remains `2.18.2 / v3.0.1-alpha.61`.
- This version does not introduce new component prerequisites for Agent, Plugin, or Package rollout.
