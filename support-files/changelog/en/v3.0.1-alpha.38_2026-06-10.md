## [Version: v3.0.1-alpha.38] - 2026-06-10

Full Changelog: [v3.0.1-alpha.37...v3.0.1-alpha.38](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.37...v3.0.1-alpha.38)

**Release scope**

- Agent: Adds documentation for node control mode and network unit. Installation and operations remain compatible.
- Plugin: Adds Plugin compatibility policy for plugin installation, upgrade, and configuration delivery.
- Package: Agent / Plugin / Package formats remain compatible.
- Backend/Control Plane: Adds business host count, business instance topology, and topology host filtering capabilities; splits Proxy upgrade and reconfig workflows.
- API / Gateway: Syncs Swagger, API Gateway resources, and API docs for node_agent, node_proxy, plugin, and topo APIs.
- Frontend: Improves IP Selector, topology graph, and control unit allocation interactions.
- Installer/Deployment: Fixes Relay workspace directory and filesystem handling.

**New features**

- Added business host count API for business-level host statistics.
- Added business instance topology API to complete business topology query coverage.
- Added set and module filters for topology host queries.
- Added Plugin compatibility policy for compatibility-mode control.

**Improvements**

- Split Proxy upgrade and reconfig workflows so upgrade and reconfiguration actions use separate flows.
- Improved IP Selector cross-page selection, topology hierarchy display, and control unit allocation interactions.
- Added documentation for node control mode, host concepts, and network unit.

**Bug fixes**

- Fixed Relay workspace directory handling to avoid file-processing issues caused by invalid workspace paths.
- Fixed Relay filesystem helper behavior to improve directory read and write stability.
- Improved business filter impact display in task details and default username conversion handling.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- Plugin compatibility follows the policy updated in this version for installation, upgrade, and configuration delivery.
- Proxy upgrade and reconfig actions now follow separate workflows.

**Component dependencies and upgrade prerequisites**

- This release does not introduce new external component dependencies.
- API Gateway resources and apidocs are synced with the API changes in this version.
- Confirm Relay workspace directories have the required read and write permissions before upgrade.
