## [Version: v3.0.1-alpha.65] - 2026-08-04

Full Changelog: [v3.0.1-alpha.64...v3.0.1-alpha.65](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.64...v3.0.1-alpha.65)

**Release scope**

- Agent: Agent, Plugin, and Package formats remain compatible.
- Plugin: Config policy now supports logger path options for managing Agent and Proxy log paths.
- Package: Agent, Plugin, and Package formats remain compatible.
- Backend/Control Plane: Try reuse agent id host result guard, CMDB integration testsuite support, and Windows SSH install documentation are updated.
- Frontend: Control area list table refresh after create or delete operations is fixed.
- API Gateway: Backend API Gateway resources are not synced in this version. Release version is updated to `3.0.1-alpha.65`.
- Developer Experience: GitHub Actions checkout is upgraded to v5, and CMDB integration testsuite support is added.
- Installer/Deployment: Deployment assets should use v3.0.1-alpha.65.

**New features**

- Config policy now supports Agent and Proxy logger path options, extending log path configuration capability.
- Windows SSH install method documentation is added to guide Windows node installation through SSH.

**Improvements**

- GitHub Actions checkout action is upgraded to v5, keeping CI workflow dependencies aligned.
- CMDB integration testsuite support is added under `pkg/thirdparty/cmdb` and `testsuite/support` for later integration test reuse.
- Installer downloader and system info log levels are lowered to reduce noisy operational logs during installation.

**Bug fixes**

- Control area list page now refreshes the table after creating or deleting a control area, avoiding stale page data.
- Relay Windows SSH client error reporting is fixed, returning clearer errors for Windows SSH installation failures.
- Backend try reuse agent id host result now has an added guard, preventing abnormal host results from affecting the reuse flow.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This version updates config policy, Backend, Relay, Frontend, Installer, documentation, and Developer Experience. It does not change package format contracts.

**Component dependencies and upgrade prerequisites**

- Upgrade deployment assets with v3.0.1-alpha.65.
- Backend API Gateway resources are not synced in this version. API Gateway release version is updated to `3.0.1-alpha.65`.
- This version does not introduce new component prerequisites for Agent, Plugin, or Package rollout.
