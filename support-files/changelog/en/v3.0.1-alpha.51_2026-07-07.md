## [Version: v3.0.1-alpha.51] - 2026-07-07

Full Changelog: [v3.0.1-alpha.50...v3.0.1-alpha.51](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.50...v3.0.1-alpha.51)

**Release scope**

- Agent: Agent, Plugin, and Package formats remain compatible.
- Backend/Control Plane: Relay proxy installation now supports SSH-only deployment scenarios.
- Frontend: Tab-heavy pages display tab units more reliably.
- Installer/Deployment: Helm chart, service image, API Gateway sync image, and mock-server image align to v3.0.1-alpha.51.

**New features**

- Relay proxy installation now supports SSH-only deployment, covering environments where proxy setup relies on SSH access only.

**Improvements**

- Helm release dependencies now use the bitnamilegacy source for chart dependency compatibility.
- The common chart version is locked to 2.31.4 for consistent deployment packaging.
- Shared retry backoff calculation is reused across retry flows, keeping retry timing behavior consistent.

**Bug fixes**

- Fixes tab display when a page contains too many tab units.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This release does not change the minimum Agent or Plugin runtime version requirements.

**Component dependencies and upgrade prerequisites**

- Upgrade deployment assets with the v3.0.1-alpha.51 Helm chart, service image, API Gateway sync image, and mock-server image.
- Backend swagger files do not change in this release, so API Gateway resources are not synced and API Gateway release metadata remains unchanged.
