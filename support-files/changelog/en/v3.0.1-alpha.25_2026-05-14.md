## [Version: v3.0.1-alpha.25] - 2026-05-14

Full Changelog: [v3.0.1-alpha.24...v3.0.1-alpha.25](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.24...v3.0.1-alpha.25)

**Release Scope**

- Agent: No functional changes.
- Proxy: No functional changes.
- Plugin: No functional changes.
- Package: No standalone package format or protocol field changes.
- Backend/Control Plane: Optimized execution performance in the post-process list path and host sync update path.
- Installer/Deployment: No installer parameter or deployment flow changes.

**Optimizations**

- Optimized query and storage-access paths for Backend workflow post-process list operations, reducing unnecessary data handling overhead in frequent list scenarios.
- Optimized host update logic in the `sync_host` path, reducing processing pressure during full or batch synchronization.

**Bug Fixes**

- This release does not introduce standalone user-visible bug fix items, it mainly delivers performance and execution-efficiency improvements.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package compatibility stays aligned with `v3.0.1-alpha.24`, with no new protocol compatibility requirements in this release.
- The optimizations are scoped to internal Backend workflow/storage and host DAO paths, so no extra Agent or Plugin side version adaptation is required.

**Component Dependencies and Upgrade Prerequisites**

- Upgrade Backend/Control Plane components together to keep workflow and host sync paths running on the same versioned code.
- If production has high-frequency post-process list queries or large-scale host sync workloads, run a grey rollout first and validate query and sync latency metrics before full rollout.
