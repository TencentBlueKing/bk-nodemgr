## [Version: v3.0.1-alpha.60] - 2026-07-28

Full Changelog: [v3.0.1-alpha.59...v3.0.1-alpha.60](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.59...v3.0.1-alpha.60)

**Release scope**

- Agent: Agent, Plugin, and Package formats remain compatible.
- Backend/Control Plane: Windows SSH P-Agent detection, Mongo fuzzy query escaping, and CMDB host pagination sort stability are improved.
- Frontend: Node history log, Proxy installation page initialization request orchestration, and plugin process control-unit display are improved.
- Installer/Deployment: Deployment assets should use v3.0.1-alpha.60.
- CI/Developer Experience: fork PR checkout security rules and testsuite support skill guidance are updated.

**New features**

- Added the relay Windows SSH P-Agent detect-info flow, supporting detection information collection before installing P-Agent through Windows SSH.

**Improvements**

- Frontend initialization orchestration is optimized for node history log, install Proxy, and reinstall Proxy pages, reducing serial request waiting.
- The plugin process page now includes control-unit names, avoiding missing control-unit information in related filters or side-slider content.
- The testsuite support skill now documents package-level integration-test guidance for Mongo, Redis, and Docker-backed sources.

**Bug fixes**

- Mongo fuzzy query values are escaped as regex literals, preventing regex metacharacters in user input from changing query semantics.
- CMDB host pagination sort query parameters are stabilized, improving compatibility for paginated sorting scenarios.
- GitHub Actions checkout flows for fork PRs now use stricter safety guards, reducing the risk of running untrusted code directly in CI.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- Windows SSH P-Agent detection is an installation-flow extension and does not change existing Agent, Plugin, or Package format contracts.

**Component dependencies and upgrade prerequisites**

- Upgrade deployment assets with v3.0.1-alpha.60.
- This version does not sync Backend API Gateway resources; API Gateway release metadata remains `2.18.1 / v3.0.1-alpha.56`.
- Fork PR workflows will follow the updated checkout guard behavior after the CI workflow security changes.
