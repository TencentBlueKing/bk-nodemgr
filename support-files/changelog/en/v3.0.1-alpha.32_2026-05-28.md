## [Version: v3.0.1-alpha.32] - 2026-05-28

Full Changelog: [v3.0.1-alpha.31...v3.0.1-alpha.32](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.31...v3.0.1-alpha.32)

**Release Scope**

- Agent: This version does not change Agent behavior.
- Plugin: Added stop plugin v2 operation support and plugin v2 migration support, improved plugin v2 compatibility install flow, and added default-version fallback for process-not-running paths.
- Package: This version does not change Agent / Plugin / Package formats.
- Backend/Control Plane: Added stop plugin v2 and migrate plugin from v2 branch actions, filtered dedicated relay callback proxies, and improved installer polling plus restart verification stability.
- API / Gateway: Added `POST /api/v3/plugin/migrate_from_v2` and synced API Gateway resource definitions.
- Frontend: Added stop plugin v2 task type text and display in task history.
- Installer/Deployment: Helm chart, appVersion, and image tags are aligned to v3.0.1-alpha.32.

**New Features**

- Added stop plugin v2 operation, which creates stop tasks for v2 plugins and runs them through the unified workflow chain.
- Added plugin v2 migration API to migrate plugin v2 processes on specified hosts into the new plugin workflow chain.
- Added compensation action for process-not-running paths to fall back to default version and finish flow convergence.
- Added stop plugin v2 task type display in task history for clearer task identification and tracking.

**Optimizations**

- Optimized plugin v2 compatibility install flow so only deployment items with compatibility mode enabled enter that install path.
- Optimized relay callback proxy selection by filtering dedicated relay proxies to avoid invalid follow-up execution.
- Improved installer polling and restart verification across node install/upgrade/reconfigure related workflow actions.

**Bug Fixes**

- Fixed flow convergence in compatibility install scenarios to reduce instability risk from unnecessary follow-up action execution.
- Fixed version fallback handling in fetch v2 process actions when process runtime is not alive.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- The plugin v2 compatibility install path keeps existing API and parameter semantics, with stop plugin v2 and migrate plugin from v2 added as incremental operation types.

**Component Dependencies and Upgrade Prerequisites**

- This version does not introduce additional external component dependencies.
