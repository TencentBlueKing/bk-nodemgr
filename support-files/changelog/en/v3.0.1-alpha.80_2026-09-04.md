## [Version: v3.0.1-alpha.80] - 2026-09-04

Full Changelog: [v3.0.1-alpha.79...v3.0.1-alpha.80](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.79...v3.0.1-alpha.80)

**Release scope**

- Agent: Agent / Proxy package formats remain compatible.
- Plugin: Plugin install flows support bind address allocation and project plugin remote config sources.
- Package: Package plugin export APIs and export result query capabilities are updated.
- Backend/Control Plane: Backend updates Plugin Workflow API documentation and Package Export API Gateway resources, with improved redsync and GSE API logging behavior.
- Installer/Deployment: Helm versions, API Gateway release metadata, API Gateway resources, and image versions are aligned to v3.0.1-alpha.80.

**New features**

- Added Backend plugin package export APIs with export workflow result query and temporary download URL support.
- Added bind address allocation support for Plugin install flows.
- Added project plugin remote config source support for deploy policies.
- Added batch editing for install methods in the installation table.

**Improvements**

- Refined the plugin operate dialog, install method batch editing, and IP selector parsing experience.
- Updated Plugin Workflow API documentation with pagination rules, deploy policy fields, and plugin workflow type descriptions.
- Improved GSE API call logging for easier troubleshooting.

**Bug fixes**

- Fixed redsync auto-extension handling.

**Agent / Plugin / Package compatibility**

- Agent / Proxy package versions are aligned with the system version v3.0.1-alpha.80.
- Plugin and Package package formats remain compatible.

**Component dependencies and upgrade prerequisites**

- API Gateway release version / comment are aligned to `3.0.1-alpha.80`.
- API Gateway resources sync the Package Export Result response field from `error_message` to `is_finish`.
- Helm chart version, appVersion, server image tag, apigw-sync image tag, and mock-server image tag are aligned to `v3.0.1-alpha.80`.
- This version does not introduce additional component dependencies.
