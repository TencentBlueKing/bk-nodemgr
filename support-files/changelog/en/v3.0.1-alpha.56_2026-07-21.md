## [Version: v3.0.1-alpha.56] - 2026-07-21

Full Changelog: [v3.0.1-alpha.55...v3.0.1-alpha.56](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.55...v3.0.1-alpha.56)

**Release scope**

- Agent: Agent, Plugin, and Package formats remain compatible; offline Plugin upgrade gains an additional path that does not require callback or download URLs.
- Backend/Control Plane: Host synchronization supports creating multiple hosts from CMDB sync, Plugin upgrade flow handles offline packages, SyncData retry backoff is spread over time, and ORM slow-query logs include filter details.
- Frontend: Frontend pages fix record, deploy target, and topology selector issues.
- Documentation: API and migration documentation expands Package, PluginWorkflow, Process, NodeConstant, Cipher, and Plugin v2-to-v3 migration content.
- Installer/Deployment: Helm chart, service image, API Gateway sync image, and mock-server image align to v3.0.1-alpha.56.

**New features**

- CMDB synchronization supports creating multiple hosts in one flow.
- Offline Plugin upgrade supports packages without callback or download URLs, preserving the existing online upgrade path.

**Improvements**

- SyncData retries use staggered backoff to reduce retry bursts.
- ORM slow-query logging records query filters, improving troubleshooting context for slow MongoDB operations.
- Package, PluginWorkflow, Process, NodeConstant, Cipher, and Plugin migration documentation is expanded for API users and upgrade operators.

**Bug fixes**

- Disabled preordered Plugin conditions are evaluated correctly.
- Frontend record, deploy target, and topology selector interactions are corrected.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- Offline Plugin upgrade is an additional supported path and does not change the existing package format contract.

**Component dependencies and upgrade prerequisites**

- Upgrade deployment assets with the v3.0.1-alpha.56 Helm chart, service image, API Gateway sync image, and mock-server image.
- This version does not sync Backend API Gateway resources; API Gateway release metadata remains `2.17.1 / v3.0.1-alpha.52`.
