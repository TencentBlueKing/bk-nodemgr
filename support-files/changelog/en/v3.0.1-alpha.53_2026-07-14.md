## [Version: v3.0.1-alpha.53] - 2026-07-14

Full Changelog: [v3.0.1-alpha.52...v3.0.1-alpha.53](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.52...v3.0.1-alpha.53)

**Release scope**

- Agent: Agent, Plugin, and Package formats remain compatible; default version prompts now appear only for running processes to avoid misleading non-running states.
- Backend/Control Plane: Host topology filtering, host sync writes, and host list distinct query performance are improved.
- Frontend: Plugin process side slider non-default version prompts are scoped to running processes.
- Installer/Deployment: Helm chart, service image, API Gateway sync image, and mock-server image align to v3.0.1-alpha.53; service images now build frontend assets through Docker multi-stage builds.

**New features**

- Service image builds now generate frontend static assets inside Docker multi-stage builds, reducing reliance on locally prebuilt `dist` artifacts.

**Improvements**

- Host distinct queries are collapsed into one MongoDB aggregate to reduce query count for multi-field filtering.
- Host sync writes use unordered bulk writes and a smaller sync batch size for more stable sync execution.
- MongoDB write concern changes to `w:1` to reduce replication acknowledgment latency for reconciled sync operations.
- Plugin process non-default version prompts now appear only in running state, avoiding misleading prompts for stopped or abnormal processes.

**Bug fixes**

- Fixes empty host topology filter values being included in queries and producing invalid filter conditions.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This version does not change Agent / Plugin / Package protocols or package formats.

**Component dependencies and upgrade prerequisites**

- Upgrade deployment assets with the v3.0.1-alpha.53 Helm chart, service image, API Gateway sync image, and mock-server image.
- This version does not sync API Gateway resources; API Gateway release metadata remains `2.17.1 / v3.0.1-alpha.52`.
