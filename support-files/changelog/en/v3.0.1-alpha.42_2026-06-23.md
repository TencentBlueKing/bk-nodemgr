## [Version: v3.0.1-alpha.42] - 2026-06-23

Full Changelog: [v3.0.1-alpha.41...v3.0.1-alpha.42](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.41...v3.0.1-alpha.42)

**Release scope**

- Agent: Adds Linux default deployment constants and zone fields used by node deployment configuration.
- Backend/Control Plane: Improves proxy installation strategy labels, Proxy status visibility, and package/plugin operation feedback.
- Frontend: Optimizes IP selection, business selection shortcuts, business select-all behavior, and package/plugin execution result displays.
- Installer/Deployment: Aligns Helm chart and image versions to this release.

**New features**

- Adds Linux default deployment constants and zone metadata support for node deployment scenarios.

**Improvements**

- Optimizes the IP selector and adds Enter shortcut support for filtered business selection.
- Adds select-all support for business selection and restores the Agent/Proxy restart confirmation modal.
- Adds Proxy status data statistics to improve Proxy status visibility.
- Displays plugin package scenarios and dispatch errors more clearly during package and plugin operations.

**Bug fixes**

- Fixes proxy installation strategy labels to make install strategy choices easier to identify.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This release does not change the minimum Agent or Plugin runtime version requirements.

**Component dependencies and upgrade prerequisites**

- This release does not introduce new external component dependencies.
- API Gateway resource metadata remains unchanged because this release does not change backend gateway resources.
