## [Version: v3.0.1-alpha.52] - 2026-07-13

Full Changelog: [v3.0.1-alpha.51...v3.0.1-alpha.52](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.51...v3.0.1-alpha.52)

**Release scope**

- Agent: Agent, Plugin, and Package formats remain compatible; Agent / Proxy install requests now support explicit install method selection.
- Backend/Control Plane: Static topology relation recording, control unit validation, custom policy restrictions, and host list query performance are improved.
- Frontend: Jump links, operation prompts, topology pages, and custom deployment fields are refined.
- Installer/Deployment: Helm chart, service image, API Gateway sync image, and mock-server image align to v3.0.1-alpha.52, with API Gateway resources synced.

**New features**

- Agent / Proxy install requests add optional `install_method`, allowing callers to explicitly select `ssh` or `wmi` where applicable for Windows Agent scenarios while preserving automatic selection when omitted.
- Windows Agent installation adds an auto-detect action to reduce manual install method decisions.
- Admin unassigned control unit sync operations and static topology relation recording are added for topology and host relation management.
- Frontend pages add jump links, operation prompts, custom deployment fields, and topology views for clearer node management workflows.

**Improvements**

- Host list query indexes and host field update flows are optimized for large host lists.
- Installer target information collection and diagnostic logs are enhanced for install troubleshooting.
- Helm dependencies and deployment assets continue to align with the Bitnami dependency source for consistent deployment packaging.
- Process side slider prompts for non-default versions are clearer, and control unit plus custom policy validation is stricter.

**Bug fixes**

- Fixes incomplete callpoint coverage for Installer target information collection.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- `install_method` is optional; default or empty values preserve the existing automatic install method selection and remain compatible with existing callers.

**Component dependencies and upgrade prerequisites**

- Upgrade deployment assets with the v3.0.1-alpha.52 Helm chart, service image, API Gateway sync image, and mock-server image.
- This release syncs the `node_agent` / `node_proxy` install request schemas to API Gateway resources and updates API Gateway release metadata to `2.17.1 / v3.0.1-alpha.52`.
