## [Version: v3.0.1-alpha.43] - 2026-06-23

Full Changelog: [v3.0.1-alpha.42...v3.0.1-alpha.43](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.42...v3.0.1-alpha.43)

**Release scope**

- Agent: Improves Proxy self-relay preflight checks and unifies SSH installation workflow actions.
- Backend/Control Plane: Adds Plugin policy configuration support, protects NetworkUnit deletion, and improves host topology synchronization.
- Frontend: Optimizes cross-page selection, table sorting, and node operation preview workflows.
- File Service: Adds temporary file garbage collection.
- Installer/Deployment: Aligns Helm chart and image versions to this release and fixes Helm chart job errors.

**New features**

- Adds Plugin policy configuration support.
- Adds temporary file garbage collection in the File Service.
- Adds Proxy self-relay preflight checks before Proxy operations.
- Adds NetworkUnit deletion protection.

**Improvements**

- Optimizes cross-page select-all behavior and table sorting in frontend tables.
- Unifies Proxy SSH installation workflow actions for a more consistent deployment flow.

**Bug fixes**

- Fixes Helm chart job errors.
- Fixes host topology synchronization so set and module relations retain `set_id` and `module_id`.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This release does not change the minimum Agent or Plugin runtime version requirements.

**Component dependencies and upgrade prerequisites**

- This release does not introduce new external component dependencies.
- API Gateway resource metadata remains unchanged because this release does not update backend gateway resources.
