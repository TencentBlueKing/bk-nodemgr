## [Version: v3.0.1-alpha.29] - 2026-05-22

Full Changelog: [v3.0.1-alpha.28...v3.0.1-alpha.29](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.28...v3.0.1-alpha.29)

**Release Scope**

- Agent: Added install request schema fields to control whether critical runtime files are preserved.
- Proxy: Added install request schema fields to control whether critical runtime files are preserved.
- Plugin: Added Plugin V2 workflow/action support across V2 operation paths such as install, uninstall, restart, and stop.
- Package: No known Package format breaking changes.
- Backend/Control Plane: Added handling for missing agentid in host sync events, and aligned process command tags with config table semantics.
- API / Gateway: Synced renew_gse_task and renew_gse_proc request schema fields for preserving critical runtime files.
- Installer/Deployment: Improved node installer script rendering and reuse flow, and preserved runtime files to improve install and uninstall stability.

**New Features**

- Expanded Plugin V2 workflow/actions coverage for more V2 operation scenarios, delivered as additive capability.
- Added node deployment controls for preserving critical runtime files, exposed in node agent/proxy install schemas.

**Optimizations**

- Improved node installer script rendering and reuse path, with runtime file preservation to reduce regeneration overhead and runtime interruption risk.
- Optimized install table and related front-end display behavior to reduce performance lag and improve display consistency.
- Removed obsolete APIGW front setting to reduce stale configuration impact.

**Bug Fixes**

- Fixed host sync handling when agentid is missing, reducing sync failure risk.
- Fixed behavior drift caused by process command tag and config table misalignment.

**Agent / Plugin / Package compatibility**

- Based on current release evidence, no Agent, Plugin, or Package format breaking change is identified.
- Plugin V2 workflow support is additive, existing flows remain usable.

**Component Dependencies and Upgrade Prerequisites**

- Runtime file preservation changes installer behavior paths, while current evidence does not show extra component dependency requirements.
- API / Gateway schemas are synced for renew_gse_task and renew_gse_proc fields, callers should align request payloads with the critical-runtime-file preservation semantics.
