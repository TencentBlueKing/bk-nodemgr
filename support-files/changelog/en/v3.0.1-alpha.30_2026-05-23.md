## [Version: v3.0.1-alpha.30] - 2026-05-23

Full Changelog: [v3.0.1-alpha.29...v3.0.1-alpha.30](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.29...v3.0.1-alpha.30)

**Release Scope**

- Agent: This version does not change the Agent package format.
- Proxy: Completed API Gateway resource schema fields for preserving runtime files in proxy install requests.
- Plugin: This version does not change the Plugin package format.
- Package: This version does not change the Package format.
- Backend/Control Plane: Corrected the process name used by the try stop process flow to avoid mismatched stop actions.
- API / Gateway: Added renew_gse_task and renew_gse_proc fields to the NodeProxyInstallHost request schema in gateway resources, and aligned the gateway release comment.
- Installer/Deployment: Aligned Helm chart version, appVersion, and image tags to v3.0.1-alpha.30.

**New Features**

- This version does not include new features.

**Optimizations**

- Completed Proxy install request runtime-file-preservation fields in API Gateway resources to keep swagger and gateway resources consistent.

**Bug Fixes**

- Corrected the process name used by the try stop process flow, reducing the risk of process stop action mismatches.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- renew_gse_task and renew_gse_proc are gateway-resource sync completions for existing request schema fields and do not change request semantics.

**Component Dependencies and Upgrade Prerequisites**

- This version does not introduce additional component dependencies.
- For Helm deployment, bk-nodemgr and mock-server image tags should align with v3.0.1-alpha.30.
