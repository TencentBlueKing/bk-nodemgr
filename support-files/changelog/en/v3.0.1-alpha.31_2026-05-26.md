## [Version: v3.0.1-alpha.31] - 2026-05-26

Full Changelog: [v3.0.1-alpha.30...v3.0.1-alpha.31](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.30...v3.0.1-alpha.31)

**Release Scope**

- Agent: Added quick search by host ID for easier fault locating.
- Proxy: Added Proxy tag based host filtering in install strategy to improve policy setup and execution paths.
- Plugin: Improved relay selection logic for plugin installation and enhanced compatibility path for v2 plugin install flow.
- Package: This version does not change Agent / Plugin / Package formats.
- Backend/Control Plane: Improved scheduled workflow trigger sync and concurrency handling, and removed process v2 storage tables with related flow dependencies.
- API / Gateway: Updated host distribution query related fields and docs, with aligned API definitions and swagger outputs.
- Installer/Deployment: Aligned Helm chart version, appVersion, and image tags to v3.0.1-alpha.31.

**New Features**

- Added quick search by host ID.
- Added host query and install strategy filtering by Proxy tag.

**Optimizations**

- Improved Proxy install strategy display details and side-slider interactions.
- Improved relay selection logic in plugin installation paths to stabilize installation flow.
- Improved scheduled workflow trigger sync and concurrency handling paths.

**Bug Fixes**

- Adjusted v2 plugin compatibility-mode trigger logic to reduce installation failure risk in legacy compatibility scenarios.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- process v2 storage capability is removed, and related flows are switched to existing plugin install and config handling paths.

**Component Dependencies and Upgrade Prerequisites**

- This version does not introduce additional external component dependencies.
- For Helm deployment, chart versions, appVersion, and image tags of bk-nodemgr and mock-server should align with v3.0.1-alpha.31.
