## [Version: v3.0.1-alpha.44] - 2026-06-25

Full Changelog: [v3.0.1-alpha.43...v3.0.1-alpha.44](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.43...v3.0.1-alpha.44)

**Release scope**

- Agent: Adds a Windows SSH pre-install detection action and fixes Proxy install mode selection.
- Plugin: Supports custom deployment specs in plugin install flows, allowing per-task resource and monitor policy overrides.
- Backend/Control Plane: Syncs protocol, storage, and workflow rendering paths for plugin custom deployment specs.
- API / Gateway: Syncs Agent / Proxy install request schemas and Plugin install custom spec schemas to API Gateway resources.
- Frontend: Generates request IDs with UUIDs in request interceptors for more consistent request tracing.
- Installer/Deployment: Aligns Helm charts, service images, mock-server image, and apigw-sync metadata to this release version.

**New features**

- Plugin install supports `custom_spec` for per-install resource limits and process monitor policies.
- Windows SSH install flow adds host detection before installation.

**Improvements**

- Frontend request IDs are generated as UUIDs to improve cross-service request tracing.
- API Gateway resources are updated for the install request schema changes published in this release.

**Bug fixes**

- Fixes Proxy install mode selection so specific install scenarios use the correct install path.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This release does not change the minimum Agent or Plugin runtime version requirements.
- Plugin custom deployment specs are optional per-request fields and do not affect existing plugin install requests that omit `custom_spec`.

**Component dependencies and upgrade prerequisites**

- This release does not introduce new external component dependencies.
- Backend gateway resources are updated in this release, and API Gateway release metadata is aligned to `2.15.1`.
