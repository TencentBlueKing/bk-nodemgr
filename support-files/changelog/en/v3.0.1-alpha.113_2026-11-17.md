## [Version: v3.0.1-alpha.113] - 2026-11-17

Full Changelog: [v3.0.1-alpha.112...v3.0.1-alpha.113](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.112...v3.0.1-alpha.113)

> Important notes

- Application's `/wiki/` documentation route is accessible without login, regardless of the Backend Wiki link mode. Do not place sensitive information in the product Wiki. Documents are returned as raw Markdown without HTML rendering.

**Release scope**

- Backend/Control Plane: Main-config delivery fix for V3 plugin deploy policies.
- Application/Frontend: Application serves the embedded bilingual product user Wiki.
- Installer/Deployment: New Application Wiki link mode and access-entry configuration, plus an API Gateway topology MCP category update.

**New features**

- The product user Wiki can now be served locally by Application under `/wiki/`. Environments without GitHub access can switch guide links in task logs to Application and read the documentation shipped with the product without external network access.

**Improvements**

- The read-only topology query MCP service `topo` in API Gateway is now listed in the `Official` category.

**Bug fixes**

- Fixes V3 plugin deploy policies not redelivering main configs when only the custom configuration rendering context changes and the plugin version stays the same. Policy execution now re-renders and delivers the affected main configs and reloads the process without upgrading the plugin package. Check workflow records for execution results.

**Agent / Plugin / Package compatibility**

- This release does not change Agent, Plugin, or Package formats.
- Existing business API paths and request/response structures are unchanged.

**Component dependencies and upgrade prerequisites**

- Wiki links still default to `github` mode, so existing deployments can upgrade without extra configuration.
- To enable Application link mode, set `backend.config.wiki.mode=application` in Helm values and set `backend.config.wiki.application.prefixURL` to an absolute HTTP(S) documentation URL prefix accessible to users, such as `https://nodemgr.example.com/wiki/`. Ensure that the access entry forwards `/wiki/` to the Application service from this release; do not use a cluster-internal service address for user-facing links.
