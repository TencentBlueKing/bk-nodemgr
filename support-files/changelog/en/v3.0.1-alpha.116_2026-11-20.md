## [Version: v3.0.1-alpha.116] - 2026-11-20

Full Changelog: [v3.0.1-alpha.115...v3.0.1-alpha.116](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.115...v3.0.1-alpha.116)

> Important notes

- Application Excel APIs introduce a breaking change: `GET /api/v3/node/{agent,proxy}/install_template/download` and `POST /api/v3/node/{agent,proxy}/install_template/upload` are removed in favor of `POST /api/v3/excel/{agent_install_template,proxy_install_template,ops_template}/{parse,download}`. Upgrade Application and Frontend together, and migrate integrations that call the old APIs.
- The embedded Application Wiki is now disabled by default. Deployments relying on this endpoint must explicitly set `application.config.wiki.enabled=true` (or `wiki.enabled=true` in direct Application configuration) and keep `/wiki/` accessible to users. This switch does not automatically change Backend's documentation link mode; `github` mode is unaffected.
- IAM V3 Helm synchronization adds `iamV3.option.allowActionReplace`, defaulting to `false`. Setting it to `true` allows policy cleanup and deletion/recreation of Actions with changed resource bindings. Existing authorizations are not migrated automatically. Policy deletion is irreversible; disabling the switch or rolling back the Chart cannot restore deleted policies.

**Release scope**

- Backend/Control Plane: Backend client host-list pagination fix.
- Application/Frontend: Unified Excel template APIs, Excel import for out-of-band settings, an embedded Wiki switch, and an Excel processing dependency update.
- Installer/Deployment: Windows SSH Installer path fix and IAM V3 Helm synchronization parameter wiring.

**New features**

- Adds unified Excel template download and parsing APIs for Agent installation, Proxy installation, and out-of-band settings. Parsing returns results and error messages per row; a failed row does not block other rows.
- The out-of-band settings page supports Excel import, matching existing hosts by business, Network Area, and internal IP and filling successful rows into the page's table. Import does not save settings directly; submission on the page is still required.

**Improvements**

- Upgrades the Excel processing dependency `excelize` to `v2.11.1`.

**Bug fixes**

- Fixes the Windows SSH Installer working directory not being consistently converted to a slash-separated path.
- Fixes Backend client host-list queries not being paginated in batches within the API limit.
- Fixes the Helm IAM V3 model synchronization Job not passing the Action replacement parameter. When explicitly enabled, install/upgrade Jobs pass `--allow-action-replace`, reusing the migration script's existing capability.

**Agent / Plugin / Package compatibility**

- This release does not change Agent, Plugin, or Package formats. The Windows change only affects SSH Installer working-directory path handling.
- Excel parsing results now use `data.items` instead of the old installation templates' `data.info`; each row includes `row_index` and `error_message`. The new templates use the first three rows for headers, required-field markers, and instructions, with data starting at row 4. Downloading fresh templates after upgrading is recommended.

**Component dependencies and upgrade prerequisites**

- If Backend uses `application` documentation link mode, explicitly enable the Application Wiki before upgrading. Ensure the external entrypoint forwards `/wiki/` to Application and `prefixURL` points to a user-accessible documentation address. Adjust Backend's link configuration separately before disabling the Wiki.
- The IAM V3 replacement switch applies to every `upsert_action` with changed resource bindings in the full-directory synchronization, not just one Action. Before enabling it, confirm the target system, tenant, and all binding changes, and use a server image whose script supports `--allow-action-replace`. Policy deletion requires IAM SaaS ≥ 1.4.15 and backend ≥ 1.7.7. Reconfigure and verify affected permissions afterward, then reset the switch to `false`. See the [IAM V3 migration tool](https://github.com/TencentBlueKing/bk-nodemgr/blob/v3.0.1-alpha.116/support-files/bkiamv3/README.md#显式替换-action-资源绑定) for detailed limits and failure recovery.
