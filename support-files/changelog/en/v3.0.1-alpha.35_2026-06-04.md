## [Version: v3.0.1-alpha.35] - 2026-06-04

Full Changelog: [v3.0.1-alpha.34...v3.0.1-alpha.35](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.34...v3.0.1-alpha.35)

> Important notice
- This release reduces the configurable surface of the Relay plugin. Before upgrading, check whether your environment depends on the removed Tracing, CallbackServer, DownloadServer, service address, or authentication custom fields. These custom fields are no longer rendered as Relay configuration entry points after the upgrade.

**Release scope**

- Agent: This release does not change Agent runtime behavior.
- Plugin: Adjusts the Relay plugin configuration definition and template, reducing configurable fields and fixing part of the service bind, authentication, and tracing behavior.
- Package: This release does not change Agent / Plugin / Package formats.
- Backend/Control Plane: Adds deployment configuration for Proxy file cache directories and renders the file topology Proxy group tag by network unit.
- API / Gateway: This release does not change external API contracts, Swagger files, or API Gateway resource definitions.
- Frontend: This release does not change frontend pages.
- Installer/Deployment: Helm values add the `proxyFileCacheDir` entry for the default file cache directory on Linux Proxy nodes.

**New features**

- Proxy nodes now support a deployment-level file cache directory, which is rendered as the default `file.cache.dirs` value when no custom configuration policy matches.
- File topology now renders a Proxy group tag by network unit, limiting file transfer scope to machines in the same network unit.

**Optimizations**

- The Relay plugin configuration is reduced to the minimum release-facing set. CallbackServer and DownloadServer now use node dynamic ports and Advertise IP, while InfoServer and AdminServer keep local binding.
- Relay configuration templates now render port and log count fields as integers to reduce configuration type ambiguity.
- The plugin package build guide is aligned with the Relay configuration definition so the documentation example matches the actual plugin definition.

**Bug fixes**

- Fixed the risk of concurrent writes to the same node deployment configuration object by rendering logic settings and custom settings sequentially.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- After upgrading the Relay plugin, plugin custom configuration no longer supports overriding Tracing, CallbackServer, DownloadServer, or the reduced service address and authentication fields.

**Component dependencies and upgrade prerequisites**

- This release does not introduce new external component dependencies.
- To enable the default Proxy file cache directory, set `proxyFileCacheDir` in deployment configuration or Helm values and validate it through a staged rollout.
