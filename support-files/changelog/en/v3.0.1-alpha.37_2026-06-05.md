## [Version: v3.0.1-alpha.37] - 2026-06-05

Full Changelog: [v3.0.1-alpha.36...v3.0.1-alpha.37](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.36...v3.0.1-alpha.37)

**Release scope**

- Agent: This release does not change Agent runtime behavior.
- Plugin: This release does not change Plugin configuration or runtime behavior.
- Package: This release does not change Agent / Plugin / Package formats.
- Backend/Control Plane: Fixes node deployment info rendering so Proxy-specific ports are rendered only for Proxy nodes.
- API / Gateway: This release does not change external API contracts, Swagger files, or API Gateway resource definitions.
- Frontend: This release does not change frontend pages.
- Installer/Deployment: This release does not change deployment parameters.

**Bug fixes**

- Fixed regular Agent node deployment info rendering so it no longer reads Proxy-specific ports, preventing non-Proxy node deployment from being interrupted when Proxy port presets are absent.
- Proxy node rendering now returns clearer errors when Proxy cluster, data, or file port values can't be parsed, making configuration issues easier to locate.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This release only adjusts Backend/Control Plane node deployment info rendering and does not change the Agent, Plugin, or Package version compatibility range.

**Component dependencies and upgrade prerequisites**

- This release does not introduce new external component dependencies.
- After upgrading, check deployment flows for newly installed or reinstalled nodes. Proxy port configuration applies only to Proxy nodes.
