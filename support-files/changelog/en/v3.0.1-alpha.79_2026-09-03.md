## [Version: v3.0.1-alpha.79] - 2026-09-03

Full Changelog: [v3.0.1-alpha.78...v3.0.1-alpha.79](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.78...v3.0.1-alpha.79)

**Release scope**

- Agent: Agent / Proxy package formats remain compatible, with improved Windows Agent SSH install method support.
- Plugin: Deploy policy custom plugin config context handling is more stable, and Plugin / Package package formats remain compatible.
- Package: Package adds export file APIs and export storage flow.
- Backend/Control Plane: Backend adds Package export capabilities, supports bklogin redirect for first Application Web login, and fixes install method auto values and plugin install package parameter passing.
- Installer/Deployment: Helm versions, API Gateway release metadata, and image versions are aligned to v3.0.1-alpha.79.

**New features**

- Added Plugin Package export file APIs with export file flow and storage support.
- Added compact expiring token generation for temporary export access scenarios.
- Added Application Web redirect to bklogin for unauthenticated first access, carrying `app_code` and the current page `c_url`.

**Improvements**

- Simplified init package configuration.
- Exposed tenant mode to the frontend and adjusted plugin package quick filtering.
- Installation tables now fill default ports when CMDB sync data is replaced without changing the row count.
- Changed the node history log sub-workflow display name to task sequence labels for easier troubleshooting.
- Made deploy policy sub config template decisions and custom config context handling more consistent.

**Bug fixes**

- Fixed Windows Agent SSH install method support.
- Fixed install method auto values and plugin install package parameter passing.

**Agent / Plugin / Package compatibility**

- Agent / Proxy package versions are aligned with the system version v3.0.1-alpha.79.
- Plugin and Package package formats remain compatible.

**Component dependencies and upgrade prerequisites**

- API Gateway release version / comment are aligned to `3.0.1-alpha.79`.
- When `application.config.bkSaaS.bkLogin.loginURL` is configured, unauthenticated Application Web access redirects to bklogin and returns to the original page after login.
- This version does not include Backend API Gateway resources sync.
- Helm chart version, appVersion, server image tag, apigw-sync image tag, and mock-server image tag are aligned to `v3.0.1-alpha.79`.
- This version does not introduce additional component dependencies.
