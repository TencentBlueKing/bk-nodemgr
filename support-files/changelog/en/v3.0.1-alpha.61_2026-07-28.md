## [Version: v3.0.1-alpha.61] - 2026-07-28

Full Changelog: [v3.0.1-alpha.60...v3.0.1-alpha.61](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.60...v3.0.1-alpha.61)

**Release scope**

- Agent: Agent, Plugin, and Package formats remain compatible.
- Backend/Control Plane: Host exact-IP query conditions, proxy unit assignment, host ScanAll index performance, and Agent version diagnostic log safety are improved.
- API Gateway: Backend topo host exact-condition request schema is synced to API Gateway release `2.18.2`, and APIGW resource descriptions are refreshed.
- API Documentation: Missing APIGW API documentation is supplemented.
- Developer Experience: mise toolchain configuration and ScanAll index documentation are updated.
- Installer/Deployment: Deployment assets should use v3.0.1-alpha.61.

**New features**

- Added exact host IP and IPv6 query conditions for topo host scenarios, allowing callers to filter hosts by exact inner IP values.
- Added proxy tag support to unit assignment so proxy tags are carried through assignment flows.

**Improvements**

- API Gateway documentation now includes the missing API reference pages for NodeAgent, NodeProxy, Sync, and Topo resources.
- API Gateway resource descriptions are synchronized with the latest resource documentation.
- Host ScanAll query indexes are added to improve host list query performance.
- mise toolchain configuration and ScanAll index usage documentation are updated for the current development environment.

**Bug fixes**

- Agent version diagnostic logs are sanitized to avoid exposing unsafe raw diagnostic content.
- Proxy unit assignment now passes the required arguments when assigning proxy units.
- Config policy preview debug logs are removed from the control-plane flow.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- Exact host IP query support changes Backend/API Gateway request schema only and does not change package format contracts.

**Component dependencies and upgrade prerequisites**

- Upgrade deployment assets with v3.0.1-alpha.61.
- Backend API Gateway resources are synced as `2.18.2 / v3.0.1-alpha.61`.
