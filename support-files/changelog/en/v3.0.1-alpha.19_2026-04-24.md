## [Version: v3.0.1-alpha.19] - 2026-04-24

Full Changelog: [v3.0.1-alpha.18...v3.0.1-alpha.19](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.18...v3.0.1-alpha.19)

**Release Scope**

- Backend/Control Plane: Split the plugin workflow routes and added operation-level authorization, adjusted syncdata workflow action timeouts, and added a new index on the operation collection
- Frontend: Improved the JSON viewer on the policy sort preview page, added no-permission placeholders for inaccessible businesses, and a default network area apply entry in topology
- Installer/Deployment: Updated Grafana dashboards for application/backend/file services and aligned Helm ServiceMonitor port configuration

**New Features**

- Unified authorization on plugin workflow `list`, `distinct`, and `operation` routes; narrowed history view scope by business and added business-level permission checks for operate actions

**Optimizations**

- Optimized the JSON detail dialog on the policy sort preview page with line numbers, syntax highlighting, alternating bracket colors, and a wider dialog for better readability
- Optimized no-permission scenarios: node and policy pages now show a no-permission placeholder when the user has no `biz_access` on any business; the biz-selector hides the "All Business" placeholder when no authorized business is available
- Optimized the topology no-permission view by reusing the unified `bk-exception` placeholder component, and now requests the default network area permission to reduce manual selection steps
- Tuned syncdata workflow action timeouts: the `gen_oper_sync_*` family was raised from 10s to 10m and the `sync_*` family from 1m to 5m, reducing timeout failures for large-scale business deployments
- Added a `parent_operation_id` index on the operation collection to speed up queries by parent operation
- Updated Grafana dashboards for application, backend, and file services to the BlueKing monitoring datasource, and aligned the backend/file scrape port in the Helm `ServiceMonitor` template to `info-http` to restore metrics collection

**Agent / Plugin / Package compatibility**

- No Agent / Plugin / Package version range or package format changes

**Component Dependencies and Upgrade Prerequisites**

- Helm chart bumped to `v3.0.1-alpha.19`; update the ServiceMonitor and Grafana datasource configuration alongside the upgrade to restore monitoring dashboards
- Plugin workflow APIs now perform business-scoped IAM checks after the upgrade; ensure relevant users have `plugin_history_view` / `plugin_operate` permission on the target businesses beforehand
