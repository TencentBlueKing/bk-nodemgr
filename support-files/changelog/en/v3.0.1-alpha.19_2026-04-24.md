## [Version: v3.0.1-alpha.19] - 2026-04-24

Full Changelog: [v3.0.1-alpha.18...v3.0.1-alpha.19](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.18...v3.0.1-alpha.19)

**Release Scope**

- Backend/Control Plane: Added authorization coverage for plugin workflow listing and operations, and adjusted syncdata workflow timeout windows
- Frontend: Added no-business-access placeholders, and improved unauthorized business selection and topology permission guidance

**New Features**

- Added authorization checks for plugin workflow operations, covering plugin workflow listing, retry, terminate, and operation history query scenarios
- Added a no-business-access placeholder page and permission application guidance, so users without accessible businesses can directly reach the permission entry

**Optimizations**

- Optimized the default business selector behavior, when all businesses are unauthorized it no longer auto-selects an inaccessible business or shows misleading placeholder text
- Optimized the topology permission request flow by requesting default region view permission, reducing permission blocks when entering topology pages for the first time
- Optimized syncdata workflow timeout windows by raising execution limits for host, Agent state, and alive plugin process sync tasks, reducing timeout failures in large batch sync scenarios

**Bug Fixes**

- Fixed node management and rule management pages continuing to show business-related interactions when the user has no access to any business, reducing misoperations and empty-state confusion after 403 responses
