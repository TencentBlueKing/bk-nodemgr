## [Version: v3.0.1-alpha.40] - 2026-06-17

Full Changelog: [v3.0.1-alpha.39...v3.0.1-alpha.40](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.39...v3.0.1-alpha.40)

**Release scope**

- Agent: Config policy options now include CPU and memory usage limits, script concurrency, data compression, and file transfer settings. Agent ops fields can be synced and batch-updated.
- Plugin: Plugin task history now includes tab subtitles. Plugin runtime behavior and package formats remain compatible.
- Package: Agent / Plugin / Package formats remain compatible.
- Backend/Control Plane: Adds Agent / Proxy batch ops-field update APIs, writing out-of-band management data to the local DB and syncing it back to CMDB. CMDB host sync now initializes ops fields.
- API / Gateway: Syncs proto, Swagger, and API Gateway resources for Agent / Proxy ops-field update APIs.
- Frontend: Task history adds subtitles for Agent, Proxy, and Plugin tabs and normalizes invalid tab parameters. Topology graph network-unit latency tooltips now show machine IP and 1min / 5min / 15min latency.
- Installer/Deployment: Helm adjusts module-level image tag configuration, separates the apigw-sync image configuration, and handles dedicated image pull secrets.

**New features**

- Agent / Proxy hosts can batch-update ops fields through the `update_ops_fields` APIs, including ops console host ID, out-of-band type, out-of-band protocol, BMC IP, and BMC port.
- CMDB host sync initializes ops fields into node dynamic information, avoiding missing out-of-band management data after first sync.
- Config policy adds Agent / Proxy options for CPU usage limit, memory usage limit, script concurrency, data compression, and file task settings.

**Improvements**

- Helm apigw-sync Job now uses the independent `apiManagerImage` configuration, allowing repository, tag, pull policy, and pull secrets to be set separately.
- Helm application, backend, and file module image tag settings now use the `image.tag` structure, aligning them with other image configuration levels.
- Topology graph latency tooltips now include host IP, making it easier to locate the machine behind each 1min / 5min / 15min latency row.
- Task history now displays subtitles for Agent, Proxy, and Plugin tabs, and invalid tab parameters fall back to Agent history.
- The server graceful shutdown document now explains Kubernetes, REST, and Workflow timeout budgets and shutdown semantics by layer.
- The repository adds bk-nodemgr Go coding skills for consistent future development, review, and maintenance.

**Bug fixes**

- Fixed frontend type and tooltip rendering mismatch after topology latency data changed from string arrays to structured data.
- Fixed unstable task history page state when an invalid active tab parameter is provided.
- Improved Workflow long-tail action shutdown handling so retryable and non-retryable paths stay separated.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This release does not change the minimum Agent or Plugin runtime version requirements.
- Newly added config policy options are disabled by default and do not automatically change existing Agent / Proxy runtime parameters after upgrade.

**Component dependencies and upgrade prerequisites**

- This release does not introduce new external component dependencies.
- Helm values `application.imageTag`, `backend.imageTag`, and `file.imageTag` are changed to `application.image.tag`, `backend.image.tag`, and `file.image.tag`. Sync custom values before upgrade.
- Helm apigw-sync image settings are changed from `apigwSync.repository` / `apigwSync.imageTag` to the independent `apiManagerImage` configuration. Sync the configuration path if your environment overrides the apigw-sync image.
