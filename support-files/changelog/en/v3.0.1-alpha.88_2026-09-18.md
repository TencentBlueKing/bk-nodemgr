## [Version: v3.0.1-alpha.88] - 2026-09-18

Full Changelog: [v3.0.1-alpha.87...v3.0.1-alpha.88](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.87...v3.0.1-alpha.88)

**Release scope**

- Frontend: Plugin, Package, node list, topology authorization display, and Plugin no-permission handling adjustments.
- Backend/Control Plane: Deploy Policy target rendering, topology authorization, Package Event filtering, IAM v4 authorization logging, CMDB cloud area deletion handling, and alive process sync checks.
- Installer/Deployment: Optional Grafana, Tempo, and OpenTelemetry Collector Gateway Helm capabilities, plus Helm chart build target and dependency updates.
- Developer docs: Project skill assets migrated to the `.agents/skills` layout, and virtual user cache troubleshooting documentation added.

**New features**

- Added optional Grafana support in the Helm chart for Node Manager self-monitoring scenarios.
- Switched the embedded Tempo and OpenTelemetry Collector Gateway Helm capabilities to official upstream charts.

**Improvements**

- Improved Plugin and Plugin bintool package management pages, including simplified Plugin page interactions and package list display adjustments.
- Improved Plugin page no-permission handling.
- Applied subconfig templates when rendering Deploy Policy targets.
- Updated Agent and Proxy authorization displays to use row-level business context.
- Added a Helm chart build target and aligned bundled Helm chart dependencies for release packaging.

**Bug fixes**

- Fixed CMDB cloud area deletion handling for management-area scenarios.
- Checked Agent state before syncing alive processes to avoid syncing invalid process state.
- Fixed NetworkUnit creation authorization by checking the related area permission.
- Ignored empty Package Event fuzzy conditions to avoid invalid query filters.
- Added IAM v4 authorization body logging for troubleshooting authorization requests.

**Agent / Plugin / Package compatibility**

- This version does not change Agent / Proxy, Plugin, or Package formats.

**Component dependencies and upgrade prerequisites**

- Grafana, Tempo, Prometheus, and OpenTelemetry Collector Gateway are optional Helm capabilities and remain disabled by default.
- This version does not introduce mandatory upgrade prerequisites.
