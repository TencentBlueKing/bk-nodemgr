## [Version: v3.0.1-alpha.50] - 2026-07-03

Full Changelog: [v3.0.1-alpha.49...v3.0.1-alpha.50](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.49...v3.0.1-alpha.50)

**Release scope**

- Agent: Adds Windows SSH node installation workflow support while keeping Agent, Plugin, and Package formats compatible.
- Backend/Control Plane: Adjusts CMDB host business relation backfill logic and adds Windows SSH installation action and operation orchestration.
- Frontend: Fixes interaction issues across installation, plugin, strategy, and proxy pages.
- Documentation/Tooling: Adds version management concept documentation and the bk-nodemgr Go code style skill.
- Installer/Deployment: Aligns Helm charts, service image, API Gateway sync image, and mock-server image to this release version.

**New features**

- Windows SSH node installation now supports profile detection, installer transfer, install script generation, and remote startup through the Windows-compatible SSH client, then continues through the existing installer wait and sync flow.
- Adds version management concept documentation covering version format, iteration rules, tag rules, and scope.
- Adds the bk-nodemgr Go code style skill to capture project-specific Go style and layering constraints.

**Improvements**

- Frontend fixes make installation tables, config templates, operation dialogs, plugin pages, strategy pages, and proxy installation pages more stable in display and interaction feedback.

**Bug fixes**

- Fixes CMDB host business relation backfill by grouping topology relations by host and validating that each host belongs to one business.
- Fixes multiple frontend issues across installation, plugin, strategy, and proxy pages.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This release does not change the minimum Agent or Plugin runtime version requirements.
- Windows SSH installation is added through a new workflow, and existing installation flows remain compatible.

**Component dependencies and upgrade prerequisites**

- This release does not introduce new external component dependencies.
- Backend swagger files are not updated in this release, so API Gateway resources are not synced and API Gateway release metadata remains unchanged.
