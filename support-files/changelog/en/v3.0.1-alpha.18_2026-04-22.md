## [Version: v3.0.1-alpha.18] - 2026-04-22

Full Changelog: [v3.0.1-alpha.17...v3.0.1-alpha.18](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.17...v3.0.1-alpha.18)

**Release Scope**

- Backend/Control Plane: Added batch deployment statistics for release packages, new topology and installation APIs, and completed IAM v3 configuration with broader route-level authorization
- Frontend: Added changelog pages and version log capabilities, improved history filters, permission placeholders, and installation workflow interactions
- Installer/Deployment: Switched installer config retrieval flow, added full-debug command, and bumped Helm charts to v3.0.1-alpha.18

**New Features**

- Added changelog API and release note pages, supporting bilingual changelog retrieval by version
- Added brief release package list APIs and a batch deployment count API for faster package management and release views
- Added topology capabilities, including access point brief APIs, host distribution statistics by node version, networkunit recommendation, and topology path completion
- Added Config Policy preview, sorting, and target IP capabilities, plus authorization checks for plugin workflow and process routes

**Optimizations**

- Optimized the authorization stack by unifying IAM callback handling, converging authorization APIs, and switching more operations to business-scoped and hierarchical path authorization
- Optimized node and task history queries with more filters (IP, node_role) and filter memory support
- Optimized installation and upgrade flows, installer now fetches configs first and supports Windows custom IPC ports, reducing cross-environment installation failures
- Optimized topology and package management interactions, including control unit details, refresh redirect behavior, and no-permission placeholders

**Bug Fixes**

- Fixed frontend issues in business selector, topology graph selection, and hierarchical resource path display in permission dialogs
- Fixed user-visible issues including non-increasing task detail time, stale log detail pages, and 403 refresh blocking subsequent API calls
- Fixed backend issues including networkunit recommendation function call errors, ConfigPolicyId=0 validation handling, and zero-value timestamp normalization
- Fixed zombie process issues for wmic and jinja2 subprocesses, reducing process leakage risk on Windows and renderer paths
