## [Version: v3.0.1-alpha.22] - 2026-04-30

Full Changelog: [v3.0.1-alpha.21...v3.0.1-alpha.22](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.21...v3.0.1-alpha.22)

**Release Scope**

- Backend/Control Plane: Added Agent / Proxy install parameter propagation into the deployment flow, introduced re-registration and pre-ordered plugin installation controls, and optimized workflow sync scheduling, query, and write paths under high load
- Frontend: Added re-registration and pre-ordered plugin installation interactions in install, reinstall, and preview flows, and fixed preview page parameter display errors
- API / Gateway: Added install control parameters to NodeAgentInstall and NodeProxyInstall API docs, swagger, and proto definitions
- Persistence/Workflow: Added `trigger_id + state` related indexes for `oper_inst_data` queries and reduced unchanged host dynamic field writes

**New Features**

- Added `re_register` to Agent and Proxy install APIs, allowing installation requests to explicitly control whether nodes should be re-registered
- Added `install_pre_ordered_plugins` to Agent and Proxy install APIs, allowing installation requests to control whether pre-ordered plugins are installed; the default remains installing pre-ordered plugins

**Optimizations**

- Added re-registration and pre-ordered plugin installation parameter display in frontend install, reinstall, and preview flows to reduce inconsistency between page input and backend execution
- Optimized workflow sync scheduling and clean policy calculation by deriving trigger clean policy from operation timeout, reducing mismatch between fixed cleanup policies and actual task timeout settings
- Batched Agent info / state host dynamic field updates and skipped updates when target fields are unchanged, reducing ineffective MongoDB writes under high load

**Bug Fixes**

- Fixed parameter display errors on Agent / Proxy install preview pages to avoid inaccurate configuration confirmation before installation
- Fixed Agent info action generation issues in workflow sync to improve synchronization stability under high concurrency

**Agent / Plugin / Package compatibility**

- No Agent / Plugin / Package version range or package format changes
- The new install API parameters are optional and keep existing defaults: `install_pre_ordered_plugins` defaults to installing pre-ordered plugins, and `re_register` defaults to no re-registration

**Component Dependencies and Upgrade Prerequisites**

- This release includes proto, swagger, and API Gateway documentation updates; external integrations based on NodeAgentInstall / NodeProxyInstall schemas should update corresponding clients or validation logic
- This release includes coordinated Frontend and Backend/Control Plane changes, a consistent rollout window is recommended for paired upgrades
- This release includes workflow sync and MongoDB query / write path optimizations to reduce database read/write pressure under high-concurrency synchronization workloads
