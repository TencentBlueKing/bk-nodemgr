## [Version: v3.0.1-alpha.45] - 2026-06-25

Full Changelog: [v3.0.1-alpha.44...v3.0.1-alpha.45](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.44...v3.0.1-alpha.45)

**Release scope**

- Agent: Improves control unit assignment and task status refresh behavior for Proxy install preordered plugins.
- Plugin: Optimizes plugin restart entry points and operation flow.
- Backend/Control Plane: Adjusts control unit assignment parameter propagation for Proxy preordered plugin installation.
- Frontend: Optimizes IP selector business/set/module requests, assignment table default view, post-retry status refresh, and request ID generation compatibility.
- Installer/Deployment: Aligns Helm charts, service image, and mock-server image to this release version.

**Improvements**

- IP selector uses adjusted business, set, and module data requests to improve data loading consistency in selection scenarios.
- Plugin restart interactions are optimized across the plugin list and process side panel.
- The control unit assignment table now uses a default view consistent with the install table.
- Task status auto-refresh after batch retry is optimized to reduce delayed status updates on task detail pages.

**Bug fixes**

- Fixes missing control unit assignment parameters when installing preordered plugins for Proxy nodes.
- Fixes frontend request ID UUID generation compatibility in some protocol or browser environments.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This release does not change the minimum Agent or Plugin runtime version requirements.
- Changes focus on install task parameter propagation, frontend interactions, and request compatibility, with no extra upgrade action required for existing nodes.

**Component dependencies and upgrade prerequisites**

- This release does not introduce new external component dependencies.
- Backend swagger files are not updated in this release, so API Gateway resources are not synced and API Gateway release metadata remains unchanged.
