## [Version: v3.0.1-alpha.33] - 2026-06-02

Full Changelog: [v3.0.1-alpha.32...v3.0.1-alpha.33](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.32...v3.0.1-alpha.33)

**Release scope**

- Agent: No Agent behavior changes in this release.
- Plugin: Moves compatibility mode filtering into ensurePluginV2 to avoid premature filtering in earlier stages.
- Package: No Agent / Plugin / Package format changes in this release.
- Backend/Control Plane: Adds go build tags for jinja2_bin and wmi_bin to trim dependencies and build outputs per target.
- API / Gateway: No externally visible API contract changes in this release.
- Frontend: No frontend behavior changes in this release.
- Installer/Deployment: Helm chart version, appVersion, and image tag aligned to v3.0.1-alpha.33.

**New features**

- None.

**Improvements**

- Moves plugin v2 compatibility mode filtering to ensurePluginV2 for clearer and more maintainable install-path decisions.
- Adds go build tags for jinja2_bin and wmi_bin to support selective compilation by platform/scenario.

**Bug fixes**

- Fixes cases where compatibility mode filtering ran too early and incorrectly skipped some plugin v2 install paths.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- Plugin v2 compatibility install semantics are unchanged; only the filtering stage moved.

**Component dependencies and upgrade prerequisites**

- No new external component dependencies in this release.
