## [Version: v3.0.1-alpha.59] - 2026-07-27

Full Changelog: [v3.0.1-alpha.58...v3.0.1-alpha.59](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.58...v3.0.1-alpha.59)

**Release scope**

- Agent: Agent, Plugin, and Package formats remain compatible.
- Backend/Control Plane: sync_host operation generation, GSE process-result polling, and Mongo/Redis integration-test support are improved.
- Frontend: The plugin process list displays additional node context fields.
- Installer/Deployment: Deployment assets should use v3.0.1-alpha.59.

**New features**

- The plugin process list now displays business, network area, network unit, operations department, node version, and node status for plugin rows, making node context easier to inspect during plugin process operations.

**Improvements**

- sync_host generation for Agent information, Agent state, and alive plugin process operations now scans only the required host fields and batches operation creation, reducing Count/List overhead on large host sets.
- Mongo and Redis integration-test support adds reusable testsuite helpers, environment-based source selection, Docker-backed source selection, isolated Mongo databases, and isolated Redis key prefixes.

**Bug fixes**

- GSE process operation result polling uses a longer exponential backoff window, reducing premature failures while process tasks are still running.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This version's frontend, sync_host, GSE polling, and integration-test changes don't change Agent, Plugin, or Package format contracts.

**Component dependencies and upgrade prerequisites**

- Upgrade deployment assets with v3.0.1-alpha.59.
- This version does not sync Backend API Gateway resources; API Gateway release metadata remains `2.18.1 / v3.0.1-alpha.56`.
- Integration tests can use `testsuite/integration.env` or Docker-backed sources with `NODEMGR_TEST_*` variables.
