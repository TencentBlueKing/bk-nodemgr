## [Version: v3.0.1-alpha.39] - 2026-06-15

Full Changelog: [v3.0.1-alpha.38...v3.0.1-alpha.39](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.38...v3.0.1-alpha.39)

**Release scope**

- Agent: The Agent status page now shows online, offline, and not-installed counts across the selected businesses. Installation, upgrade, and reinstall flows remain compatible.
- Plugin: Plugin workflow status handling is more robust when workers shut down or operation records are missing.
- Package: Agent / Plugin / Package formats remain compatible.
- Backend/Control Plane: Adds graceful shutdown for REST servers and Workflow workers; improves cross-unit Proxy installation; completes topology graph host information and workflow status fallback behavior.
- API / Gateway: Syncs topo Swagger and API Gateway resources, including the topology graph node latency structure.
- Frontend: Improves Agent status statistics, IP Selector topology filtering, network unit latency tooltips, and upstream/downstream access point prompts.
- Installer/Deployment: Helm adds a default preStop lifecycle hook and extends Pod termination grace period for graceful shutdown.

**New features**

- Backend REST servers support graceful shutdown and wait for in-flight requests within the configured timeout.
- Workflow workers support graceful shutdown. Retryable tasks are rescheduled after shutdown, and non-retryable tasks are terminated explicitly.
- Helm deployment now injects default preStop hooks and graceful shutdown timeout configuration to reduce interruption during rolling upgrades.
- The Agent status page shows online, offline, and not-installed Agent counts for the selected business scope.
- Cross-unit Proxy installation supports SSH-Only mode, avoiding relay-assisted installation paths across network units.

**Improvements**

- IP Selector topology filtering now follows CMDB Set / Module hierarchy, and host queries support set and module filters.
- Network unit latency tooltips in the topology graph now display 1min / 5min / 15min latency grouped by machine.
- Improved upstream and downstream access point prompts when creating or editing network units.
- Node and Plugin package transfer options now use explicit disable semantics, reducing ambiguity when transferring only installers or release packages.
- Expanded server configuration FAQ and graceful shutdown design documentation for deployment and operations.

**Bug fixes**

- Fixed cross-unit Proxy installation being routed through the relay-assisted installation path. Cross-unit scenarios now use SSH-Only installation.
- Fixed unreliable workflow status fallback when node or plugin workflow operation records are missing. Running workflows now fall back to failed after the grace period.
- Protected finished workflow statuses from being overwritten after operation records are cleaned up.
- Adjusted IP Selector business filter data to avoid including unrelated business scope when selecting sets or modules.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This release does not change the minimum Agent or Plugin runtime version requirements.
- Transfer options persisted in node and plugin deployment records now use disable semantics. Confirm unfinished workflows and historical deployment records during the rolling upgrade window.

**Component dependencies and upgrade prerequisites**

- This release does not introduce new external component dependencies.
- Helm default `terminationGracePeriodSeconds` is changed to 120 seconds, and default `preStop: sleep 5` is configured. If your deployment overrides `terminationGracePeriodSeconds` or `lifecycleHooks`, verify the custom values still provide enough graceful shutdown time before upgrade.
- REST Server and Workflow graceful shutdown timeout defaults to 60 seconds. For long-running tasks, plan rolling upgrades with the task execution window in mind.
