## [Version: v3.0.1-alpha.74] - 2026-08-27

Full Changelog: [v3.0.1-alpha.73...v3.0.1-alpha.74](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.73...v3.0.1-alpha.74)

**Release scope**

- Agent: Agent / Proxy package formats remain compatible.
- Plugin: Plugin start API and frontend entry were added, with Plugin debug workflow and documentation updates.
- Package: Plugin / Package import and export capabilities were added, and Package platform matching was fixed.
- Backend/Control Plane: Tenant-aware context now covers user, auth, UserManager, GSE, CMDB, and API Gateway flows, with fixes for scheduled workflow tenant context and selected failure paths.
- Installer/Deployment: Reinstall now carries proxy, install source, and install_method updates; Helm, API Gateway release metadata, and image versions are aligned to v3.0.1-alpha.74.

**New features**

- Plugin management now supports the start API and frontend operation entry.
- Plugin / Package import and export are available for cross-environment sync and operations delivery.
- Plugin debug workflow documentation now covers debug, import, config policy, and access package scenarios.

**Improvements**

- Reinstall now supports proxy, install source, and install_method parameters to describe installation sources more clearly.
- Tenant-aware context now passes through user, auth, UserManager, GSE, CMDB, and API Gateway calls.
- Frontend timestamps now follow timezone display, and the IP selector interaction was improved.
- Added documentation for ipchooser, import, debug, config policy, and access package usage.

**Bug fixes**

- Fixed missing tenant context when scheduled workflows run.
- Fixed Package platform equality matching.
- Fixed a nil path that could panic in operation controller.
- Fixed user display-name translation.

**Agent / Plugin / Package compatibility**

- Agent / Proxy package versions are aligned with the system version v3.0.1-alpha.74.
- Plugin and Package package formats remain compatible.

**Component dependencies and upgrade prerequisites**

- API Gateway release version / comment are aligned to `3.0.1-alpha.74`.
- Helm chart version, appVersion, server image tag, apigw-sync image tag, and mock-server image tag are aligned to `v3.0.1-alpha.74`.
