## [Version: v3.0.1-alpha.49] - 2026-07-02

Full Changelog: [v3.0.1-alpha.48...v3.0.1-alpha.49](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.48...v3.0.1-alpha.49)

**Release scope**

- Agent: Agent, Plugin, and Package runtime behavior stays compatible with the previous alpha release.
- Backend/Control Plane: Fixes the host query path used by the sync flow that corrects Agent IDs.
- Frontend: Uses the first host IP for network unit recommendation and improves assignment-related interaction display.
- Installer/Deployment: Aligns Helm charts, service image, API Gateway sync image, and mock-server image to this release version.

**New features**

- Network unit recommendation now prefers the first host IP, improving the default recommendation accuracy in assignment scenarios.

**Bug fixes**

- Fixes the host query path used by the Agent ID correction sync flow so it uses the unified host list query capability.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This release does not change the minimum Agent or Plugin runtime version requirements.
- Existing nodes require no extra upgrade action.

**Component dependencies and upgrade prerequisites**

- This release does not introduce new external component dependencies.
- Backend swagger files are not updated in this release, so API Gateway resources are not synced and API Gateway release metadata remains unchanged.
