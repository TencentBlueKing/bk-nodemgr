## [Version: v3.0.1-alpha.48] - 2026-07-01

Full Changelog: [v3.0.1-alpha.47...v3.0.1-alpha.48](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.47...v3.0.1-alpha.48)

**Release scope**

- Agent: Agent, Plugin, and Package runtime behavior stays compatible with the previous alpha release.
- Backend/Control Plane: Reuses the batch executor in sync workflows, fixes host list logic, and ensures IP selection data is backfilled after selection.
- Frontend: Fixes out-of-band management internationalization display and status statistic filtering conflicts, and improves assignment and proxy detail interactions.
- Installer/Deployment: Aligns Helm charts, service image, and mock-server image to this release version.

**Improvements**

- Reuses the batch executor for backend sync workflows and assignment-unit handlers to reduce duplicate batch processing paths.
- Improves frontend assignment, Agent list, out-of-band detail, and proxy information interactions.

**Bug fixes**

- Fixes internationalization display issues in out-of-band management pages.
- Fixes status conflict behavior when filtering Agent status statistics.
- Fixes host list logic used by install and sync workflows.
- Fixes missing data backfill after IP selector selection.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This release does not change the minimum Agent or Plugin runtime version requirements.
- Existing nodes require no extra upgrade action.

**Component dependencies and upgrade prerequisites**

- This release does not introduce new external component dependencies.
- Backend swagger files are not updated in this release, so API Gateway resources are not synced and API Gateway release metadata remains unchanged.
