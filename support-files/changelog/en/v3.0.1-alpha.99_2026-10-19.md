## [Version: v3.0.1-alpha.99] - 2026-10-19

Full Changelog: [v3.0.1-alpha.98...v3.0.1-alpha.99](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.98...v3.0.1-alpha.99)

**Release scope**

- Backend/Control Plane: The plugin install API can now omit the plugin version and install the default version, and the multi-tenant flag in plugin Jinja2 system configuration is now rendered as a string.

**New features**

- The `version` field of each item in the `plugin` list of the plugin install API `/api/v3/plugin/install` is now optional. When it is omitted, the default version of the plugin package matching the target host's Agent generation, OS, and CPU architecture is installed.

**Bug fixes**

- Fixed the multi-tenant flag in the Jinja2 system configuration of plugin configuration files being rendered as a boolean instead of a string. It is now rendered as `"true"` or `"false"`.

**Agent / Plugin / Package compatibility**

- This version does not change Agent, Plugin, or Package formats.
- The plugin install API remains compatible with requests that specify `version`; behavior is unchanged for those requests.
- Plugin configuration templates that reference the multi-tenant flag in Jinja2 now receive a string value (`"true"` or `"false"`) instead of a boolean.
