## [Version: v3.0.1-alpha.96] - 2026-10-12

Full Changelog: [v3.0.1-alpha.95...v3.0.1-alpha.96](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.95...v3.0.1-alpha.96)

**Release scope**

- Backend/Control Plane: Extended node uninstall and topology host-count APIs with additional request options.
- Frontend: Updated status wording for Agent and Proxy statistics and filters.
- Operations: Updated release verification and source archive signing guidance.
- CLI: Added a manual CLI for selected operational workflows.
- Installer: Added explicit HTTP proxy override and skip support for server and tool installers.

**New features**

- Added an option to unbind the host AgentID relation after successful Agent or Proxy uninstallation.
- Added node-role filtering to business host-count queries.
- Added manual CLI support for selected Node Manager operations.
- Added an installer option to use a specified HTTP proxy or explicitly skip proxy settings.

**Improvements**

- Clarified API Gateway documentation for node-role permissions and host-count filtering.
- Improved permission refresh after network unit creation and bounded trigger queries.
- Improved strategy management form behavior and topology filtering integration.

**Bug fixes**

- Fixed permission data not being refreshed after creating a network unit.
- Fixed trigger queries that could run without an upper bound.
- Corrected node installer wait log wording.
- Fixed strategy management acceptance issues.
- Fixed parsing of notice timestamps with timezone offsets.

**Agent / Plugin / Package compatibility**

- This version does not change Agent, Plugin, or Package formats.

**Component dependencies and upgrade prerequisites**

- Helm deployment defaults preserve existing installer proxy behavior; no additional upgrade prerequisites are introduced.
