## [Version: v3.0.1-alpha.41] - 2026-06-18

Full Changelog: [v3.0.1-alpha.40...v3.0.1-alpha.41](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.40...v3.0.1-alpha.41)

**Release scope**

- API / Gateway: API Gateway sync configuration now includes related app settings so gateway releases can identify the current app.
- Installer/Deployment: Helm apigw-sync Job now includes resource configuration and no longer defaults the release stage to stage when it is not explicitly configured.
- Documentation: Adds an API Gateway sync FAQ for Helm deployments to support gateway sync execution and troubleshooting.

**Improvements**

- Helm apigw-sync Job reuses init container resource settings, allowing resource requests and limits for sync jobs to be controlled consistently.
- The API Gateway sync script no longer publishes to stage by default. Use `RELEASE_STAGES` to explicitly select target release stages.
- Release alignment verification now checks file scope, version fields, and API Gateway resources sync requirements to reduce release omissions.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This release does not change the minimum Agent or Plugin runtime version requirements.

**Component dependencies and upgrade prerequisites**

- This release does not introduce new external component dependencies.
- If your deployment depends on apigw-sync publishing to a specific stage automatically, configure the target stage explicitly with `RELEASE_STAGES`.
