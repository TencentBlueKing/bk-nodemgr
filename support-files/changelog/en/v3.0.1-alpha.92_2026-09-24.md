## [Version: v3.0.1-alpha.92] - 2026-09-24

Full Changelog: [v3.0.1-alpha.91...v3.0.1-alpha.92](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.91...v3.0.1-alpha.92)

**Release scope**

- Installer/Deployment: Adjusted log discovery for Node Manager containers when Alloy is enabled.

**Bug fixes**

- Fixed hard-coded namespaces in the Helm chart's Alloy log discovery: by default, it discovers Pods in the Helm release namespace; Helmfile deployment specifies the application, backend, and file namespaces.

**Agent / Plugin / Package compatibility**

- This version does not change Agent, Plugin, or Package formats.

**Component dependencies and upgrade prerequisites**

- To collect Node Manager logs across namespaces with Alloy, set `alloy.nodemgrNamespaces` to the actual service namespaces. Alloy remains disabled by default. Non-Node Manager containers with names matching `bk-nodemgr-(application|backend|file)` in those namespaces may also be collected.
