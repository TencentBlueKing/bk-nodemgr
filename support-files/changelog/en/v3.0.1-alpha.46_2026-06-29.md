## [Version: v3.0.1-alpha.46] - 2026-06-29

Full Changelog: [v3.0.1-alpha.45...v3.0.1-alpha.46](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.45...v3.0.1-alpha.46)

**Release scope**

- Agent: Adds direct SSH installation with proxy support and Windows-compatible SSH MAC algorithms for legacy Windows SSH servers.
- Backend/Control Plane: Adds correct-agent-id and dynamic-agent-id sync workflows, tenant-scoped GSE event data IDs, CMDB-based out-of-band node information management, and an updated GSE version regex.
- Plugin: Corrects installer endpoint selection for plugin uninstall and upgrade, and adjusts plugin policy creation configuration items.
- Frontend: Improves Agent status display coverage, agent/proxy status statistics filtering, package default-version reminders, and out-of-band node information presentation.
- Installer/Deployment: Aligns Helm charts, service image, and mock-server image to this release version.

**Features**

- Adds direct SSH installation with proxy support for node installation scenarios.
- Adds tenant-scoped GSE event data IDs.
- Adds Windows-compatible SSH MAC algorithm support for legacy Windows SSH servers.
- Adds correct-agent-id sync workflow and dynamic agent id sync for updated hosts.
- Adds CMDB-based out-of-band information management for nodes, including zone and city information.
- Adds a frontend reminder when a default version is not set in package management.

**Improvements**

- Updates the GSE version regex for broader version recognition.
- Adjusts configuration items on the plugin policy creation page.
- Aligns agent and proxy status statistics filter conditions and fixes proxy status list pagination switching.

**Bug fixes**

- Fixes plugin uninstall and upgrade installer endpoint selection.
- Self-heals wmiexec and jinja2_exec temporary binary paths.
- Covers the full backend NodeStatus set in the frontend Agent status display.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This release does not change the minimum Agent or Plugin runtime version requirements.
- Existing nodes require no extra upgrade action.

**Component dependencies and upgrade prerequisites**

- This release does not introduce new external component dependencies.
- API Gateway resources are synced for node runtime fields, with API Gateway release metadata updated to `2.15.2 / v3.0.1-alpha.46`.
