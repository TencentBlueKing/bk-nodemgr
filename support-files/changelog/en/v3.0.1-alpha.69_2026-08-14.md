## [Version: v3.0.1-alpha.69] - 2026-08-14

Full Changelog: [v3.0.1-alpha.68...v3.0.1-alpha.69](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.68...v3.0.1-alpha.69)

**Release scope**
- Agent: Refreshed Agent / Proxy batch assign-unit and topology-related API schemas so numeric `int64` fields stay aligned with the proto contract.
- Plugin: This version does not change the Plugin package format, and existing Plugin release compatibility remains unchanged.
- Package: This version does not change Package release semantics or package format.
- Backend/Control Plane: Synchronized generated proto and Swagger resources, correcting OpenAPI schema types for topology, network area, host, and related ID fields.
- Installer/Deployment: Aligned Helm, API Gateway release metadata, and image versions to v3.0.1-alpha.69, and updated the downloader `allowHosts` example value.

**Improvements**
- Refreshed generated proto and Swagger resources to keep API documentation, client-generation inputs, and backend contracts aligned.
- Updated the downloader `allowHosts` example in Helm values to `127.0.0.1`, making it easier to reuse in local or minimal deployments.

**Bug fixes**
- Corrected generated OpenAPI schemas where multiple `int64` ID fields were described as strings, including topology, network area, host, and batch assign-unit request item fields.

**Agent / Plugin / Package compatibility**
- Agent / Proxy package versions are aligned with the system version v3.0.1-alpha.69.
- Plugin and Package package formats remain compatible.
- Integrators that generate clients from OpenAPI schemas should regenerate clients with this version's schemas to pick up the corrected integer type definitions.

**Component dependencies and upgrade prerequisites**
- API Gateway release version / comment are aligned to `3.0.1-alpha.69`.
- Helm chart version, appVersion, server image tag, apigw-sync image tag, and mock-server image tag are aligned to `v3.0.1-alpha.69`.
- This version does not introduce new component dependencies.
