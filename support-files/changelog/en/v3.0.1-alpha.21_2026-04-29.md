## [Version: v3.0.1-alpha.21] - 2026-04-29

Full Changelog: [v3.0.1-alpha.20...v3.0.1-alpha.21](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.20...v3.0.1-alpha.21)

**Release Scope**

- Backend/Control Plane: Added operation instance timeout detection and periodic task handling optimizations, optimized Agent sync flow by business context, and enhanced operation and operation instance query and filtering capabilities
- Frontend: Added address display in install and status tables, improved assign unit and plugin installation interactions, and updated related i18n resources and permission points
- Installer/Deployment: Updated API version for Helm sync jobs and fixed application chart config key rendering

**New Features**

- Added address display support in install and status tables to improve node installation and status troubleshooting efficiency
- Added accumulated operation instance timeout detection to identify long-pending execution instances and trigger corresponding handling flows

**Optimizations**

- Optimized plugin installation flow and assign unit related control unit interactions to reduce repeated steps in page operations
- Optimized periodic task handling path and operation query conditions to improve task filtering and execution stability in large-scale scenarios
- Optimized Agent info synchronization by business dimension to reduce ineffective processing overhead in sync pipelines

**Bug Fixes**

- Fixed application chart config key rendering issues to avoid mismatch between configuration display and parsing

**Agent / Plugin / Package compatibility**

- No Agent / Plugin / Package version range or package format changes

**Component Dependencies and Upgrade Prerequisites**

- This release includes proto and swagger updates, for external integrations based on API schemas, update corresponding clients or validation logic accordingly
- This release includes coordinated Frontend and Backend/Control Plane changes, a consistent rollout window is recommended for paired upgrades
- When upgrading Helm to `v3.0.1-alpha.21`, verify cluster compatibility with the updated sync Job API version
