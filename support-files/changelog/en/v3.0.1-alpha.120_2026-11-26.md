## [Version: v3.0.1-alpha.120] - 2026-11-26

Full Changelog: [v3.0.1-alpha.119...v3.0.1-alpha.120](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.119...v3.0.1-alpha.120)

**Release scope**

- Application/Frontend: Agent and Proxy management navigation and multi-tenant login authentication.
- Installer/Deployment: Helmfile trace export configuration.

**New features**

- Helmfile supports additional trace exporters through `opentelemetryGateway.exporters` in `env.yaml`, sending traces to both the embedded Tempo and additional collectors without manually configuring the traces pipeline.

**Improvements**

- Renames Agent Status and Proxy Status navigation and page titles to Agent Management and Proxy Management, respectively.

**Bug fixes**

- Fixes login failures in multi-tenant mode when the tenant has not yet been resolved. The user information query uses application authentication, with `bk_token` identifying the user and their tenant.

**Agent / Plugin / Package compatibility**

- This release does not change Agent, Plugin, or Package formats.

**Component dependencies and upgrade prerequisites**

- `opentelemetryGateway.exporters` defaults to `{}`, preserving the existing embedded Tempo export behavior without requiring changes to existing configuration.
- When configuring additional exporters, `otlp/tempo` is reserved for the embedded Tempo. Use fully qualified Service DNS names for cross-namespace forwarding and avoid targeting the current Gateway or creating forwarding loops. Advanced configuration in `overrides/monitoring.yaml` still takes precedence over template-generated configuration.
