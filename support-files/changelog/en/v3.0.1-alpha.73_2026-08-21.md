## [Version: v3.0.1-alpha.73] - 2026-08-21

Full Changelog: [v3.0.1-alpha.72...v3.0.1-alpha.73](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.72...v3.0.1-alpha.73)

**Release scope**

- Agent: Agent / Proxy package formats remain compatible.
- Plugin: Plugin package format remains compatible.
- Package: Package capabilities remain compatible.
- Backend/Control Plane: The bkiamv3 sync job now passes tenant id while syncing the permission model.
- Installer/Deployment: API Gateway sync prerequisite documentation and the Helm default grant-permission example were updated; Helm, API Gateway release metadata, and image versions are aligned to v3.0.1-alpha.73.

**Improvements**

- Added apigw-sync prerequisite documentation that clarifies the `bk-nodemgr` app must be added to the `bk-nodemgr` gateway's allowed sync app list.
- Changed the default Helm API Gateway grant permission example to gateway-level authorization and kept the resource-level example as commented reference.

**Bug fixes**

- bkiamv3 sync job now passes `bk_tenant_id`; single-tenant mode uses `default`, and multi-tenant mode uses `system`, so permission model sync runs with the correct tenant context.

**Agent / Plugin / Package compatibility**

- Agent / Proxy package versions are aligned with the system version v3.0.1-alpha.73.
- Plugin and Package package formats remain compatible.

**Component dependencies and upgrade prerequisites**

- API Gateway release version / comment are aligned to `3.0.1-alpha.73`.
- Helm chart version, appVersion, server image tag, apigw-sync image tag, and mock-server image tag are aligned to `v3.0.1-alpha.73`.
- Before deployment, ensure `bk-nodemgr` is included in the `bk-nodemgr` gateway's allowed sync app list.
