## [Version: v3.0.1-alpha.66] - 2026-08-06

Full Changelog: [v3.0.1-alpha.65...v3.0.1-alpha.66](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.65...v3.0.1-alpha.66)

**Release scope**

- Agent: Agent, Plugin, and Package formats remain compatible.
- Plugin: Plugin release query and visibility control capabilities are added.
- Package: Package release query capabilities and Package workflow storage are added.
- Backend/Control Plane: Host list, business selector, install table, CMDB request delegation, API Gateway release metadata, and API Gateway resources are updated.
- Frontend: Business selector performance, long text tooltip behavior, and frontend build command are improved.
- Installer/Deployment: Deployment assets should use v3.0.1-alpha.66, and Installer debug logging is enabled by default.

**New features**

- Package release distinct queries now return name and version distinct results.
- Plugin release distinct queries are now available.
- Plugin package release visibility control is now available.
- Package workflow storage is now available.
- Deploy policy workflows now record provenance.
- Password key encryption has been adjusted.

**Improvements**

- Business selector performance is improved, with long text tooltip support added.
- The IP query field position in the host list API is adjusted.
- The frontend Docker build command now matches the current release build flow.
- Installer debug logging is enabled by default to help installation troubleshooting.

**Bug fixes**

- Agent strategy scope copy is clarified.
- CMDB requests are delegated to the virtual user to fix request identity handling.
- Host static updates now use the DAO type path.
- API Gateway release metadata is aligned to `3.0.1-alpha.66`.
- Install table now auto fills the login port.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- Plugin release and Package release query additions are backward compatible with existing calls.
- This release does not require a Package format upgrade.

**Component dependencies and upgrade prerequisites**

- API Gateway resources include the required `pkg.swagger.json` sync for this release.
- API Gateway release version is `3.0.1-alpha.66`.
- This release does not introduce new external component dependencies.
