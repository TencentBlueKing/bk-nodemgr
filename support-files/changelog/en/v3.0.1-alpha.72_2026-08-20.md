## [Version: v3.0.1-alpha.72] - 2026-08-20

Full Changelog: [v3.0.1-alpha.71...v3.0.1-alpha.72](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.71...v3.0.1-alpha.72)

**Release scope**

- Agent: NodeAgent Windows auto-install documentation was clarified; installer and relay code paths keep the existing Agent package format compatible.
- Plugin: Plugin control now supports debug command metadata; Plugin subconfig upgrade rendering and main-config selection were corrected.
- Package: Added Package import workflow support for Plugin V3 packages and introduced package deployment storage backing.
- Backend/Control Plane: Added continuous profiling support, multi-tenant bk_token routing through API Gateway, package workflow APIs, process config query-chain fields, and target URL requests.
- Installer/Deployment: Aligned Helm, API Gateway release metadata, and image versions to v3.0.1-alpha.72.

**New features**

- Package import workflow can fetch, publish, hide, and enable imported Plugin V3 packages through the Backend package workflow APIs.
- Continuous profiling can be enabled for backend, file, relay, and application services.
- REST client requests can target an explicit URL when the caller needs to bypass the default service endpoint.
- Plugin control data now carries debug command metadata for Plugin operation scenarios.

**Improvements**

- Multi-tenant bk_token requests are routed through API Gateway with gateway header handling.
- Process config records now persist template-name and query-chain data to support more precise config reads.
- Plugin install parameter rendering passes only the main config name when selecting Plugin install configuration.
- BKRepo resource usage and third-party permission documentation were updated for deployment preparation.

**Bug fixes**

- Plugin subconfig is rendered again during upgrade, so upgraded Plugin instances receive the expected subconfig content.
- bk-user data-only responses are parsed correctly by the UserManager client.
- Filter panel positioning stays aligned with fixed columns during horizontal scrolling.

**Agent / Plugin / Package compatibility**

- Agent / Proxy package versions are aligned with the system version v3.0.1-alpha.72.
- Plugin and Package package formats remain compatible.
- The new Package import workflow extends Package operations without changing existing package publishing compatibility.

**Component dependencies and upgrade prerequisites**

- API Gateway release version / comment are aligned to `3.0.1-alpha.72`.
- Helm chart version, appVersion, server image tag, apigw-sync image tag, and mock-server image tag are aligned to `v3.0.1-alpha.72`.
- This version updates Go module dependencies and does not require additional runtime components.
