## [Version: v3.0.1-alpha.64] - 2026-08-03

Full Changelog: [v3.0.1-alpha.63...v3.0.1-alpha.64](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.63...v3.0.1-alpha.64)

**Release scope**

- Agent: Agent, Plugin, and Package formats remain compatible.
- Plugin: Plugin configuration and CMDB zone id handling are improved.
- Package: Package import proto definition is added for the Backend API contract.
- Backend/Control Plane: Tenant initialization, Windows SSH install, scheduled agent state sync, stopped operation handling, and CMDB host zone id compatibility are updated.
- Frontend: Log viewer filtering and related page bug fixes are included.
- API Gateway: Backend API Gateway resources are not synced in this version. Release metadata remains `2.18.2 / v3.0.1-alpha.61`.
- Developer Experience: Docker SDK, Dependabot configuration, PR template, and Agent Go toolchain documentation are updated.
- Installer/Deployment: Deployment assets should use v3.0.1-alpha.64.

**New features**

- Tenant initialization now has adminclient support, preparing tenant setup flows for Backend administration.
- Package import proto definition is added for package import API work.
- Windows node installation now supports SSH as an install method.

**Improvements**

- Scheduled agent state sync skips unchanged state updates, reducing repeated workflow and storage work.
- Stopped operation polling and storage handling are updated to improve stop operation lifecycle tracking.
- Frontend log viewer now supports log level filtering and hides DEBUG logs by default.
- Docker SDK and Dependabot configuration are updated, and the PR template is added for contributor workflow consistency.
- Agent Go toolchain documentation is aligned with the current development setup.

**Bug fixes**

- CMDB host zone id handling now accepts numeric values, keeping node deployment and plugin configuration flows compatible with CMDB data.
- Frontend page fixes improve node list, footer, layout, copy IP, and custom deploy configuration behavior.
- Installer log reporter lowers attempt log severity to reduce noisy operational logs.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- This version updates Backend, Frontend, Installer, Developer Experience, and package import API definition assets. It does not change package format contracts.

**Component dependencies and upgrade prerequisites**

- Upgrade deployment assets with v3.0.1-alpha.64.
- Backend API Gateway resources are not synced in this version. API Gateway release metadata remains `2.18.2 / v3.0.1-alpha.61`.
- This version does not introduce new component prerequisites for Agent, Plugin, or Package rollout.
