## [Version: v3.0.1-alpha.55] - 2026-07-16

Full Changelog: [v3.0.1-alpha.54...v3.0.1-alpha.55](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.54...v3.0.1-alpha.55)

**Release scope**

- Agent: Agent, Plugin, and Package formats remain compatible; Windows Agent deployment adds an SSH installation method.
- Backend/Control Plane: The Application service adds Host / Process distinct caches, while host synchronization improves Proxy service IP repair and Agent ID deduplication.
- Frontend: Agent, Proxy, and Plugin pages adapt to the Host / Process distinct request fields.
- Installer/Deployment: Helm chart, service image, API Gateway sync image, and mock-server image align to v3.0.1-alpha.55.

**New features**

- Windows Agent deployment supports selecting the SSH installation method while retaining the existing WMI path.
- Agent and Proxy configuration policies add a BT listening IP or interface option, disabled by default to preserve existing runtime behavior.

**Improvements**

- The Application service adds per-tenant in-memory caches for Host / Process distinct queries to reduce repeated Backend / MongoDB requests.
- Host synchronization fills missing Proxy service IPv4 / IPv6 values from internal IP addresses and persists the repaired values.

**Bug fixes**

- Agent information and state synchronization deduplicate Agent IDs before batch requests, preventing duplicate IDs from failing synchronization.

**Agent / Plugin / Package compatibility**

- Agent, Plugin, and Package formats remain compatible.
- Application Host distinct requests now use `role_type`, and Process distinct requests add the optional `plugin_name`; repository Frontend callers are updated, while external Application API callers should check their request fields.

**Component dependencies and upgrade prerequisites**

- Upgrade deployment assets with the v3.0.1-alpha.55 Helm chart, service image, API Gateway sync image, and mock-server image.
- This version does not sync Backend API Gateway resources; API Gateway release metadata remains `2.17.1 / v3.0.1-alpha.52`.
