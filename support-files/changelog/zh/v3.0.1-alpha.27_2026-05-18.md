## [Version: v3.0.1-alpha.27] - 2026-05-18

Full Changelog: [v3.0.1-alpha.26...v3.0.1-alpha.27](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.26...v3.0.1-alpha.27)

**发布范围**

- Agent: 无直接变更。
- Proxy: 无直接变更。
- Plugin: 补齐旧版 v2 plugin 的兼容处理与 action 标准化。
- Package: 无独立发布包格式变更；Backend API / Gateway 条件字段有同步更新。
- Backend/Control Plane: 新增 process v2 存储表，优化主机统计与进程列表查询性能，扩展用户信息返回，优化多租户场景用户名显示。
- API / Gateway: Process 条件字段从 `node_generation` 同步为 `generation`，并对齐为 `int64` 数组。
- Installer/Deployment: 补齐旧版 v2 plugin 完整安装与卸载命令，调整 application 前端配置到 docker 与 helm。

**新增功能**

- Backend 新增 process v2 存储表，为进程管理 v2 兼容链路提供数据层支持。

**功能优化**

- Backend 主机统计查询优化为 group by 聚合方式，减少查询开销。
- Backend 进程列表查询优化，提升查询性能。
- Backend 同步 Agent 信息时同步连接周期时间，缩小同步间隙，减少数据延迟。
- Frontend 优化多租户场景下用户名显示逻辑，提升用户体验。
- Frontend 个人中心用户名显示优化。
- Backend WebUserInfo 接口扩展返回更多用户信息，支持前端展示需求。
- Installer/Deployment application 前端配置调整到 docker 与 helm 配置文件，便于部署管理。

**Agent / Plugin / Package compatibility**

- 本次变更用于兼容旧版 v2 plugin，并补齐相关 action 标准化与完整安装/卸载流程。
- 现有 Plugin v1 功能保持兼容；涉及 Process 条件字段的 API / Gateway 调用方需要使用 `generation` 替代 `node_generation`，字段类型为 `int64` 数组。

**组件依赖与升级前置条件**

- 无额外组件依赖或升级前置条件。
