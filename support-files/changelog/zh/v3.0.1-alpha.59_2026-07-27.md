## [Version: v3.0.1-alpha.59] - 2026-07-27

Full Changelog: [v3.0.1-alpha.58...v3.0.1-alpha.59](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.58...v3.0.1-alpha.59)

**发布范围**

- Agent: Agent、Plugin、Package 包格式保持兼容。
- Backend/Control Plane: sync_host 操作生成、GSE process-result 轮询和 Mongo/Redis integration-test support 得到优化。
- Frontend: 插件进程列表展示更多节点上下文字段。
- Installer/Deployment: 部署资产需使用 v3.0.1-alpha.59。

**新增功能**

- 插件进程列表新增归属业务、管控区域、管控单元、运维部门、节点版本和节点状态展示，便于在插件进程操作时查看节点上下文。

**功能优化**

- sync_host 生成 Agent 信息、Agent 状态和存活插件进程操作时，仅扫描所需 Host 字段并批量创建操作，降低大批量主机场景下的 Count/List 开销。
- Mongo 和 Redis integration-test support 新增可复用的 testsuite helpers、基于环境变量和 Docker 的测试源选择、隔离的 Mongo database 以及隔离的 Redis key prefix。

**缺陷修复**

- GSE process operation 结果轮询使用更长的 exponential backoff 窗口，降低任务仍在运行时过早失败的概率。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本的 Frontend、sync_host、GSE 轮询和 integration-test 调整不改变 Agent、Plugin、Package 包格式契约。

**组件依赖与升级前置条件**

- 升级部署资产时需使用 v3.0.1-alpha.59。
- 本版本不涉及 Backend API Gateway resources 同步，API Gateway release metadata 保持 `2.18.1 / v3.0.1-alpha.56`。
- Integration tests 可通过 `testsuite/integration.env` 或 Docker-backed sources 的 `NODEMGR_TEST_*` 变量选择测试源。
