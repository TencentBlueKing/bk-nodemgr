## [Version: v3.0.1-alpha.67] - 2026-08-10

Full Changelog: [v3.0.1-alpha.66...v3.0.1-alpha.67](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.66...v3.0.1-alpha.67)

**发布范围**

- Agent: Agent 仓库使用指引得到补充，Agent、Plugin、Package 包格式保持兼容。
- Plugin: Windows Plugin endpoint 渲染逻辑得到修复。
- Package: 仓库属性 metadata 得到补充，Plugin Package 管理页资源包查看权限判断得到修复。
- Backend/Control Plane: bkrepo 系统租户请求、tenant ID provider contract、workflow storage 调度注册、API Gateway release metadata 和 API Gateway resources 得到更新。
- Frontend: Policy 配置页面文案和 Plugin Package 管理页权限判断得到优化。
- Installer/Deployment: Deploy policy 集成文档和社区健康文档得到补充。

**新增功能**

- bkrepo 系统租户 ID 提供契约已补充，Backend/Control Plane 请求可复用统一系统租户来源。
- 仓库属性 metadata 已补充，Package 仓库信息在发布和管理链路中保持一致。
- 项目错误处理 skill 已补充，统一 Go error handling 写作和评审规则。
- 社区健康文档已补充，贡献、协作和项目治理信息更完整。

**功能优化**

- Deploy policy 集成文档得到补充，部署策略对接说明更清晰。
- bkrepo 系统租户请求已适配统一租户 ID 来源。
- Agent 仓库使用指引得到更新。
- Policy 配置页面文案说明得到优化。
- API Gateway release metadata 对齐到 `3.0.1-alpha.67`。
- API Gateway resources 已同步本版本新增 Package endpoints 的中英文资源描述。

**缺陷修复**

- Workflow storage scheduler 注册和 nil check 得到修复，提升 workflow storage 调度路径稳定性。
- Windows Plugin endpoint 改为使用 loopback 渲染，修复 Windows Plugin 访问端点生成问题。
- Plugin Package 管理页查看资源包的前端权限判断得到修复。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本不引入 Package 格式升级要求。
- Windows Plugin endpoint 修复不改变 Plugin 包格式。

**组件依赖与升级前置条件**

- API Gateway release version 使用 `3.0.1-alpha.67`。
- 本版本不引入新的外部组件依赖。
- 本版本不要求额外的升级前置动作。
