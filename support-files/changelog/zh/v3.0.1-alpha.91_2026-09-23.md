## [Version: v3.0.1-alpha.91] - 2026-09-23

Full Changelog: [v3.0.1-alpha.90...v3.0.1-alpha.91](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.90...v3.0.1-alpha.91)

> 重要提示
> - 已启用内嵌 Loki 的部署，升级前须核对 Loki Chart `3.8.2` 至 `6.30.1` 的 values 与存储配置；不要直接沿用旧版配置并假定数据兼容。
> - 使用 Helmfile `example` 部署前，须填写环境凭据、网关地址与业务参数，并确认存储类及监控资源；主 Helm Chart 的自监控组件仍默认关闭。

**发布范围**

- Backend/API: 新增孤儿进程清理工作流及租户初始化流程，调整 IAM v4 授权和第三方请求失败的 HTTP 状态码。
- File/Package: 优化 BKRepo 下载及文件流处理。
- Installer/Deployment: 增加 Helmfile 示例部署与可选 Pyroscope profiling，更新内嵌 Loki 和自监控接线。

**新增功能**

- 新增 `POST /api/v3/sync/process/clean_orphan`，异步清理主机已不存在的过期孤儿进程记录；返回 `trigger_id` 供查询工作流结果。
- 管理端租户初始化现可创建租户存储并触发业务/主机、管控区域、默认插件及共享制品同步工作流。
- 新增 Helmfile 多 release 示例部署入口及按环境渲染 values 的能力；Helm 可按需启用 Pyroscope 并为 application、backend、file 服务配置 profiling。

**功能优化**

- 内嵌 Loki Chart 升级至 `6.30.1`；Grafana 增加 Pyroscope 数据源与自监控信号关联配置。
- 优化 BKRepo 下载的流式处理与压缩文件完整性校验，降低大文件下载时的内存占用。
- 支持对孤儿进程候选记录进行有界扫描，避免一次性加载大量记录。

**缺陷修复**

- 修复内嵌 Loki 日志采集路径及 Helmfile 自监控、网关默认值接线。
- 修复 Plugin 部署时 `last_sync_at` 丢失及过期进程同步时间未更新的问题。
- 修复 IAM v4 下级资源授权范围处理，并避免文件流重复关闭。
- 第三方请求失败由 HTTP `500` 调整为 `422`，便于区分外部依赖请求错误与服务内部错误。

**Agent / Plugin / Package compatibility**

- 本版本不修改 Agent / Proxy、Plugin 或 Package 包格式；新增 Sync API 不替换现有接口。依赖第三方请求失败时 HTTP `500` 的调用方须适配 `422`。

**组件依赖与升级前置条件**

- 主 Helm Chart 的 Pyroscope、Loki、Alloy 等自监控组件默认关闭；启用内嵌 Pyroscope 后，未显式指定 `profiling.enabled` 的服务会自动开启 profiling。使用外部 Pyroscope 时，须同时设置 `profiling.enabled: true` 和 `profiling.serverAddress`；需要保留内嵌 profiles 时须配置持久化。
- Helmfile `example` 默认启用自监控并将依赖、服务和监控拆分部署；升级现有 Helm 环境前先核对 release/namespace、存储及自定义 values，尤其是 Loki 的存储和 schema 配置。
