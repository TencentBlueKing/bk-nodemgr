## [Version: v3.0.1-alpha.102] - 2026-10-27

Full Changelog: [v3.0.1-alpha.101...v3.0.1-alpha.102](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.101...v3.0.1-alpha.102)

> 重要提示

- 导入插件包时，配置模板的 `filePath` 必须为固定目录：主配置为 `etc`，子配置为 `etc/<plugin_name>`；不一致的插件包将被拒绝导入。升级前请检查待导入插件包的 `definition.yaml`（V3）或 `project.yaml`（V2）。
- 下载 Agent、Proxy、插件、证书和 bin tool 安装包前，需具备对应包的 `package_view` 权限；backend 鉴权服务不可用时，下载请求会失败。

**发布范围**

- Backend/Control Plane：新增 V2 插件安装限速配置、配置策略事件快照一致性修复、包下载权限检查和 APIGW 请求 ID 修正。
- Plugin/Package：V2 插件包支持声明安装 CPU/磁盘 IO 限速；插件配置模板路径固定；上传结果展示限速配置。
- Installer/Deployment：Installer 在 Windows 全量安装前可配置 firewall，并在解压 V2 插件包时应用限速；APIGW 同步支持可选的拓扑查询 MCP Server。
- Frontend：优化带外管理设置，新增带外协议选项配置。

**新增功能**

- V2 插件 `project.yaml` 可选配置 `install_cpu_limit`（0 到 1）和 `install_disk_io_limit`（MB/s），用于限制安装或升级过程中处理 tgz 包的速度。未配置或设为 `0` 时不限速；`install_cpu_limit` 为 `1` 同样表示不限速。
- Installer 全量安装新增 `--firewall_features`、`--firewall_remote_ips` 参数：在 Windows 上，安装前按所选 features（`gse`、`nodemgr`）和允许的 CIDR 配置 firewall 规则；非 Windows 系统跳过该步骤。设置 features 时必须同时设置 CIDR。
- 包上传结果页展示插件包声明的安装 CPU/磁盘 IO 限速；插件发布查询响应保留这些限速信息。
- 带外管理设置页支持配置带外设备类型、协议、IP 和端口，并为各字段提供填写说明；协议选项由 Helm `application.config.front.opsOutBandProtocols` 提供（JSON 编码的协议列表，默认 `[]`）。
- API Gateway 同步支持发布节点管理拓扑只读查询 MCP Server `topo`（业务拓扑、网络区域、网络单元、接入点、图节点和主机查询，不含创建、修改、删除操作）。该能力由 apigw-sync 的 `ENABLE_SYNC_MCP_SERVERS` 控制，默认 `false`。

**功能优化**

- Plugin、Plugin V2 和 Package 的 workflow action 失败重试改为带抖动的退避等待；超时和重试次数不变，失败动作的后续重试和最终失败返回可能等待更久。
- V3 插件模板可通过 `PluginInfo.SubConfigPath` 获取插件子配置目录（`<PluginHomeDir>/etc/<plugin_name>`）。
- 优化带外管理页面的设备下拉选择，协议名称不再显示端口后缀。
- apigw-sync 镜像基础镜像升级为 `apigw-manager:4.2.4`；Helm 中 `apigwSync.config` 使用 `spec_version: 2`。

**缺陷修复**

- 修复配置策略的创建、更新、删除、启用、禁用和调整优先级操作记录的事件快照：事件使用操作时的原子快照，批量操作部分成功后出错时，已成功的变更仍被记录。
- 修复 APIGW 请求 ID 请求头混用问题：服务端读取网关生成的 `X-Bkapi-Request-Id`，客户端向网关发送业务 `X-Request-Id`。
- 修复插件可见业务范围查询未包含 `visible_biz_ids` 为空的插件的问题。
- 修复旧版 V2 插件安装、升级解包未应用 CPU、磁盘 IO 限速的问题。

**Agent / Plugin / Package compatibility**

- V2 插件包的 `install_cpu_limit` 取值须在 0 到 1 之间，`install_disk_io_limit` 须为非负数；非法取值会导致插件包导入失败。
- V2 插件包导入校验配置模板路径：主配置 `filePath` 为 `etc`，子配置为 `etc/<plugin_name>`；V3 与外部插件包同样适用该规则。
- 插件安装 / 升级仅在限速值生效（`install_cpu_limit` 大于 0 且小于 1，或 `install_disk_io_limit` 大于 0）时才向 Installer 传递对应参数；未配置限速的插件包行为不变。
- 包下载接口的请求与成功响应字段不变；调用方须具备对应包的 `package_view` 权限。

**组件依赖与升级前置条件**

- 使用 V2 插件安装限速时，目标主机上的 Installer 须升级到本版本，以支持 `--cpu-limit`、`--diskio-limit` 并在解压时应用限速。
- 使用 Windows firewall 配置时，Installer 须升级到本版本，以支持 `--firewall_features`、`--firewall_remote_ips`；请先确认 features 与 CIDR 符合预期，单个 IPv4/IPv6 地址分别使用 `/32` 或 `/128` 表示。
- 升级前确认下载安装包的操作人员和调用方具备对应 `package` 资源的 `package_view` 权限。
- 启用拓扑 MCP Server 同步需同时升级 chart 与 apigw-sync 镜像，并将 `ENABLE_SYNC_MCP_SERVERS` 设为 `true`。
- 使用带外协议选项时，需在 Helm `application.config.front.opsOutBandProtocols` 中配置协议列表；未配置时协议选项为空。
