## [Version: v3.0.1-alpha.22] - 2026-04-30

Full Changelog: [v3.0.1-alpha.21...v3.0.1-alpha.22](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.21...v3.0.1-alpha.22)

**发布范围**

- Backend/Control Plane: 支持 Agent / Proxy 安装参数透传到部署链路，新增重新注册与预设插件安装控制能力，并优化 workflow sync 在高负载场景下的调度、查询与写入路径
- Frontend: 安装、重装与预览流程补齐重新注册和预设插件安装相关交互，并修复预览页参数展示错误
- API / Gateway: NodeAgentInstall 与 NodeProxyInstall 接口文档、swagger 和 proto 增加安装控制参数
- Persistence/Workflow: 为 `oper_inst_data` 查询补充 `trigger_id + state` 相关索引，减少 host dynamic fields 无变化写入

**新增功能**

- Agent 和 Proxy 安装接口新增 `re_register` 参数，支持在安装请求中显式控制是否重新注册节点
- Agent 和 Proxy 安装接口新增 `install_pre_ordered_plugins` 参数，支持控制安装节点时是否安装预设插件，默认保持安装预设插件

**功能优化**

- 前端安装、重装与预览流程补齐重新注册和预设插件安装参数展示，减少安装参数在页面与后端之间的不一致
- 优化 workflow sync 调度与清理策略，基于 operation timeout 计算 trigger clean policy，减少固定清理策略与实际任务超时不匹配的问题
- 对 Agent info / state 的 host dynamic fields 更新做分批处理，并仅在目标字段变化时执行更新，降低 MongoDB 高负载场景下的无效写入

**缺陷修复**

- 修复 Agent / Proxy 安装预览相关页面的参数展示错误，避免用户确认安装配置时看到不准确的信息
- 修复 workflow sync 生成 Agent info 动作时的同步问题，提升同步任务在高并发场景下的稳定性

**Agent / Plugin / Package compatibility**

- 无 Agent / Plugin / Package 版本范围或包格式调整
- 安装接口新增参数保持可选，并保留默认行为；未传 `install_pre_ordered_plugins` 时仍默认安装预设插件，未传 `re_register` 时默认不重新注册

**组件依赖与升级前置条件**

- 本版本包含 proto、swagger 与 API Gateway 文档更新，若存在基于 NodeAgentInstall / NodeProxyInstall schema 的外部集成，请同步更新对应客户端或校验逻辑
- 本版本包含 Frontend 与 Backend/Control Plane 的联动变更，建议按同一发布窗口完成配套升级
- 本版本包含 workflow sync 与 MongoDB 查询 / 写入路径优化，升级后可降低高并发同步场景下的数据库读写压力
