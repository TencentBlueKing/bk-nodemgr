## [Version: v3.0.1-alpha.103] - 2026-10-29

Full Changelog: [v3.0.1-alpha.102...v3.0.1-alpha.103](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.102...v3.0.1-alpha.103)

> 重要提示

- Agent/Proxy 带外管理更新接口迁移至 `/api/v3/node/ops/update_fields/agent` 和 `/api/v3/node/ops/update_fields/proxy`，原 `/api/v3/node/{agent,proxy}/update_ops_fields` 路径停止提供。对接方需更新调用路径，并同步 API Gateway 资源。
- 基础 System API 和 Open API 在身份校验后新增 `system_access` 系统准入检查；IAM 回调仍使用独立 Basic Auth，不受该准入检查影响。原有功能、资源权限校验保持独立。

**发布范围**

- Backend/Control Plane：带外管理操作历史、当前字段查询、用户态 Open API 入口及 IAM 模型更新。
- Plugin/Package：旧版 V2 插件兼容性安装支持自定义运行和数据目录；资源包发布信息读取增加缓存。
- Installer/Deployment：初始化包导入支持 KMS JWT 签发，补齐 Helm Job 密钥挂载与环境变量。
- Frontend：新增带外管理操作历史及详情，优化管控区域创建引导和主控机选择范围。

**新增功能**

- 带外管理新增 Agent/Proxy 更新操作历史，可查看执行人、时间、节点角色及主机设置快照，支持按业务范围、操作 ID、执行人和时间筛选。
- 新增 Agent/Proxy 当前带外管理字段查询接口：`/api/v3/node/ops/list_fields/agent`、`/api/v3/node/ops/list_fields/proxy`，分别校验对应节点查看权限。任一请求主机不存在、已删除或不属于当前租户时，整个请求返回参数错误，不返回部分结果；成功时返回全部去重后的目标主机。
- Backend 新增 `/api/v3/open` 用户态 API 入口，支持通过 API Gateway 用户身份访问节点、插件、拓扑和资源包等接口。
- adminclient 新增 `jwt_token <service> <server>`，使用 KMS global envelope 中的服务 JWT 密钥签发 token；初始化包导入可自动使用该能力。

**功能优化**

- 资源包发布信息读取增加短时缓存并合并相同查询的并发请求；发布信息和默认版本变更在相关查询中可能延迟约 1 分钟体现。
- HTTP tracing 分别记录每次实际请求及错误，便于区分重试；服务端跳过 HEAD 请求的 tracing。
- 创建管控区域后，引导进入该区域配置管控单元；具有创建权限时自动打开新建入口。

**缺陷修复**

- 修复带外管理主控机选择器未遵循顶部所选业务范围的问题。
- 更新 Go toolchain 至 `1.26.10`，并更新 Excelize 及相关依赖，修复 Excelize `CVE-2026-107211` 安全问题。

**Agent / Plugin / Package compatibility**

- 旧版 V2 插件兼容性安装可通过 Backend `gseDeployConfs[*].pluginCustom.v2RunDir`、`v2DataDir` 指定最终目录；留空时沿用原有规则，普通 V3 插件安装不使用这两个配置。
- 同一 `generation`、`osType` 下的兼容性安装共享配置目录，不追加环境或插件目录层级；需避免共享数据目录中的同名文件冲突。修改配置不会自动迁移已部署插件的目录。

**组件依赖与升级前置条件**

- 带外管理接口迁移需配套升级 Backend、Application、Frontend 和 API Gateway 资源，避免继续调用已移除路径。
- 升级 Backend 前，IAM V3 环境需按 `0003 → 0004 → 0005` 重新同步模型，IAM V4 环境需重新同步 Action 和 Role 模型，并确认已有用户具备 `system_access`，必要时另行补授权。仅同步模型不会为全部已有用户自动补授权，否则可能导致升级后无法访问基础 API。
- KMS 部署使用初始化包导入时，需配套升级 chart 和包含新 adminclient 的 File 镜像，确保 Job 可读取 global envelope，并通过 `BK_NODEMGR_KMS_PRIVATE_KEY_GLOBAL` 获取私钥。非 KMS 部署沿用原有明文配置方式；KMS 模式签发的 token 有效期固定为 24 小时，`--expire-hours` 不生效。
- 使用旧版 V2 自定义目录前，需配置对应操作系统的部署项，并另行安排已部署插件的目录迁移；仅配置目录不会启用兼容性安装。
- 从源码构建服务需使用 Go `1.26.10`。

**已知问题**

- 直接刷新带外管理操作历史详情页时，执行人、操作时间和节点角色可能显示为 `--`；可返回历史列表后重新进入详情。
