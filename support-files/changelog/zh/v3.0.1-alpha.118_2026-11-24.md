## [Version: v3.0.1-alpha.118] - 2026-11-24

Full Changelog: [v3.0.1-alpha.117...v3.0.1-alpha.118](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.117...v3.0.1-alpha.118)

> 重要提示

- File 依赖文件传输请求调整了 Protobuf 字段编号；使用二进制 Protobuf 的集成方须与服务端同步升级客户端。HTTP JSON 调用字段不变。

**发布范围**

- Backend/Control Plane：插件分组查询、业务可见范围过滤、File 传输协议及服务端临时文件隔离。
- Application/Frontend：插件列表按分组筛选。
- Installer/Deployment：WMI 安装临时文件隔离。

**新增功能**

- 插件列表支持按分组多选筛选，默认选择 `default` 分组；切换业务后刷新可选分组，调整分组筛选时从第一页重新查询。
- 新增插件分组去重查询，提供应用态和用户态接口；按当前租户及调用方获准的业务范围返回分组，包含尚未安装到主机的插件，不受列表分页影响。

**缺陷修复**

- 修复插件列表及计数查询丢失业务可见范围条件的问题，按既有业务可见规则过滤查询结果。
- 修复临时目录路径被并发调用共享状态覆盖的问题，隔离 WMI 安装和文件导出等操作的临时文件目录。

**Agent / Plugin / Package compatibility**

- 本版本不变更 Agent、Plugin 或 Package 格式。
- Backend 插件依赖文件管理本版本仅提供协议定义，不提供可调用的管理或传输入口。
- File 依赖文件传输请求的 Protobuf 字段编号调整：`target_dir` 从 `3` 改为 `2`，`target_host_id` 从 `4` 改为 `3`。HTTP JSON 字段名不变；二进制 Protobuf 编解码不兼容旧编号。

**组件依赖与升级前置条件**

- 使用插件分组筛选时，配套升级 Backend、Application 与 Frontend；分组查询沿用 `system_access` 与 `plugin_view` 权限校验，不扩大业务授权范围。
- 通过 API Gateway 调用新增分组查询接口前，须另行导入、发布对应网关资源并配置调用授权；升级服务不会自动开放网关入口。
- 使用 File 依赖文件传输消息进行二进制 Protobuf 编解码的集成方，须重新生成客户端并与服务端同步升级，避免混用新旧字段编号。
