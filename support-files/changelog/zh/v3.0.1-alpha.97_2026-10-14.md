## [Version: v3.0.1-alpha.97] - 2026-10-14

Full Changelog: [v3.0.1-alpha.96...v3.0.1-alpha.97](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.96...v3.0.1-alpha.97)

**发布范围**

- Backend/Control Plane：新增部署策略只读预览，并支持按指定顺序预览配置策略。
- Frontend：新增和优化配置策略排序预览及相关策略管理体验。
- Operations/Deployment：调整包上传后的 Package 权限授予，并统一 Helm workload 的 ServiceAccount 配置。

**新增功能**

- 新增 `POST /api/v3/deploy_policy/preview` 只读接口，可预览已启用部署策略的计算状态，不执行变更。
- 配置策略预览支持通过启用策略 ID 顺序控制冲突优先级。
- 新增未分配管控区域 ID 配置，默认值为 `-1`。

**功能优化**

- 优化 Agent、Plugin 配置策略排序和预览行为。
- 优化部署策略计算及目标状态预览。
- 在 IAM V4 模式下，Package 上传成功后为上传者授予对应 Package 的管理权限。
- Helm chart 为各服务和同步 Job 统一设置 `serviceAccountName`，并支持通过 `serviceAccount` 配置指定账号和注解。

**缺陷修复**

- 修复配置策略预览和列表接口的错误处理问题。
- 修复预排序插件的 compatibility mode 传递问题。
- 修复配置策略优先级重排时的事件详情记录问题。
- 修复 Agent 和 Proxy 安装预览数据清空后，执行安装按钮仍可用的问题。

**Agent / Plugin / Package compatibility**

- 本版本不修改 Agent、Plugin 或 Package 包格式。

**组件依赖与升级前置条件**

- Helm chart 的 `serviceAccount.create` 默认值由 `true` 改为 `false`；未指定 `serviceAccount.name` 时，Workload 默认使用 Kubernetes 的 `default` ServiceAccount。需要继续使用专用 ServiceAccount 的环境，应在升级时显式设置 `serviceAccount.create: true`，或配置已有的 `serviceAccount.name`，并保留所需权限。
- Package 上传后的管理权限授予失败不会回滚已完成的上传；使用 IAM V4 时请确认对应角色授予能力可用。
