## [Version: v3.0.1-alpha.80] - 2026-09-04

Full Changelog: [v3.0.1-alpha.79...v3.0.1-alpha.80](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.79...v3.0.1-alpha.80)

**发布范围**

- Agent: Agent / Proxy 包格式保持兼容。
- Plugin: Plugin 安装流程支持绑定地址分配，并支持项目插件远程配置来源。
- Package: Package 插件包导出接口与导出结果查询能力更新。
- Backend/Control Plane: Backend 更新 Plugin Workflow API 文档与 Package Export API Gateway resources，并增强 redsync 与 GSE API 日志能力。
- Installer/Deployment: Helm 版本、API Gateway release metadata、API Gateway resources 与镜像版本对齐到 v3.0.1-alpha.80。

**新增功能**

- 新增 Backend 插件包导出接口，支持查询导出工作流结果与临时下载地址。
- Plugin 安装流程新增绑定地址分配能力。
- Deploy policy 支持项目插件远程配置来源。
- 安装表格支持批量编辑安装方式。

**功能优化**

- 优化插件操作弹窗、安装方式批量编辑与 IP selector 解析体验。
- 更新 Plugin Workflow API 文档，补充分页规则、部署策略字段与插件任务流类型说明。
- 增强 GSE API 调用日志，便于问题排查。

**缺陷修复**

- 修复 redsync 自动续期处理问题。

**Agent / Plugin / Package compatibility**

- Agent / Proxy 包版本随系统版本对齐到 v3.0.1-alpha.80。
- Plugin 与 Package 包格式保持兼容。

**组件依赖与升级前置条件**

- API Gateway release version / comment 对齐为 `3.0.1-alpha.80`。
- API Gateway resources 同步 Package Export Result 响应字段，将 `error_message` 调整为 `is_finish`。
- Helm chart version、appVersion、server image tag、apigw-sync image tag、mock-server image tag 对齐到 `v3.0.1-alpha.80`。
- 本版本不引入新增组件依赖。
