## [Version: v3.0.1-alpha.120] - 2026-11-26

Full Changelog: [v3.0.1-alpha.119...v3.0.1-alpha.120](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.119...v3.0.1-alpha.120)

**发布范围**

- Application/Frontend：Agent 和 Proxy 管理导航、多租户登录认证。
- Installer/Deployment：Helmfile 链路追踪导出配置。

**新增功能**

- Helmfile 支持通过 `env.yaml` 的 `opentelemetryGateway.exporters` 添加链路追踪导出端，将 traces 同时发送至内置 Tempo 和额外采集端，无需手动配置 traces pipeline。

**功能优化**

- Agent 状态、Proxy 状态导航及页面标题分别调整为 Agent 管理、Proxy 管理。

**缺陷修复**

- 修复多租户模式下因登录前尚未解析租户而导致的登录失败问题。用户信息查询使用应用认证，通过 `bk_token` 识别用户及其所属租户。

**Agent / Plugin / Package compatibility**

- 本版本不变更 Agent、Plugin 或 Package 格式。

**组件依赖与升级前置条件**

- `opentelemetryGateway.exporters` 默认为 `{}`，保留原有内置 Tempo 导出行为，无需修改现有配置。
- 配置额外导出端时，`otlp/tempo` 为内置 Tempo 保留名称；跨 namespace 转发使用 Service 完整 DNS，避免指回当前 Gateway 或形成转发环路。高级配置 `overrides/monitoring.yaml` 仍优先于模板生成配置。
