## [Version: v3.0.1-alpha.39] - 2026-06-15

Full Changelog: [v3.0.1-alpha.38...v3.0.1-alpha.39](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.38...v3.0.1-alpha.39)

**发布范围**

- Agent: Agent 状态页新增全业务在线、离线、未安装统计展示；安装、升级与重装流程保持兼容。
- Plugin: 插件任务在 Worker 关闭和操作记录缺失场景下的状态处理更稳健。
- Package: Agent / Plugin / Package 包格式保持兼容。
- Backend/Control Plane: 新增 REST Server 与 Workflow 优雅退出能力；优化跨管控单元 Proxy 安装流程；补齐拓扑图主机信息与状态回退逻辑。
- API / Gateway: 同步 topo 相关 Swagger 与 API Gateway resources，补齐拓扑图节点延迟信息结构。
- Frontend: 优化 Agent 状态页统计、IP Selector 拓扑筛选、管控单元延迟 tooltip 和上下游接入点提示。
- Installer/Deployment: Helm 新增默认 preStop lifecycle hook，并延长 Pod termination grace period 以支持优雅退出。

**新增功能**

- Backend REST Server 支持优雅退出，服务停止时会在配置的超时时间内等待请求完成。
- Workflow Worker 支持优雅退出，关闭期间可重试任务会延后重新调度，不可重试任务会明确终止。
- Helm 部署默认注入 preStop hook 与优雅退出超时配置，降低滚动升级时请求和任务被直接中断的风险。
- Agent 状态页支持展示当前选择业务范围内的在线、离线、未安装 Agent 数量。
- 跨管控单元 Proxy 安装支持 SSH-Only 模式，避免跨单元场景依赖中继安装路径。

**功能优化**

- IP Selector 拓扑筛选调整为 CMDB Set / Module 层级，主机查询支持按集群和模块过滤。
- 拓扑图管控单元延迟 tooltip 按机器分组展示 1min / 5min / 15min 延迟数据。
- 创建和编辑管控单元时，优化上游、下游接入点输入提示。
- 节点和插件包传输选项调整为显式禁用语义，减少只传安装器或制品包时的配置歧义。
- 补充服务配置 FAQ 与优雅退出设计文档，便于部署和运维确认配置含义。

**缺陷修复**

- 修复跨管控单元 Proxy 安装误走中继安装路径的问题，跨单元场景现在使用 SSH-Only 安装。
- 修复节点和插件 Workflow 操作记录缺失时状态无法可靠回落的问题，运行中 workflow 超过宽限时间后会回落为失败。
- 优化已完成 Workflow 的状态保护，避免操作记录被清理后覆盖已有终态。
- 调整 IP Selector 业务过滤数据，避免选择集群或模块时带入不相关业务范围。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本不改变 Agent / Plugin 运行时最低版本要求。
- 节点与插件部署信息中的 transfer options 调整为禁用语义，滚动升级期间请确认未完成 workflow 与历史部署记录的处理窗口。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
- Helm 默认 `terminationGracePeriodSeconds` 调整为 120 秒，并默认配置 `preStop: sleep 5`；如部署环境覆盖了 `terminationGracePeriodSeconds` 或 `lifecycleHooks`，升级前请确认自定义值仍满足优雅退出窗口。
- REST Server 与 Workflow 优雅退出默认超时时间为 60 秒；如运行长耗时任务，请结合业务窗口评估滚动升级节奏。
