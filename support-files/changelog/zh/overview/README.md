# 大版本概览

本目录存放独立编写的中文大版本概览，例如 `v3.0.1`。所有 `v3.0.1-alpha.*`、`v3.0.1-beta.*` 和 `v3.0.1-release.*` 迭代共用这份概览。

- 每个大版本维护一个 `<version>.md` 文件，例如 `v3.0.1.md`。内容变化时直接更新原文件；文件名和概览列表均不包含发布日期。
- 介绍该版本的整体能力、亮点及相关使用或兼容性边界，不逐条复制迭代变更。使用标准 Markdown 标题、列表和链接，不支持可执行 HTML 或脚本。
- 在 `../../en/overview/` 维护同名英文文档，保持两种语言的事实一致。
- 详细迭代日志仍存放在上级目录。同一版本的大版本概览与正式发布日志是两份独立文档。
- 文档由 `support-files/changelog/embed.go` 内嵌，修改后需要重新构建并部署 Application，不涉及数据库或 Wiki 配置。
- 界面默认打开当前所属大版本的“版本概览”。当前语言缺少对应文档时显示空态，不替换为其他版本，也不拼接迭代日志。用户仍可主动选择其他已有概览；“更新明细”保留原有迭代历史。

本 README 仅供文档维护者使用，不会作为大版本概览列出。
