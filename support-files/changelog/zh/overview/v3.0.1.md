# 蓝鲸节点管理 v3.0.1

蓝鲸节点管理 v3.0.1 围绕复杂网络下的节点接入、集中配置与插件管理，提供从 Agent 安装、网络拓扑管理到插件运行维护的一体化能力。通过管控单元组织接入路径，通过配置策略集中管理节点与插件配置，让不同网络、不同业务下的节点管理采用统一的操作方式。

## 灵活组织跨网络管控

以管控区域、管控单元和接入点组织节点接入，支持直连管理与多层级 Proxy 桥接，适应跨网络、隔离区域等不同部署环境。

- 在同一管控区域内，按实际网络条件划分直连和非直连管控单元。
- 通过接入点配置上游连接，分别组织控制、文件和数据通道。
- 结合拓扑图查看管控关系与连接延迟，辅助定位网络链路问题。

管控拓扑描述的是接入关系，实际使用仍需具备对应的网络连通条件；非直连节点的安装还需准备具备安装能力的 Proxy。

## 覆盖节点全生命周期

统一管理 Agent 和 Proxy 的安装、升级、配置重载、重启与卸载，结合任务记录跟踪操作过程和执行结果。

- 支持自动安装与手动执行安装命令；Proxy 支持离线安装，便于建立隔离网络中的首个接入节点。
- Windows Agent 支持 SSH 和 WMI 安装方式，适应不同的主机访问条件。
- 新安装页面支持批量录入 IPv4、IPv6，并通过 Excel 模板整理安装信息。
- 带外管理信息支持批量维护和 Excel 导入，逐行反馈解析结果。

安装前可预览参数；执行后可查看步骤日志和失败信息，便于确认结果、定位异常。Excel 导入带外管理信息后，仍需在页面提交才会保存。

## 集中管理节点与插件配置

通过配置策略统一管理 Agent、Proxy 和插件的配置，减少逐台维护配置的重复操作。

- 按适用范围匹配配置，满足不同节点和业务的配置需求。
- 调整策略优先级，并预览配置结果。
- 集中管理 Agent、Proxy 的 CPU、内存、脚本并发、数据压缩和文件任务等参数。

配置预览不会执行变更。

## 统一插件包与配置交付

将插件资源包、配置模板和主机上的运行实例分开管理，支持资源复用与差异化部署。

- 管理 Agent 包、Proxy 包、插件包、证书包和工具包的版本，支持插件及插件包的导入、导出。
- 插件支持多份主配置和子配置模板，结合自定义渲染上下文生成目标配置。
- 支持 V3 插件，并保留旧版 V2 插件的兼容管理能力。
- 插件包可声明安装过程中的 CPU、磁盘 IO 限速，控制安装和升级解包时的资源占用。

V2 兼容部署需要准备对应的旧版插件包，不等同于自动转换包格式；安装限速也不替代插件运行时的资源管理。

## 按租户与权限组织协作

面向多业务、多租户的协作，按租户隔离管理数据与制品，并按资源范围控制访问。

- 各租户独立管理插件启用状态、制品元数据和文件路径。
- 支持将 `system` 租户中的共享制品同步到其他租户，兼顾统一交付与租户自主维护。
- 提供节点、插件、配置策略、拓扑及资源包等管理或只读权限。
- 任务历史和资源操作记录按调用用户的授权范围查询。

IAM V3 与 IAM V4 的启用和授权需按环境配置，不会因服务升级自动完成权限体系切换或旧授权迁移。

## 开放集成与 AI 辅助查询

通过开放 API 对接自动化平台，并提供受用户权限约束的 MCP 查询能力。

- 拓扑查询覆盖业务拓扑、管控区域、管控单元、接入点和主机等对象。
- 执行诊断可查询节点与插件工作流、执行实例及步骤日志。
- AI 助手可借助 MCP 获取拓扑和任务信息，辅助理解环境、排查执行问题。

MCP 能力需在网关中配置并启用，查询仍受用户身份和资源权限约束；这些拓扑与执行诊断查询不提供修改、重试或终止操作。
