## [Version: v3.0.1-alpha.77] - 2026-08-28

Full Changelog: [v3.0.1-alpha.76...v3.0.1-alpha.77](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.76...v3.0.1-alpha.77)

**发布范围**

- Agent: Agent / Proxy 包格式保持兼容。
- Plugin: Deploy policy 支持按插件子配置模板生成 apply subconfig 任务，Plugin / Package 包格式保持兼容。
- Package: Package workflow API 与包格式保持兼容。
- Backend/Control Plane: Application API v3 新增 deploy_policy list / execute 代理入口；Backend DPMgr 支持 specify_plugin_sub_config_template 策略展开。
- Installer/Deployment: Helm 版本、API Gateway release metadata 与镜像版本对齐到 v3.0.1-alpha.77。

**新增功能**

- Application API v3 新增 deploy policy list / execute 入口，便于应用侧调用既有 Backend deploy policy 能力。
- Deploy policy 新增 plugin subconfig template 策略，支持按目标主机和模板内容生成 apply subconfig 任务。

**功能优化**

- Apply subconfig workflow 保留 ProcessConfig Set 和稳定配置实例名，提升配置持久化一致性。

**Agent / Plugin / Package compatibility**

- Agent / Proxy 包版本随系统版本对齐到 v3.0.1-alpha.77。
- Plugin 与 Package 包格式保持兼容；新增 plugin subconfig template 策略不改变既有包格式。

**组件依赖与升级前置条件**

- API Gateway release version / comment 对齐为 `3.0.1-alpha.77`。
- Helm chart version、appVersion、server image tag、apigw-sync image tag、mock-server image tag 对齐到 `v3.0.1-alpha.77`。
- 本版本不引入新增组件依赖。
