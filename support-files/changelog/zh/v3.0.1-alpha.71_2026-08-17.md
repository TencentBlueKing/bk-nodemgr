## [Version: v3.0.1-alpha.71] - 2026-08-17

Full Changelog: [v3.0.1-alpha.70...v3.0.1-alpha.71](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.70...v3.0.1-alpha.71)

**发布范围**
- Agent: 修正 Plugin 升级部署使用的目标版本，避免升级流程渲染到非预期版本。
- Plugin: Plugin / Plugin V2 部署渲染逻辑对齐目标版本选择，Plugin 包格式保持兼容。
- Package: 本版本不涉及 Package 发布语义或包格式变更。
- Backend/Control Plane: API 错误响应补充 trace-id 展示；UserManager 租户列表请求保持系统租户上下文；节点部署读取错误语义保持可追踪。
- Installer/Deployment: 对齐 Helm、API Gateway release metadata 与镜像版本到 v3.0.1-alpha.71。

**功能优化**
- API 错误信息展示 trace-id，便于运维人员按请求链路定位后端异常。
- 策略预览页面文案调整，提升策略配置确认时的可读性。

**缺陷修复**
- Plugin 升级部署渲染使用目标版本，避免升级任务继续引用非目标版本。
- UserManager 租户列表请求保持系统租户上下文，避免多租户场景下租户列表读取不稳定。
- 节点部署读取失败时保留原始错误语义，便于调用方识别失败原因。

**Agent / Plugin / Package compatibility**
- Agent / Proxy 包版本随系统版本对齐到 v3.0.1-alpha.71。
- Plugin 与 Package 包格式保持兼容。
- 本版本不要求变更既有 Plugin 包制作流程。

**组件依赖与升级前置条件**
- API Gateway release version / comment 对齐为 `3.0.1-alpha.71`。
- Helm chart version、appVersion、server image tag、apigw-sync image tag、mock-server image tag 对齐到 `v3.0.1-alpha.71`。
- 本版本不引入新增组件依赖。
