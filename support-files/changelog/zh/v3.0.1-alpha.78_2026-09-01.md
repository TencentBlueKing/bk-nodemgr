## [Version: v3.0.1-alpha.78] - 2026-09-01

Full Changelog: [v3.0.1-alpha.77...v3.0.1-alpha.78](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.77...v3.0.1-alpha.78)

**发布范围**

- Agent: Agent / Proxy 包格式保持兼容。
- Plugin: Deploy policy 新增项目级插件包与插件配置模板投放能力，Plugin / Package 包格式保持兼容。
- Package: Package workflow API 与包格式保持兼容。
- Backend/Control Plane: Backend 新增主机与进程同步时间，优化 deploy policy 过滤，复用 remove subconfig workflow，并支持 network area 0 自动创建直连网络单元。
- Installer/Deployment: Helm 版本、API Gateway release metadata、API Gateway resources 与镜像版本对齐到 v3.0.1-alpha.78。

**新增功能**

- Deploy policy 新增 project plugin package placement 与 project plugin config template placement 支持。
- Topology 与 process 查询 API 返回主机和进程最近同步时间。
- Network area 0 支持自动创建直连网络单元。

**功能优化**

- Deploy policy remove subconfig 场景复用既有 remove subconfig workflow。
- 补充插件包投放、插件配置模板投放与 init package import 的部署集成文档。

**缺陷修复**

- 修复 deploy policy 仅统计数量且未传 page 参数时的处理问题。
- 修复 force restart 不应通过 operate_agent 执行的问题。
- 移除部署 values 中的 legacy event data ID 配置。

**Agent / Plugin / Package compatibility**

- Agent / Proxy 包版本随系统版本对齐到 v3.0.1-alpha.78。
- Plugin 与 Package 包格式保持兼容。

**组件依赖与升级前置条件**

- API Gateway release version / comment 对齐为 `3.0.1-alpha.78`。
- API Gateway resources 已同步 Backend deploy_policy、process、topo API schema 变更。
- Helm chart version、appVersion、server image tag、apigw-sync image tag、mock-server image tag 对齐到 `v3.0.1-alpha.78`。
- 本版本不引入新增组件依赖。
