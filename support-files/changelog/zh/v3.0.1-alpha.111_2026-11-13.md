## [Version: v3.0.1-alpha.111] - 2026-11-13

Full Changelog: [v3.0.1-alpha.110...v3.0.1-alpha.111](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.110...v3.0.1-alpha.111)

> 重要提示

- Node、V3 Plugin 和旧版 V2 Plugin Installer 改为要求显式传入完整工作目录 `--work_dir`，不再通过 `--base_work_dir` 推导。管控面与 Installer 必须同步升级；直接调用 Installer 的自定义脚本也需同步调整参数。

**发布范围**

- Backend/Control Plane：节点与插件操作的按用户工作目录隔离、旧版 V2 插件进程状态同步，以及 File 服务的租户上下文修复。
- Application/Frontend：新安装主机时批量填写内网 IPv4／IPv6。
- Installer/Deployment：Installer 工作目录参数及目录权限管理调整。

**新增功能**

- 新安装页面支持按空格、逗号或换行批量填写内网 IPv4／IPv6，每个 IP 生成一台主机；重装和升级页面不展示该入口。
- 新增旧版 V2 插件进程状态同步能力：可按指定主机或全部主机触发存活／已停止进程同步，并新增每 10 分钟执行一次的已停止进程定时同步。接口返回 `trigger_id`，执行结果需查看工作流记录。
- 节点与插件操作按执行通道隔离 Installer 工作目录：SSH／WMI／手动安装使用登录用户目录，sudo 安装使用独立目录，GSE 通道操作使用操作用户目录，减少跨用户文件归属冲突。

**功能优化**

- 进程状态同步保留已成功查询并确认的主机结果，部分主机查询失败或超时不再导致整批结果被丢弃；未确认的目标不按已停止处理。

**缺陷修复**

- 修复多租户模式下 File 服务查询当前 GSE Endpoint 使用业务租户上下文的问题，改为使用系统租户，避免直连区域主机查询失败影响文件传输。

**Agent / Plugin / Package compatibility**

- 本版本不变更 Agent、Plugin 或 Package 格式。
- 新增 4 个旧版 V2 插件进程同步 API；既有 API 路径及请求／响应结构未调整。Installer 命令行兼容性以重要提示中的 `--work_dir` 调整为准。

**组件依赖与升级前置条件**

- 升级时确保管控面下发的 Installer 与本版本一致，不要混用旧版 Installer；已有自定义调用需将 `--base_work_dir` 改为包含用户隔离段的完整 `--work_dir`。
- 使用 API Gateway 的环境需同步本版本资源后再调用新增同步 API。同步任务为异步执行，接口成功不代表进程状态已同步完成。
