## [Version: v3.0.1-alpha.79] - 2026-09-03

Full Changelog: [v3.0.1-alpha.78...v3.0.1-alpha.79](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.78...v3.0.1-alpha.79)

**发布范围**

- Agent: Agent / Proxy 包格式保持兼容，Windows Agent SSH 安装方式可用性提升。
- Plugin: Deploy policy 自定义插件配置上下文处理更稳定，Plugin / Package 包格式保持兼容。
- Package: Package 新增导出文件 API 与导出存储链路。
- Backend/Control Plane: Backend 新增 Package 导出能力，修复安装方式自动值与插件安装包参数传递问题。
- Installer/Deployment: Helm 版本、API Gateway release metadata 与镜像版本对齐到 v3.0.1-alpha.79。

**新增功能**

- 新增 Plugin Package 导出文件 API，支持导出文件链路与存储能力。
- 新增 compact expiring token 生成能力，用于临时导出访问场景。

**功能优化**

- 简化 init package 配置流程。
- 前端暴露 tenant mode，并调整插件包快速过滤体验。
- Deploy policy 子配置模板决策与自定义配置上下文处理更加一致。

**缺陷修复**

- 修复 Windows Agent SSH 安装方式支持问题。
- 修复安装方式自动值与插件安装包参数传递问题。

**Agent / Plugin / Package compatibility**

- Agent / Proxy 包版本随系统版本对齐到 v3.0.1-alpha.79。
- Plugin 与 Package 包格式保持兼容。

**组件依赖与升级前置条件**

- API Gateway release version / comment 对齐为 `3.0.1-alpha.79`。
- 本版本未涉及 Backend API Gateway resources 同步。
- Helm chart version、appVersion、server image tag、apigw-sync image tag、mock-server image tag 对齐到 `v3.0.1-alpha.79`。
- 本版本不引入新增组件依赖。
