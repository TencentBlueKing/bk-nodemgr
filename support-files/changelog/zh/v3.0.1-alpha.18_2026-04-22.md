## [Version: v3.0.1-alpha.18] - 2026-04-22

Full Changelog: [v3.0.1-alpha.17...v3.0.1-alpha.18](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.17...v3.0.1-alpha.18)

**发布范围**

- Backend/Control Plane: 新增发布包批量部署统计、拓扑与安装相关 API，补齐 IAM v3 配置与多类路由鉴权
- Frontend: 新增 changelog 页面与版本日志能力，完善历史筛选、权限提示与安装流程交互
- Installer/Deployment: 调整 installer 配置获取链路，新增 full-debug 命令，更新 Helm chart 到 v3.0.1-alpha.18

**新增功能**

- 新增 changelog API 与发布说明页面，支持按版本读取中英文 changelog
- 新增发布包 brief 列表 API 与发布包部署数量批量查询 API，用于包管理和发布视图快速加载
- 新增拓扑能力，包括 access point brief、主机版本分布统计、networkunit 推荐与路径补全能力
- 新增配置策略（Config Policy）预览、排序、目标 IP 等能力，并补齐插件工作流与进程路由鉴权能力

**功能优化**

- 优化权限体系，统一 IAM callback 处理路径，收敛授权接口，并将更多操作切换为业务域与层级路径授权
- 优化节点与任务历史查询，支持更多筛选条件（IP、node_role）与筛选记忆能力
- 优化安装与升级链路，installer 优先拉取配置并支持 Windows 自定义 IPC 端口，降低跨环境安装失败率
- 优化拓扑与包管理交互，包括控制单元详情、刷新跳转与无权限占位提示

**缺陷修复**

- 修复业务选择器、拓扑图选择、权限弹窗层级路径展示等前端异常行为
- 修复任务详情时间不递增、日志详情不刷新、403 刷新后阻断后续 API 调用等可见问题
- 修复推荐 networkunit 调用错误、ConfigPolicyId=0 校验异常、时间戳零值处理不一致等后端问题
- 修复 wmic 与 jinja2 子进程残留问题，减少 Windows 与渲染链路中的僵尸进程风险
