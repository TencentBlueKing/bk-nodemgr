## [Version: v3.0.1-alpha.44] - 2026-06-25

Full Changelog: [v3.0.1-alpha.43...v3.0.1-alpha.44](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.43...v3.0.1-alpha.44)

**发布范围**

- Agent: 新增 Windows SSH 安装前检测动作，并修正 Proxy 安装模式选择。
- Plugin: 插件安装流程支持自定义部署规格，允许按任务传入资源与监控策略。
- Backend/Control Plane: 同步插件自定义部署规格的协议、存储与工作流渲染链路。
- API / Gateway: 同步 Agent / Proxy 安装请求 schema 与 Plugin 安装自定义规格 schema 到 API Gateway resources。
- Frontend: 请求拦截器使用 UUID 生成 request ID，提升链路追踪一致性。
- Installer/Deployment: Helm chart、服务镜像、mock-server 镜像和 apigw-sync metadata 对齐到本次发布版本。

**新增功能**

- 插件安装支持 `custom_spec`，可为单次插件部署指定资源限制和进程监控策略。
- Windows SSH 安装流程新增主机检测动作，安装前可补齐 Windows 主机信息检测。

**功能优化**

- 前端请求 ID 改为 UUID 生成，便于跨服务排查请求链路。
- API Gateway resources 同步本版本公开的安装请求 schema 变化。

**缺陷修复**

- 修复 Proxy 安装模式选择逻辑，避免特定安装场景下选择错误的安装路径。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本不改变 Agent / Plugin 运行时最低版本要求。
- 插件自定义部署规格为按需传入字段，不影响未传入 `custom_spec` 的既有插件安装请求。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
- 本版本更新 backend gateway resources，API Gateway release metadata 对齐到 `2.15.1`。
