## [Version: v3.0.1-alpha.21] - 2026-04-29

Full Changelog: [v3.0.1-alpha.20...v3.0.1-alpha.21](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.20...v3.0.1-alpha.21)

**发布范围**

- Backend/Control Plane: 新增操作实例超时检测与周期任务处理优化，按业务优化 Agent 同步流程，并增强 operation/operation instance 的查询与筛选能力
- Frontend: 补齐 install table 与状态表 address 字段展示，完善 assign unit 页面与插件安装流程交互，更新相关多语言与权限点
- Installer/Deployment: 调整 Helm 同步 Job 的 API version，并修复 application chart 配置 key 渲染

**新增功能**

- 支持在 install table 与状态表展示 address 信息，提升节点安装与状态排障时的定位效率
- 新增操作实例累计超时检测能力，用于识别长期积压的执行实例并触发对应处理流程

**功能优化**

- 优化插件安装流程与 assign unit 相关控制单元交互，减少页面操作路径中的重复动作
- 优化周期任务处理链路与 operation 查询条件能力，增强大规模场景下的任务筛选与执行稳定性
- 按业务维度优化 Agent 信息同步流程，降低同步链路中的无效处理开销

**缺陷修复**

- 修复 application chart 配置 key 渲染异常问题，避免配置项展示与解析不一致

**Agent / Plugin / Package compatibility**

- 无 Agent / Plugin / Package 版本范围或包格式调整

**组件依赖与升级前置条件**

- 本版本包含 proto 与 swagger 更新，若存在基于 API schema 的外部集成，请同步更新对应客户端或校验逻辑
- 本版本包含 Frontend 与 Backend/Control Plane 的联动变更，建议按同一发布窗口完成配套升级
- Helm 升级到 `v3.0.1-alpha.21` 时，需确认集群对同步 Job API version 的兼容性
