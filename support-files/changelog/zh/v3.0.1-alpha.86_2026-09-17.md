## [Version: v3.0.1-alpha.86] - 2026-09-17

Full Changelog: [v3.0.1-alpha.85...v3.0.1-alpha.86](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.85...v3.0.1-alpha.86)

**发布范围**

- Backend/Control Plane: Plugin、Package、Sync、Deploy Policy、IAM v4、Workflow、Tracing 相关处理。
- API Gateway: 新增 Sync 资源文档与资源定义。
- Installer/Deployment: Helm 与 docker-compose tracing 配置，内置 Tempo 与 OpenTelemetry Gateway 可选部署能力。

**新增功能**

- 新增手动触发默认 Plugin 补齐与共享 Release 同步的 Sync API，并补充 API Gateway 资源与中英文接口文档。
- 新增 OTLP HTTP tracing exporter 配置，支持通过 Helm 和 docker-compose 配置 tracing 输出。
- Helm Chart 新增可选内置 Tempo 与 OpenTelemetry Collector Gateway，用于节点管理自监控和 tracing 转发。

**功能优化**

- Package Release 响应补充名称字段，便于前端与 API 使用方展示制品信息。
- 优化插件卸载工作流中的进程配置清理，兼容 Plugin V2 卸载路径。
- 保留 IAM v4 授权资源属性，避免授权请求丢失资源上下文。

**缺陷修复**

- Release brief API 跳过 Package 权限校验，避免概要查询因包权限检查失败。
- 允许部署策略工作流 ID 为 0 的有效数据，避免错误过滤或中断。
- 跳过过期 workflow trigger cache，避免读取陈旧触发记录。
- 处理空的下游服务错误响应，避免错误信息丢失。

**Agent / Plugin / Package compatibility**

- 本版本不改变 Agent / Proxy、Plugin 或 Package 包格式。

**组件依赖与升级前置条件**

- Tempo 与 OpenTelemetry Gateway 为 Helm 可选能力，默认不启用。
- 本版本不引入强制升级前置条件。
