## [Version: v3.0.1-alpha.58] - 2026-07-23

Full Changelog: [v3.0.1-alpha.57...v3.0.1-alpha.58](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.57...v3.0.1-alpha.58)

**发布范围**

- Agent: Agent、Plugin、Package 包格式保持兼容。
- Backend/Control Plane: 主机同步查询、AgentID 过滤、触发器索引和并发变更校验得到优化，SSH 安装器轮询与日志上报逻辑集中复用。
- Frontend: 分配管理单元页面支持一键移除未分配的管控单元。
- Installer/Deployment: 部署资产需使用 v3.0.1-alpha.58。

**新增功能**

- 分配管理单元页面新增一键移除未分配管控单元的入口，降低清理无效分配关系的操作成本。

**功能优化**

- 触发器采集分类索引调整为 `{data.category: 1}` 并配合未删除数据过滤，支持清理和活跃触发器同步时复用新索引，避免重新创建旧索引。
- 主机同步任务生成优化 AgentID 非空过滤，减少空 AgentID 条件带来的低效查询。
- sync_host 完整 Host DB 查询切换到 ScanAllHostWithFields 和 DAO/storage scan-all 路径，避免 Count 加 UnlimitedPage List 的大批量查询模式。
- Backend 与 relay 的 SSH 安装器轮询、远程日志读取、状态解析和超时重连行为集中到共享 poller 路径，安装日志上报更一致。

**缺陷修复**

- 主机同步写入前会再次校验主机新增和删除结果，降低并发数据变化导致重复写入或误删除的风险。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本的同步、索引和安装器轮询调整不改变 Agent、Plugin、Package 包格式契约。

**组件依赖与升级前置条件**

- 升级部署资产时需使用 v3.0.1-alpha.58。
- 本版本不涉及 Backend API Gateway resources 同步，API Gateway release metadata 保持 `2.18.1 / v3.0.1-alpha.56`。
