## [Version: v3.0.1-alpha.90] - 2026-09-20

Full Changelog: [v3.0.1-alpha.89...v3.0.1-alpha.90](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.89...v3.0.1-alpha.90)

**发布范围**

- Backend/API: Sync API 触发器 ID 返回、插件进程状态持久化与过期进程状态纠正。
- Installer/Deployment: Helm Loki 日志采集与按 Kubernetes 版本处理内部流量策略。
- Documentation/Operations: tracing OTLP 协议配置、第三方 APIGateway 权限、APM 调试流程与 Helm 监控/日志采集说明。

**新增功能**

- Sync API 返回一次性工作流的 trigger ID。
- 新增插件进程观测状态存储操作。
- 新增纠正过期插件进程状态为 `unknown` 的 Sync API。
- Helm 新增 Loki 日志采集支持。

**功能优化**

- 补充 tracing OTLP 协议配置文档。
- 更新第三方 APIGateway 权限文档。
- 新增 bk-nodemgr APM 调试 skill 文档。
- 补充 Helm 自监控 Ingress 与 Loki 日志采集文档。

**缺陷修复**

- 记录进程观测时间戳。
- 恢复对托管态 unknown 插件进程的同步。
- 初始化缺失的 scheduled workflows。
- 修复插件移除子配置前端类型映射，避免列表为空和详情显示原始标识。
- 按 Kubernetes 版本保护 Helm internal traffic policy 配置。

**Agent / Plugin / Package compatibility**

- Sync API 响应数据使用 `trigger_id` 返回工作流触发器 ID。
- 本版本不改变 Agent / Proxy、Plugin 或 Package 包格式。

**组件依赖与升级前置条件**

- Loki 日志采集与 tracing OTLP 协议配置均为可选能力，启用前应确认相关部署 values。
- Helm internal traffic policy 处理现在遵循 Kubernetes 版本。
