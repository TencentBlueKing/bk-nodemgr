## [Version: v3.0.1-alpha.49] - 2026-07-02

Full Changelog: [v3.0.1-alpha.48...v3.0.1-alpha.49](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.48...v3.0.1-alpha.49)

**发布范围**

- Agent: Agent、Plugin、Package 运行时行为与上一 alpha 版本保持兼容。
- Backend/Control Plane: 修复同步纠正 Agent ID 流程中的主机查询方式。
- Frontend: 网络管控区域推荐使用首个主机 IP，优化分配相关交互展示。
- Installer/Deployment: Helm chart、服务镜像、API Gateway sync 镜像、mock-server 镜像对齐到本次发布版本。

**新增功能**

- 网络管控区域推荐逻辑支持优先使用首个主机 IP，提升分配场景中的默认推荐准确性。

**缺陷修复**

- 修复同步纠正 Agent ID 流程中的主机查询方式，确保使用统一的主机列表查询能力。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本不改变 Agent / Plugin 运行时最低版本要求。
- 存量节点无需额外升级动作。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
- 本版本未更新 backend swagger 文件，不涉及 API Gateway resources 同步；API Gateway release metadata 保持不变。
