## [Version: v3.0.1-alpha.74] - 2026-08-27

Full Changelog: [v3.0.1-alpha.73...v3.0.1-alpha.74](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.73...v3.0.1-alpha.74)

**发布范围**

- Agent: Agent / Proxy 包格式保持兼容。
- Plugin: 新增 Plugin start API 与前端入口，补充 Plugin debug 工作流与说明文档。
- Package: 新增 Plugin / Package 导入导出能力，并修复 Package 平台匹配判断。
- Backend/Control Plane: 补齐 tenant-aware 用户、鉴权、UserManager、GSE、CMDB 与 API Gateway 上下文传递，修复定时任务租户上下文与部分异常路径。
- Installer/Deployment: reinstall 流程支持 proxy、install source 与 install_method 相关调整，并对齐 Helm、API Gateway release metadata 与镜像版本到 v3.0.1-alpha.74。

**新增功能**

- Plugin 管理支持 start API 与前端操作入口。
- Plugin / Package 支持导入导出，便于跨环境同步与运维交付。
- Plugin debug 工作流补充配套文档，覆盖调试、导入、配置策略与 access package 场景。

**功能优化**

- reinstall 流程补充 proxy、install source 与 install_method 参数支持，提升重装场景的安装来源表达能力。
- tenant-aware 上下文贯穿用户、鉴权、UserManager、GSE、CMDB 与 API Gateway 调用链路。
- 前端时间戳按 timezone 展示，并优化 IP 选择器交互。
- 补充 ipchooser、import、debug、config policy 与 access package 相关文档。

**缺陷修复**

- 修复定时工作流执行时租户上下文丢失的问题。
- 修复 Package 平台相等判断异常。
- 修复 operation controller 空值路径可能触发 panic 的问题。
- 修复用户展示名翻译异常。

**Agent / Plugin / Package compatibility**

- Agent / Proxy 包版本随系统版本对齐到 v3.0.1-alpha.74。
- Plugin 与 Package 包格式保持兼容。

**组件依赖与升级前置条件**

- API Gateway release version / comment 对齐为 `3.0.1-alpha.74`。
- Helm chart version、appVersion、server image tag、apigw-sync image tag、mock-server image tag 对齐到 `v3.0.1-alpha.74`。
