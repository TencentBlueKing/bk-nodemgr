## [Version: v3.0.1-alpha.116] - 2026-11-20

Full Changelog: [v3.0.1-alpha.115...v3.0.1-alpha.116](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.115...v3.0.1-alpha.116)

> 重要提示

- Application Excel 接口调整为不兼容变更：移除 `GET /api/v3/node/{agent,proxy}/install_template/download` 和 `POST /api/v3/node/{agent,proxy}/install_template/upload`，统一使用 `POST /api/v3/excel/{agent_install_template,proxy_install_template,ops_template}/{parse,download}`。Application 与 Frontend 必须同步升级，直接调用旧接口的集成方需同步迁移。
- Application 内嵌 Wiki 改为默认关闭。依赖该入口的部署需显式启用 `application.config.wiki.enabled=true`（Application 直接配置为 `wiki.enabled=true`），并保持用户可访问 `/wiki/`；该开关不会自动切换 Backend 的文档链接模式，`github` 模式不受影响。
- IAM V3 Helm 同步新增 `iamV3.option.allowActionReplace`，默认 `false`。设为 `true` 将允许清理策略、删除并重建资源绑定发生变化的 Action；已有授权不会自动迁移，策略删除不可逆，关闭开关或回退 Chart 均不能恢复已删除的策略。

**发布范围**

- Backend/Control Plane：Backend 客户端主机列表分页修复。
- Application/Frontend：统一 Excel 模板接口、带外设置 Excel 导入、内嵌 Wiki 开关及 Excel 处理依赖更新。
- Installer/Deployment：Windows SSH Installer 路径修复及 IAM V3 Helm 同步参数接入。

**新增功能**

- 新增统一 Excel 模板下载与解析接口，覆盖 Agent 安装、Proxy 安装和带外设置，逐行返回解析结果与错误原因，单行失败不阻塞其他行。
- 带外设置页面支持 Excel 导入，按业务、管控区域和内网 IP 匹配已有主机，将成功行回填到页面表格；导入不会直接保存设置，仍需在页面提交。

**功能优化**

- Excel 处理依赖 `excelize` 升级至 `v2.11.1`。

**缺陷修复**

- 修复 Windows SSH Installer 工作目录未统一转换为斜线路径的问题。
- 修复 Backend 客户端主机列表查询未按接口限制分批分页的问题。
- 修复 Helm IAM V3 模型同步 Job 未传递 Action 替换参数的问题；显式启用开关后，安装／升级 Job 传入 `--allow-action-replace`，复用迁移脚本已有能力。

**Agent / Plugin / Package compatibility**

- 本版本不变更 Agent、Plugin 或 Package 格式；Windows 变更仅涉及 SSH Installer 工作目录路径处理。
- Excel 解析结果统一为 `data.items`，不再使用旧安装模板的 `data.info`；每行包含 `row_index` 和 `error_message`。新版模板前三行依次为表头、必填标注和填写说明，数据从第 4 行开始，升级后建议重新下载模板。

**组件依赖与升级前置条件**

- Backend 使用 `application` 文档链接模式时，升级前显式启用 Application Wiki，并确保外部入口将 `/wiki/` 转发到 Application、`prefixURL` 指向用户可访问的文档地址；关闭 Wiki 前需另行调整 Backend 链接配置。
- IAM V3 替换开关作用于本次全目录同步中所有发生资源绑定变化的 `upsert_action`，不限于单个 Action。启用前确认目标系统、租户及全部绑定变更，使用包含 `--allow-action-replace` 支持的 server 镜像；策略删除要求 IAM SaaS ≥ 1.4.15、后台 ≥ 1.7.7。完成后重新配置并验证受影响权限，再将开关恢复为 `false`。详细限制与失败恢复见 [IAM V3 迁移工具](https://github.com/TencentBlueKing/bk-nodemgr/blob/v3.0.1-alpha.116/support-files/bkiamv3/README.md#显式替换-action-资源绑定)。
