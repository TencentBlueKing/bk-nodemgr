## [Version: v3.0.1-alpha.57] - 2026-07-22

Full Changelog: [v3.0.1-alpha.56...v3.0.1-alpha.57](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.56...v3.0.1-alpha.57)

**发布范围**

- Agent: Agent、Plugin、Package 包格式保持兼容；节点完整卸载支持 skip-callback 路径。
- Backend/Control Plane: 拓扑查询切换到 brief cache 路径，主机同步写入保持幂等，主机 upsert 复用已匹配的 host ID，基础 MongoDB ORM 新增 ORM ScanAll。
- API/Documentation: 新增配置策略优先级重排 API 文档，拓扑 API 文档同步适配 brief topology response。
- Frontend: 拓扑调用适配 brief topology response 字段。
- Installer/Deployment: 部署资产需使用 v3.0.1-alpha.57。

**新增功能**

- 拓扑查询切换到 brief cache 路径，减少重复完整拓扑查询。
- 节点完整卸载支持 skip-callback 处理，Proxy 卸载流程对齐 skip report 行为。
- 基础 MongoDB ORM 新增 ORM ScanAll，支持共享 DAO 代码扫描完整查询结果。

**功能优化**

- 主机 upsert 复用已匹配的 host ID，减少同步过程中产生重复主机记录。
- 配置策略优先级重排 API 文档已补充，方便 API 调用方对接。

**缺陷修复**

- 主机同步写入保持幂等，避免重复同步产生不一致写入结果。
- 节点完整卸载在需要 skip callback 的工作流中可正确跳过 callback 处理。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 完整卸载 skip-callback 与 Proxy skip report 处理仅更新工作流行为，不改变包格式契约。

**组件依赖与升级前置条件**

- 升级部署资产时需使用 v3.0.1-alpha.57。
- 本版本不涉及 Backend API Gateway resources 同步，API Gateway release metadata 保持 `2.18.1 / v3.0.1-alpha.56`。
