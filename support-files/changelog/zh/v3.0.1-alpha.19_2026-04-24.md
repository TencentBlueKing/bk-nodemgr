## [Version: v3.0.1-alpha.19] - 2026-04-24

Full Changelog: [v3.0.1-alpha.18...v3.0.1-alpha.19](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.18...v3.0.1-alpha.19)

**发布范围**

- Backend/Control Plane: 拆分插件工作流路由并补齐操作鉴权，调整 syncdata workflow 动作超时，新增 operation 表索引
- Frontend: 优化策略排序配置详情页 JSON 展示，补齐业务无权限场景占位与拓扑默认网络区域申请入口
- Installer/Deployment: 更新 application/backend/file 监控面板，对齐 Helm ServiceMonitor 端口配置

**新增功能**

- 插件工作流相关 list / distinct / operation 路由统一接入鉴权，按业务维度过滤 history view 范围，并对 operate 类操作增加业务级权限校验

**功能优化**

- 优化策略排序配置详情页 JSON 弹窗，新增行号、语法高亮与括号配色，并放宽弹窗宽度，提升可读性
- 优化业务无权限场景：节点与策略页面在无任一业务 `biz_access` 权限时直接展示无权限占位页；biz-selector 在无授权业务时隐藏 “全部业务” 文案
- 优化拓扑无权限提示，复用统一的 `bk-exception` 占位组件，并默认申请默认网络区域权限，减少手动选择步骤
- 优化 syncdata workflow 动作超时配置：`gen_oper_sync_*` 系列由 10s 调整为 10m，`sync_*` 系列由 1m 调整为 5m，降低大业务量场景下的同步动作超时失败率
- 新增 operation 集合 `parent_operation_id` 索引，加速按父操作维度的查询
- 更新 application、backend、file 服务的 Grafana 监控面板，统一切换到蓝鲸监控数据源，并对齐 Helm `ServiceMonitor` 中 backend / file 服务的采集端口为 `info-http`，恢复指标采集

**Agent / Plugin / Package compatibility**

- 无 Agent / Plugin / Package 相关版本范围或包格式调整

**组件依赖与升级前置条件**

- Helm chart 升级至 `v3.0.1-alpha.19`，建议同步更新 ServiceMonitor 与 Grafana 数据源配置以恢复监控面板
- 插件工作流相关接口在升级后会按业务粒度做 IAM 鉴权，需提前确认相关用户具备目标业务的 `plugin_history_view` / `plugin_operate` 权限
