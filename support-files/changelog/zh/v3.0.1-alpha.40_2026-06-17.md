## [Version: v3.0.1-alpha.40] - 2026-06-17

Full Changelog: [v3.0.1-alpha.39...v3.0.1-alpha.40](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.39...v3.0.1-alpha.40)

**发布范围**

- Agent: 配置策略选项新增 CPU / 内存使用限制、脚本并发、数据压缩和文件传输相关参数；Agent 运维字段支持同步与批量更新。
- Plugin: 插件任务历史页补充说明文案；Plugin 运行与包格式保持兼容。
- Package: Agent / Plugin / Package 包格式保持兼容。
- Backend/Control Plane: 新增 Agent / Proxy 运维字段批量更新 API，支持将带外管理信息写入本地 DB 并同步到 CMDB；CMDB 主机同步流程补齐运维字段回写。
- API / Gateway: 同步 Agent / Proxy 运维字段更新接口的 proto、Swagger 与 API Gateway resources。
- Frontend: 任务历史页新增 Agent、Proxy、Plugin tab 说明并规范异常 tab 参数；拓扑图管控单元延迟 tooltip 支持按机器展示 IP 与 1min / 5min / 15min 延迟。
- Installer/Deployment: Helm 调整模块级 image tag 配置结构，拆分 apigw-sync 镜像配置，并补齐独立 image pull secrets 处理。

**新增功能**

- Agent / Proxy 支持通过 `update_ops_fields` 接口批量更新运维字段，包括运维平台主机 ID、带外类型、带外协议、BMC IP 和 BMC 端口。
- CMDB 主机同步支持将运维字段初始化到节点动态信息，避免首次同步后本地数据缺少带外管理信息。
- 配置策略新增 Agent / Proxy 的 CPU 使用限制、内存使用限制、脚本并发、数据压缩和文件任务参数选项。

**功能优化**

- Helm 的 apigw-sync Job 使用独立 `apiManagerImage` 配置，便于单独设置仓库、tag、pull policy 和 pull secrets。
- Helm 中 application、backend、file 模块的镜像 tag 配置调整为 `image.tag` 结构，和其他镜像配置层级保持一致。
- 拓扑图延迟 tooltip 增加主机 IP 展示，便于定位具体机器的 1min / 5min / 15min 延迟。
- 任务历史页根据 Agent、Proxy、Plugin tab 展示说明文案，并将非法 tab 参数回落到 Agent 历史页。
- 服务优雅退出文档调整为按 Kubernetes、REST、Workflow 分层说明时间预算与退出语义。
- 仓库补充 bk-nodemgr Go coding skills，便于后续开发、评审和维护统一使用项目约束。

**缺陷修复**

- 修复拓扑图延迟数据从字符串数组调整为结构化数据后，前端类型和 tooltip 展示不一致的问题。
- 修复任务历史页接收非法 active tab 参数时页面状态不稳定的问题。
- 优化 Workflow 长尾 action 关闭处理分支，避免可重试和不可重试路径混杂。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本不改变 Agent / Plugin 运行时最低版本要求。
- 配置策略新增项默认未启用，升级后不会自动改变既有 Agent / Proxy 运行参数。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
- Helm values 中 `application.imageTag`、`backend.imageTag`、`file.imageTag` 调整为 `application.image.tag`、`backend.image.tag`、`file.image.tag`；升级前请同步自定义 values。
- Helm apigw-sync 镜像配置由 `apigwSync.repository` / `apigwSync.imageTag` 调整为独立 `apiManagerImage`；如环境单独覆盖 apigw-sync 镜像，请同步配置路径。
