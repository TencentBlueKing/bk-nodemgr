## [Version: v3.0.1-alpha.66] - 2026-08-06

Full Changelog: [v3.0.1-alpha.65...v3.0.1-alpha.66](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.65...v3.0.1-alpha.66)

**发布范围**

- Agent: Agent、Plugin、Package 包格式保持兼容。
- Plugin: 新增 Plugin release 查询与可见性控制能力。
- Package: 新增 Package release 查询能力，并补充 Package workflow storage。
- Backend/Control Plane: 主机列表、业务选择器、安装表、CMDB 请求代理、API Gateway release metadata 和 API Gateway resources 得到更新。
- Frontend: 业务选择器性能、长文本提示和前端构建命令得到优化。
- Installer/Deployment: 部署资产需使用 v3.0.1-alpha.66，Installer 默认启用 debug 日志。

**新增功能**

- Package release distinct 查询支持按 name 和 version 返回去重结果。
- Plugin release 增加 distinct 查询能力。
- Plugin package release 增加可见性控制。
- Package workflow 增加 storage 能力。
- Deploy policy workflow 增加来源记录能力。
- 密码 key 的加密方式已调整。

**功能优化**

- 业务选择器性能得到优化，并增加长文本 tooltip。
- 主机列表 API 中 IP 查询字段位置得到调整。
- 前端 Docker build 命令已匹配当前发布构建流程。
- Installer 默认输出 debug 日志，便于安装问题排查。

**缺陷修复**

- Agent strategy scope 文案得到澄清。
- CMDB 请求改由 virtual user 代理，修复相关调用身份问题。
- Host static updates 使用 DAO 类型处理路径。
- API Gateway release metadata 对齐到 `3.0.1-alpha.66`。
- Install table 支持自动填充 login port。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- Plugin release 与 Package release 查询能力向后兼容已有调用。
- 本版本不引入 Package 格式升级要求。

**组件依赖与升级前置条件**

- API Gateway resources 已包含本版本需要同步的 `pkg.swagger.json` 变更。
- API Gateway release version 使用 `3.0.1-alpha.66`。
- 本版本不引入新的外部组件依赖。
