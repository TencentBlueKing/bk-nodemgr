## [Version: v3.0.1-alpha.68] - 2026-08-14

Full Changelog: [v3.0.1-alpha.67...v3.0.1-alpha.68](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.67...v3.0.1-alpha.68)

**发布范围**
- Agent: 新增 Windows 自动安装 workflow，并支持 Agent / Proxy 批量分配管控区域能力。
- Plugin: 本版本不涉及 Plugin 包格式变更，既有 Plugin 发布兼容性保持不变。
- Package: Package 发布可见性语义调整为 hidden-state，并同步 API Gateway 资源说明。
- Backend/Control Plane: 增加多租户集合隔离、远程文件下载、发现注册预校验、API Gateway 同步与权限配置修正。
- Installer/Deployment: 对齐 Helm、API Gateway release metadata 与镜像版本到 v3.0.1-alpha.68，并补充外部 MongoDB 与 Redis Cluster 部署说明。

**新增功能**
- 支持 Windows 自动安装 workflow，扩展 Windows Agent 安装流程能力。
- 支持 Agent / Proxy 批量分配管控区域接口，减少多节点分配操作成本。
- 新增远程文件下载接口，并提供共享 HTTP downloader 能力。
- AccessPoint、NetworkArea、NetworkUnit、PackageEvent 集合按租户拆分，增强多租户数据隔离。
- 增加默认 cipher storage 确保接口，并在保存进程配置时保留自定义 config context。

**功能优化**
- Package 发布可见性从 `is_visible` 调整为 hidden-state 语义，接口与 API Gateway 资源描述保持一致。
- 拆分 metrics dashboard presets，降低仪表盘预置内容维护成本。
- 补充 discover package、process config、Redis Cluster queue isolation、installation / thirdparty API Gateway 权限等部署与运维文档。
- 移除未使用的 CMDB `searchObject` 接口，并统一 discover provider 命名。

**缺陷修复**
- 发现注册批量请求增加预校验，减少无效请求进入后续处理链路。
- 修复操作级失败时部分重试 start index 计算问题。
- Helm runtime values 参数化，避免运行时配置被固定在 chart 中。
- API Gateway 同步请求补齐 tenant id，并切换为 UserManager API Gateway 配置。

**Agent / Plugin / Package compatibility**
- Agent / Proxy 包版本随系统版本对齐到 v3.0.1-alpha.68。
- Plugin 包格式与既有发布兼容性保持不变。
- Package release hidden-state 接口语义已通过 API Gateway 资源同步发布，对接方需按新字段语义读取可见性状态。

**组件依赖与升级前置条件**
- API Gateway release version / comment 对齐为 `3.0.1-alpha.68`。
- Helm chart version、appVersion、server image tag、apigw-sync image tag、mock-server image tag 对齐到 `v3.0.1-alpha.68`。
- 使用外部 MongoDB 或 Redis Cluster 的部署环境可参考本版本补充的 Helm values 与 queue isolation 文档完成配置核对。
