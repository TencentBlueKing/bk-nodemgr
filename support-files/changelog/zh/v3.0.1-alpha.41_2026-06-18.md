## [Version: v3.0.1-alpha.41] - 2026-06-18

Full Changelog: [v3.0.1-alpha.40...v3.0.1-alpha.41](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.40...v3.0.1-alpha.41)

**发布范围**

- API / Gateway: API Gateway 同步配置补充关联应用配置，便于网关发布时识别当前应用。
- Installer/Deployment: Helm apigw-sync Job 补齐资源配置，并调整发布阶段默认值，避免未显式配置时限定到 stage。
- Documentation: 补充 Helm 部署场景下 API Gateway 同步 FAQ，便于排查和执行网关同步。

**功能优化**

- Helm apigw-sync Job 复用初始化容器资源配置，便于统一控制同步任务资源请求和限制。
- API Gateway 同步脚本默认不再固定发布到 stage，支持通过环境变量按需指定发布阶段。
- 发布对齐检查脚本补充文件范围、版本字段和 API Gateway resources 同步校验，降低发版遗漏风险。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本不改变 Agent / Plugin 运行时最低版本要求。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
- 如部署环境依赖 apigw-sync 自动发布到指定 stage，请通过 `RELEASE_STAGES` 显式配置目标发布阶段。
