## [Version: v3.0.1-alpha.92] - 2026-09-24

Full Changelog: [v3.0.1-alpha.91...v3.0.1-alpha.92](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.91...v3.0.1-alpha.92)

**发布范围**

- Installer/Deployment: 调整启用 Alloy 后的节点管理容器日志发现范围。

**缺陷修复**

- 修复 Helm Chart 中 Alloy 日志发现使用固定 namespace 的问题：默认发现当前 Helm release 所在 namespace 的 Pod；Helmfile 部署会指定 application、backend、file 三个业务 namespace。

**Agent / Plugin / Package compatibility**

- 本版本不修改 Agent、Plugin 或 Package 包格式。

**组件依赖与升级前置条件**

- 使用 Alloy 采集跨 namespace 的节点管理日志时，请在 `alloy.nodemgrNamespaces` 中指定实际业务 namespace；Alloy 默认保持关闭。同一 namespace 中容器名匹配 `bk-nodemgr-(application|backend|file)` 的非节点管理容器也可能被采集。
