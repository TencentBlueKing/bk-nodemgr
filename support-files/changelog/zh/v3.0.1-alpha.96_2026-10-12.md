## [Version: v3.0.1-alpha.96] - 2026-10-12

Full Changelog: [v3.0.1-alpha.95...v3.0.1-alpha.96](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.95...v3.0.1-alpha.96)

**发布范围**

- Backend/Control Plane: 扩展节点卸载和拓扑主机统计 API 的请求参数。
- Frontend: 统一 Agent 和 Proxy 统计与筛选条件中的状态文案。
- Operations: 更新 release verification 和 source archive signing 说明。
- CLI: 新增部分运维流程的 manual CLI 支持。
- Installer: 为服务端和工具安装器新增显式 HTTP proxy 覆盖与跳过支持。

**新增功能**

- 节点 Agent 或 Proxy 卸载成功后，支持解绑主机 AgentID 关系。
- 业务主机统计接口支持按节点角色过滤。
- 新增部分 Node Manager 操作的 manual CLI 支持。
- 安装器支持使用指定 HTTP proxy，或显式跳过 proxy 设置。

**功能优化**

- 补充 API Gateway 文档中的节点角色权限和主机统计过滤说明。
- 优化管控单元创建后的权限刷新，并限制 trigger 查询范围。
- 优化策略管理表单行为和拓扑筛选集成。

**缺陷修复**

- 修复创建管控单元后权限数据未刷新的问题。
- 修复 trigger 查询可能不受数量上限约束的问题。
- 修正节点安装器等待日志文案。
- 修复策略管理验收问题。
- 修复带 timezone offset 的 notice 时间解析问题。

**Agent / Plugin / Package compatibility**

- 本版本不修改 Agent、Plugin 或 Package 包格式。

**组件依赖与升级前置条件**

- Helm 部署默认保持现有 installer proxy 行为，不引入额外升级前置条件。
