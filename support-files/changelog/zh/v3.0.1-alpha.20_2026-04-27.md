## [Version: v3.0.1-alpha.20] - 2026-04-27

Full Changelog: [v3.0.1-alpha.19...v3.0.1-alpha.20](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.19...v3.0.1-alpha.20)

**发布范围**

- Backend/Control Plane: 新增 Proxy assign unit 相关 API、流程动作与路由注册，增强 OpenTelemetry（分布式追踪）配置能力，重构并修复 global settings（全局设置）注册逻辑，优化 syncdata 同步任务并发与性能
- Frontend: 新增并联调插件安装与 plugin operation 页面流程，补齐 Proxy assign unit 页面与交互，更新相关多语言与类型定义
- Installer/Deployment: Helm 模板为同步 Job 增加 revision 与 `ttlSecondsAfterFinished` 配置，并更新多服务 deployment 配置项

**新增功能**

- 支持 Proxy assign unit 能力，覆盖 application/backend 两侧 API、路由与 workflow 动作，实现按单元分配 Proxy 的操作链路
- 新增 plugin operation 页面及步骤化流程，完善插件安装相关的前端入口与执行预览能力

**功能优化**

- 增强 OpenTelemetry 可观测能力，补充 tracing 配置项与处理逻辑，便于排查跨服务请求链路
- 基于 global settings 优化 syncdata 任务性能，增加并发控制并调整相关同步动作执行策略，降低大规模场景下同步耗时与拥塞风险
- 优化工作流执行链路的调度与处理逻辑，提升稳定性与吞吐表现

**Agent / Plugin / Package compatibility**

- 无 Agent / Plugin / Package 版本范围或包格式调整

**组件依赖与升级前置条件**

- 本版本包含新增 Node Proxy API 字段与流程能力，升级后需确保 backend/application 服务与前端版本保持一致发布
- 本版本包含 proto 与 swagger 更新，若存在基于 API schema 的外部集成，请同步更新对应客户端或校验逻辑
- Helm 升级到 `v3.0.1-alpha.20` 时，建议核对同步 Job 的 `revision` 标识与 `ttlSecondsAfterFinished` 清理策略是否符合当前集群的 Job 保留和排障要求
