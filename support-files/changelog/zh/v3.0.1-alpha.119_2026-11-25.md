## [Version: v3.0.1-alpha.119] - 2026-11-25

Full Changelog: [v3.0.1-alpha.118...v3.0.1-alpha.119](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.118...v3.0.1-alpha.119)

> 重要提示

- GSE Proxy 网络参数新增全局配置。Linux Proxy 的 Bind IP/端口会优先采用 `gseDeployConfs[*].custom`，并新增 V1 File Agent、Topology Thrift、File/Data Metric Exporter 端口；修改后须重启 Backend，已有 Proxy 节点还需重新下发配置。
- File 服务新增 `file.config.userManager`，用于解析配置的 `gse.user`。蓝鲸平台 7.3 的 `single` 和 `multiple` 模式均需配置用户管理网关与应用凭证；蓝鲸平台 7.2 的 `single` 模式须在 Backend、Application、File 三个服务同步设置 `userManager.useLegacyUsername: true`。
- 新增 Backend 业务配置只读查询接口；调用方须具备 `platform_manage` 权限，资源类型为 `platform_resource`、资源 ID 为 `system_config`。通过 API Gateway 调用前需另行导入并发布网关资源。

**发布范围**

- Backend/Control Plane：GSE Proxy 全局网络参数、hostid 自主推送、业务配置查询、插件进程状态过期修正、File 用户解析、插件工作流过滤与临时文件清理。
- Application/Frontend：中英文 Excel 模板、表格筛选搜索、管控区域/单元 ID 展示、历史任务与插件操作交互修复。
- Installer/Deployment：Helm、Helmfile 与 Docker Compose 增加 GSE Proxy 和 File 用户管理配置；Linux 工具不再使用 UPX 压缩。

**新增功能**

- Agent、Proxy 与 Ops Excel 模板支持中英文，根据 `blueking_language` Cookie 选择模板语言，未指定时使用中文。
- 新增 Backend 业务配置只读查询，提供应用态 `/api/v3/system_config/get` 和用户态 `/api/v3/open/system_config/get`；返回租户模式、IAM 开关、GSE 安装默认值等白名单配置，不返回凭据、连接端点或代理地址。
- GSE Proxy 支持全局配置网络参数，覆盖 Proxy 发布包 env 中的默认值；配置仅对 Linux 生效。
- 支持 `gseDeployConfs[*].pluginCustom.hostIDPushMode: self`，由节点管理生成并通过 GSE 推送 hostid；默认仍为 `cmdb`。
- 表格列筛选支持搜索；Agent 列表与管控区域/单元表格展示 `[ID] 名称`。
- 插件工作流操作列表支持按 `bk_host_innerip`、`bk_host_innerip_v6` 精确过滤。

**功能优化**

- V3 与 V2 运行中插件进程支持按 alive-sync 周期过期修正，新增 `oper_correct_running_process_status_expiry_cycles` 和 `oper_correct_running_process_v2_status_expiry_cycles` 全局配置，默认 3 个周期。
- File 同步共享版本时同步启用状态与默认版本状态，避免源租户变更后目标版本状态不一致。
- 插件文件清理在 Unix/Windows 下增加指数退避重试；WMI 安装与文件临时目录在成功和失败路径均清理自身创建的文件和目录。
- 分配 Proxy 管控单元时仅安装 `bk-nodemgr-relay`，不再安装预置监控插件。
- Linux 工具禁用 UPX 压缩，避免旧内核或受限环境下的启动崩溃。

**缺陷修复**

- 修复 Agent/Proxy 安装表单 IPv4、IPv6 二选一校验错误未及时清除的问题。
- 修复节点历史任务日期筛选恢复时间戳导致 DatePicker 报错的问题。
- 修复任务详情轮询重建表格后已勾选任务丢失的问题。
- 修复插件操作预览将未分配管控单元显示为 `[0]` 的问题。
- 修复 Proxy 重载场景仍显示无损/超时选项，未固定使用强制重启的问题。
- 修复业务选择器按页面操作权限过滤业务、导致与业务可见范围不一致的问题。
- 修复虚拟用户认证错误被吞掉后继续发送空用户名请求的问题。
- 修复配置策略优先级出现在工作流日志中的问题。
- 修复 File 服务未按用户管理 lookup 解析配置 `gse.user` 的问题。

**Agent / Plugin / Package compatibility**

- 本版本不变更 Agent、Plugin 或 Package 格式。
- `hostIDPushMode: self` 仅在安装流程中推送一次，hostid 内容仅包含节点管理可确定的字段（主机 ID、管控区域 ID、首个内网 IP、Agent ID、寻址方式、租户 ID）；后续业务拓扑、进程变化不会同步，不提供 `cmdb` 模式的周期性同步能力。
- `hostIDPushMode` 仅接受 `cmdb` 或 `self`，留空等同 `cmdb`；非法值会导致 Backend 启动失败。
- GSE Proxy 全局网络参数仅用于 Linux；非 Linux Agent 不受影响。

**组件依赖与升级前置条件**

- 使用新增业务配置查询接口时，升级 Backend，并导入、发布对应 API Gateway 资源，为调用方配置 `system_config` 的平台管理权限。
- 使用插件工作流 IP 过滤时，需同步更新并发布 API Gateway 资源；升级服务不会自动开放网关入口。
- 升级 File 服务前配置 `file.config.userManager`。蓝鲸 7.3 的单租户和多租户模式均通过用户管理 lookup 解析 `login_name`；蓝鲸 7.2 单租户须在三个服务中同步设置 `useLegacyUsername: true`，多租户不支持该兼容开关。
- 修改 GSE Proxy 全局网络参数后重启 Backend，并对已有 Proxy 节点重新下发配置；端口可设为 0（使用默认值）或 1-65535，且最终取值互不冲突。
- 新增插件进程过期配置有默认值，无需手工初始化；可按 alive-sync 周期调整。
