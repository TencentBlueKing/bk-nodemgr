## [Version: v3.0.1-alpha.51] - 2026-07-07

Full Changelog: [v3.0.1-alpha.50...v3.0.1-alpha.51](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.50...v3.0.1-alpha.51)

**发布范围**

- Agent: Agent、Plugin、Package 包格式保持兼容。
- Backend/Control Plane: Relay proxy 安装支持 SSH-only 部署场景。
- Frontend: tab 数量较多的页面展示更稳定。
- Installer/Deployment: Helm chart、服务镜像、API Gateway sync 镜像、mock-server 镜像对齐到 v3.0.1-alpha.51。

**新增功能**

- Relay proxy 安装支持 SSH-only 部署，覆盖仅依赖 SSH 访问完成 proxy 安装的环境。

**功能优化**

- Helm release 依赖迁移到 bitnamilegacy 来源，保持 chart dependency 兼容性。
- common chart 版本锁定为 2.31.4，保证部署包版本一致。
- 复用共享的 retry backoff 计算逻辑，让 retry 等待时间行为保持一致。

**缺陷修复**

- 修复页面 tab 单元过多时 tab 展示异常的问题。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本不改变 Agent / Plugin 运行时最低版本要求。

**组件依赖与升级前置条件**

- 升级部署资产时，Helm chart、服务镜像、API Gateway sync 镜像、mock-server 镜像需使用 v3.0.1-alpha.51。
- 本版本 backend swagger 文件不变，不涉及 API Gateway resources 同步；API Gateway release metadata 保持不变。
