## [Version: v3.0.1-alpha.62] - 2026-07-29

Full Changelog: [v3.0.1-alpha.61...v3.0.1-alpha.62](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.61...v3.0.1-alpha.62)

**发布范围**

- Agent: Agent、Plugin、Package 包格式保持兼容。
- Backend/Control Plane: Stopping operation instance Change Stream watch scope 和 TTL index initialization 得到优化。
- API Gateway: 本版本不涉及 Backend API Gateway resources 同步，release metadata 保持 `2.18.2 / v3.0.1-alpha.61`。
- Developer Experience: Mongo business integration tests、CodeCC/golint maintenance annotations 和 logger package maintenance guidance 得到更新。
- Installer/Deployment: 部署资产需使用 v3.0.1-alpha.62。

**功能优化**

- Stopping operation instance watch 范围收敛到所属 Mongo database 和 collection，减少停止操作流程中的无关 Change Stream events。
- Stopping operation instance TTL index creation 调整为 DAO 初始化阶段执行，确保 upsert 流量进入前具备过期停止操作数据清理能力。
- Mongo business integration tests 迁移到 `testsuite/support` isolated databases，降低 package-level integration testing 对固定环境的耦合。
- Logger package maintenance guidance 补充包职责、logging category 规则、structured fields 和 operational compatibility surfaces，方便后续维护。
- CodeCC/golint maintenance 更新 comments、naming 和 NOCC annotations，不改变运行时行为。

**缺陷修复**

- Stopping operation instance Change Stream matching 补充 namespace constraints，watcher 只响应目标 database 和 collection 的变更。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本仅调整 Backend maintenance 和 testing assets，不改变包格式契约。

**组件依赖与升级前置条件**

- 升级部署资产时需使用 v3.0.1-alpha.62。
- 本版本不涉及 Backend API Gateway resources 同步，API Gateway release metadata 保持 `2.18.2 / v3.0.1-alpha.61`。
- 本版本不为 Agent、Plugin、Package rollout 引入新的组件前置条件。
