## [Version: v3.0.1-alpha.25] - 2026-05-14

Full Changelog: [v3.0.1-alpha.24...v3.0.1-alpha.25](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.24...v3.0.1-alpha.25)

**发布范围**

- Agent: 无功能变更。
- Proxy: 无功能变更。
- Plugin: 无功能变更。
- Package: 无独立发布包格式或协议字段变更。
- Backend/Control Plane: 优化 post process 列表查询链路和 host 同步更新逻辑的执行性能。
- Installer/Deployment: 无额外安装器参数或部署流程变更。

**功能优化**

- Backend workflow post process 列表操作优化查询与存储访问路径，在高频列表场景下减少不必要的数据处理开销。
- `sync_host` 更新链路优化主机数据更新逻辑，降低全量或批量同步过程中的处理负担。

**缺陷修复**

- 本版本未引入独立的用户可感知缺陷修复项，主要为性能与执行效率优化。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package compatibility 与 `v3.0.1-alpha.24` 保持一致，本次未新增协议兼容性要求。
- 本次优化集中在 Backend 内部 workflow/storage 与 host DAO 路径，不要求 Agent 或 Plugin 侧做额外版本适配。

**组件依赖与升级前置条件**

- 建议与现网 `Backend/Control Plane` 配套发布，确保 workflow 与 host 同步链路在同一版本代码上运行。
- 若生产环境存在高频 post process 列表查询或大规模主机同步任务，建议先灰度验证查询耗时与同步耗时指标再全量升级。
