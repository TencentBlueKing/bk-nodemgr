## [Version: v3.0.1-alpha.29] - 2026-05-22

Full Changelog: [v3.0.1-alpha.28...v3.0.1-alpha.29](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.28...v3.0.1-alpha.29)

**发布范围**

- Agent: Agent 安装请求结构新增是否保留关键运行时文件的控制字段。
- Proxy: Proxy 安装请求结构新增是否保留关键运行时文件的控制字段。
- Plugin: 新增 Plugin V2 workflow/action 支持，覆盖安装、卸载、重启、停止等 V2 流程能力。
- Package: 无已知 Package 格式破坏性变更。
- Backend/Control Plane: 补齐 host sync 事件缺失 agentid 的处理路径，优化 process command tag 与配置表字段对齐。
- API / Gateway: 同步 renew_gse_task 与 renew_gse_proc 请求 schema 字段，用于控制是否保留关键运行时文件。
- Installer/Deployment: 优化节点安装器脚本渲染与复用逻辑，保留运行时文件以提升安装与卸载流程稳定性。

**新增功能**

- Plugin V2 workflow/actions 能力扩展，支持更多 V2 操作场景并保持对现有流程的增量兼容。
- 节点部署链路支持配置是否保留关键运行时文件，并在 node agent/proxy 安装请求结构中暴露对应字段。

**功能优化**

- 节点安装器优化脚本渲染与复用流程，并保留关键运行时文件，减少重复生成和运行中断风险。
- install table 与相关前端展示逻辑优化，缓解性能卡顿并改进显示一致性。
- 清理过时 APIGW 前端设置，减少无效配置影响。

**缺陷修复**

- 修复 host sync 场景中缺失 agentid 时的处理问题，降低同步失败概率。
- 修复 process command tag 与配置表字段不一致导致的行为偏差。

**Agent / Plugin / Package compatibility**

- 依据当前变更证据，未发现 Agent、Plugin、Package 包格式破坏性变更。
- Plugin V2 workflow 支持为增量能力，现有流程可继续使用。

**组件依赖与升级前置条件**

- 节点安装器运行时文件保留会影响安装器行为路径，但当前证据未显示需要新增组件依赖。
- API / Gateway 请求 schema 已同步 renew_gse_task 与 renew_gse_proc 字段，升级时需确保调用方按是否保留关键运行时文件的语义传参。
