## [Version: v3.0.1-alpha.117] - 2026-11-23

Full Changelog: [v3.0.1-alpha.116...v3.0.1-alpha.117](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.116...v3.0.1-alpha.117)

> 重要提示

- 定时任务调度的查询、启用和停用新增 `platform_manage` 权限校验，资源类型为 `platform_resource`、资源 ID 为 `scheduler_workflow`。升级时须同步 IAM V3 或 V4 模型并配置相应授权，仅有 `system_access` 不再满足访问要求。
- MCP 内置清单改为通过 `apigwSync.mcp.enabled=true` 同步并启用，默认关闭。此前仅使用 `ENABLE_SYNC_MCP_SERVERS=true` 继承默认清单的部署，须迁移到新开关，或显式保留完整的 stage MCP 定义及状态；Chart 与 apigw-sync 镜像须配套升级。
- 内置模式会为未显式配置 `mcp_servers` 的 stage 启用 `topo`、`execution` 和 `system-diagnosis`。全局配置查询返回跨租户共享的数据库原始值，不脱敏，可能包含敏感自定义配置；仅向获准的内部维护应用和人员授权，并限制结果的记录和转发。

**发布范围**

- Backend/Control Plane：历史安装参数查询、调度权限与执行诊断、全局配置只读查询。
- Application/Frontend：从 Agent / Proxy 安装历史回填新安装表单。
- Installer/Deployment：MCP 产品清单、同步开关与 stage 覆写、IAM 平台管理模型及 Helm 部署升级文档。

**新增功能**

- Agent / Proxy 安装任务详情支持选择历史操作，将可恢复参数回填到新安装表单；用户确认并补齐参数后，按正常安装流程创建独立的新任务，不重试或修改历史任务。
- 定时任务调度支持查询操作、执行实例、步骤及额外执行日志，并按派发实例下钻直接子操作；应用态接口与用户态只读诊断入口均保留租户和任务链归属校验。
- 新增全局配置列表查询，支持分页、名称过滤和计数；提供应用态接口及 `system-diagnosis` 用户态 MCP 工具。查询只读取数据库已保存值，不补默认值，不代表进程当前实际生效配置，也不提供修改或删除。
- `topo`、`execution` MCP 支持个人令牌客户端；`system-diagnosis` 的 personal/public OAuth 客户端仍关闭，个人令牌不能替代网关调用授权和用户业务权限。
- 新增面向使用者的执行排障 Skill，支持通过执行诊断 MCP 或对应用户态 API 查询节点与插件任务、实例和日志，不执行重试、终止或其他变更操作。

**功能优化**

- MCP 产品清单与 stage 配置分离：显式非空 `mcp_servers` 完整覆写内置清单、不合并字段；显式 `[]` 仅跳过该 stage 的同步，不删除或停用已有 MCP。需要停用时须提交完整定义并设置 `status: 0`。
- 完善 Helm 安装、升级、回滚及版本化 values 迁移文档，说明 Hook 同步副作用和持久化数据恢复边界。

**Agent / Plugin / Package compatibility**

- 本版本不变更 Agent、Plugin 或 Package 格式。
- 历史安装回填不复制密码、私钥、密码库凭据 ID 或部署 Token，仍需按正常安装流程提供凭据并校验权限。历史记录不是完整请求快照：内网 IPv6 等缺失项需补齐，失效或冲突的业务、管控区域、管控单元和目标版本需重新确认，不会自动替换为最新版本。
- 调度诊断仅覆盖当前触发器关联且尚未清理的任务链，不提供完整历史归档；调度配置启用或父实例成功均不代表子任务执行成功。

**组件依赖与升级前置条件**

- 使用历史安装回填时，配套升级 Backend、Application 与 Frontend，避免新页面调用未升级的参数查询接口。
- 提供系统诊断前，启用并同步 IAM V3 或 V4，核对既有应用授权及平台资源通配授权。调度使用 `scheduler_workflow`，全局配置使用独立的 `global_settings` 资源授权；不能通过关闭 IAM 业务鉴权提供这些入口。
- 使用 MCP 前，按原流程发布所需用户态网关资源并配置应用、用户和资源调用权限。新开关要求 `spec_version: 2`，优先于旧 MCP 同步环境变量，但不会自动启用同步 Job 或改变发布策略；显式清单不会自动加入新工具。详细迁移与授权要求见 [API Gateway 同步说明](https://github.com/TencentBlueKing/bk-nodemgr/blob/v3.0.1-alpha.117/docs/faq/apigw-sync.md)。
- Helm 升级应按 [升级指南](https://github.com/TencentBlueKing/bk-nodemgr/blob/v3.0.1-alpha.117/install/helm/bk-nodemgr/UPGRADE.md) 合并环境覆盖参数并备份数据；Helm rollback 不撤销 MongoDB、BKRepo、IAM 或网关已完成的变更。
