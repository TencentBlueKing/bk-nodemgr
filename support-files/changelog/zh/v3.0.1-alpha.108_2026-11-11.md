## [Version: v3.0.1-alpha.108] - 2026-11-11

Full Changelog: [v3.0.1-alpha.107...v3.0.1-alpha.108](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.107...v3.0.1-alpha.108)

> 重要提示

- IAM V4 自动替换 Action 绑定需显式启用，执行方式为删除旧 Action 后重建，不级联清理依赖。角色或授权等依赖导致 IAM 拒绝删除时，同步停止，不自动扩大级联范围；旧授权不会自动迁移，失败不自动回滚已写入的 IAM 模型。

**发布范围**

- Backend/Control Plane：IAM V4 模型迁移工具新增可选的 Action 绑定自动替换能力。
- Installer/Deployment：Helm IAM V4 同步 Job 增加替换开关；补充 API Gateway 同步租户 warning 排障文档。

**新增功能**

- IAM V4 迁移工具新增 `--allow-action-replace`，默认关闭。启用后，`upsert_action` 遇到资源绑定冲突时复用 `replace_action` 的默认无级联删除重建流程；未启用时仍拒绝绑定变化。
- Helm 新增 `iamV4.option.allowActionReplace`，默认 `false`；设为 `true` 后，IAM V4 同步 Job 传入 `--allow-action-replace`。

**功能优化**

- 补充 API Gateway 同步中重复租户 warning 的说明：该提示本身不代表租户配置错误或同步失败；租户正确且同步成功时无需修改配置或重跑 Job。本次仅更新排障文档，不改变 SDK 的 warning 行为。

**Agent / Plugin / Package compatibility**

- 本版本不变更 Agent、Plugin 或 Package 格式。

**组件依赖与升级前置条件**

- 使用 Helm 替换开关需配套升级 Chart 与 Backend 镜像；迁移工具随 Backend 镜像提供，旧工具不支持新增参数。
- 启用前核对目标系统、租户、受影响角色及授权范围；替换后同步角色并核验授权。`--dry-run` 仅查询模型和输出计划，不调用删除接口，不能证明 IAM 服务端依赖允许删除。
- 操作步骤与恢复限制见 [IAM V4 模型迁移说明](https://github.com/TencentBlueKing/bk-nodemgr/blob/v3.0.1-alpha.108/support-files/bkiamv4/README.md#显式替换-action-绑定)。
