## [Version: v3.0.1-alpha.113] - 2026-11-17

Full Changelog: [v3.0.1-alpha.112...v3.0.1-alpha.113](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.112...v3.0.1-alpha.113)

> 重要提示

- Application 的 `/wiki/` 文档路由可免登录访问，不受 Backend Wiki 链接模式影响；请勿在产品 Wiki 中放置敏感信息。文档以原始 Markdown 返回，不提供 HTML 渲染。

**发布范围**

- Backend/Control Plane：V3 插件部署策略的主配置下发修复。
- Application/Frontend：Application 提供随产品内嵌的双语用户 Wiki。
- Installer/Deployment：新增 Wiki 的 Application 链接模式及访问入口配置，调整 API Gateway 拓扑 MCP 分类。

**新增功能**

- 产品用户 Wiki 支持由 Application 在 `/wiki/` 提供本地访问；无法访问 GitHub 的环境可将任务日志中的指引链接切换到 Application，无需访问外网阅读随产品交付的文档。

**功能优化**

- API Gateway 的拓扑只读查询 MCP 服务 `topo` 归入 `Official` 分类。

**缺陷修复**

- 修复 V3 插件部署策略仅变更自定义配置渲染上下文、插件版本未变时主配置未重新下发的问题。策略执行时会重新渲染、下发对应主配置并重载进程，无需升级插件包；执行结果需查看工作流记录。

**Agent / Plugin / Package compatibility**

- 本版本不变更 Agent、Plugin 或 Package 格式。
- 既有业务 API 路径及请求／响应结构未调整。

**组件依赖与升级前置条件**

- Wiki 链接默认仍为 `github` 模式，存量部署无需额外配置即可升级。
- 启用 Application 链接模式时，在 Helm values 中设置 `backend.config.wiki.mode=application`，并将 `backend.config.wiki.application.prefixURL` 设置为用户可访问的绝对 HTTP(S) 文档地址前缀，例如 `https://nodemgr.example.com/wiki/`；同时确保访问入口将 `/wiki/` 转发至本版本 Application 服务，不要使用集群内服务地址作为用户链接。
