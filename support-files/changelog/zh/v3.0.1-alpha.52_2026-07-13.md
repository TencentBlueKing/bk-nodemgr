## [Version: v3.0.1-alpha.52] - 2026-07-13

Full Changelog: [v3.0.1-alpha.51...v3.0.1-alpha.52](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.51...v3.0.1-alpha.52)

**发布范围**

- Agent: Agent、Plugin、Package 包格式保持兼容；Agent / Proxy 安装请求支持显式选择安装方式。
- Backend/Control Plane: 支持静态拓扑关系记录、管控区域校验与自定义策略限制，并优化主机列表查询。
- Frontend: 补充跳转链接、页面提示、拓扑页面与自定义部署字段展示。
- Installer/Deployment: Helm chart、服务镜像、API Gateway sync 镜像、mock-server 镜像对齐到 v3.0.1-alpha.52，并同步 API Gateway resources。

**新增功能**

- Agent / Proxy 安装请求新增 `install_method`，支持按场景显式选择 `ssh` 或 `wmi`（Agent Windows 场景适用），未传值时保持原有自动选择行为。
- Windows Agent 安装链路新增自动检测动作，减少手工判断安装方式的成本。
- 新增 admin 未分配管控区域同步运维能力，并记录静态拓扑关系，便于后续拓扑与主机关联管理。
- 前端补充跳转链接、操作提示、自定义部署字段与拓扑页面展示，提升节点管理操作可见性。

**功能优化**

- 优化主机列表查询索引与主机字段更新流程，提升大规模主机列表查询效率。
- Installer 增强目标信息采集与诊断日志，便于定位安装链路问题。
- Helm 依赖与部署资产继续对齐 Bitnami 依赖来源，保持部署包一致性。
- 进程侧滑页补充非默认版本提示，管控区域与自定义策略校验更明确。

**缺陷修复**

- 修复 Installer 目标信息采集调用点覆盖不完整的问题。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- `install_method` 为可选字段；默认或空值保持原有自动选择安装方式，不影响已有调用方。

**组件依赖与升级前置条件**

- 升级部署资产时，Helm chart、服务镜像、API Gateway sync 镜像、mock-server 镜像需使用 v3.0.1-alpha.52。
- 本版本同步 `node_agent` / `node_proxy` 安装请求 schema 到 API Gateway resources，API Gateway release metadata 更新为 `2.17.1 / v3.0.1-alpha.52`。
