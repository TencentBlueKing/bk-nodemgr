## [Version: v3.0.1-alpha.37] - 2026-06-05

Full Changelog: [v3.0.1-alpha.36...v3.0.1-alpha.37](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.36...v3.0.1-alpha.37)

**发布范围**

- Agent: 本版本不涉及 Agent 运行时行为变更。
- Plugin: 本版本不涉及 Plugin 配置或运行时行为变更。
- Package: 本版本不涉及 Agent / Plugin / Package 包格式变更。
- Backend/Control Plane: 修复节点部署信息渲染逻辑，Proxy 专用端口现在只在 Proxy 节点上渲染。
- API / Gateway: 本版本不涉及对外 API 契约、Swagger 或 API Gateway 资源定义变更。
- Frontend: 本版本不涉及前端页面变更。
- Installer/Deployment: 本版本不涉及部署参数变更。

**缺陷修复**

- 修复普通 Agent 节点渲染部署信息时尝试读取 Proxy 专用端口的问题，避免非 Proxy 节点因缺少 Proxy 端口预设而中断部署流程。
- Proxy 节点渲染 Proxy 集群端口、数据端口和文件端口失败时，现在返回更明确的错误信息，便于定位配置问题。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本仅调整 Backend/Control Plane 对节点部署信息的渲染逻辑，不改变 Agent、Plugin 或 Package 的版本兼容范围。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
- 升级后请关注新建或重装节点的部署流程，Proxy 端口配置仅对 Proxy 节点生效。
