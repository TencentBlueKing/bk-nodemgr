## [Version: v3.0.1-alpha.48] - 2026-07-01

Full Changelog: [v3.0.1-alpha.47...v3.0.1-alpha.48](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.47...v3.0.1-alpha.48)

**发布范围**

- Agent: Agent、Plugin、Package 运行时行为与上一 alpha 版本保持兼容。
- Backend/Control Plane: 同步流程复用 batch executor，修复主机列表逻辑，并确保 IP 选择后的数据回填。
- Frontend: 修复带外管理国际化展示与状态统计过滤冲突，优化分配与 Proxy 详情交互。
- Installer/Deployment: Helm chart、服务镜像、mock-server 镜像对齐到本次发布版本。

**功能优化**

- 后端同步流程与分配单元接口复用 batch executor，减少重复批处理路径。
- 优化前端分配、Agent 列表、带外详情和 Proxy 信息交互。

**缺陷修复**

- 修复带外管理页面的国际化展示问题。
- 修复 Agent 状态统计过滤时的状态冲突问题。
- 修复安装与同步流程使用的主机列表逻辑问题。
- 修复 IP selector 选择后数据未回填的问题。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本不改变 Agent / Plugin 运行时最低版本要求。
- 存量节点无需额外升级动作。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
- 本版本未更新 backend swagger 文件，不涉及 API Gateway resources 同步；API Gateway release metadata 保持不变。
