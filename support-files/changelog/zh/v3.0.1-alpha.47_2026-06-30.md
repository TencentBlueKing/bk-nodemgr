## [Version: v3.0.1-alpha.47] - 2026-06-30

Full Changelog: [v3.0.1-alpha.46...v3.0.1-alpha.47](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.46...v3.0.1-alpha.47)

**发布范围**

- Agent: Agent、Plugin、Package 运行时行为与上一 alpha 版本保持兼容。
- Backend/Control Plane: 新增 relay proxy SSH protocol scaffold，更新 GSE 版本识别规则，并修复 CMDB 主机关系批量查询。
- Frontend: 调整 delayed popup 展示高度，优化页面交互体验。
- Installer/Deployment: 统一 installer endpoint 来源选择，并将 Helm release values 对齐到本次发布版本。

**功能新增**

- 新增 relay proxy SSH protocol scaffold，为 relay proxy SSH 接入能力提供基础。

**功能优化**

- 统一安装流程中的 installer endpoint 来源选择。
- 更新 GSE 版本正则，提升版本识别范围。
- 调整前端 delayed popup 展示高度。

**缺陷修复**

- 修复 CMDB 集成中的主机关系批量查询处理问题。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本不改变 Agent / Plugin 运行时最低版本要求。
- 存量节点无需额外升级动作。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
- Helm release values 对齐到 `v3.0.1-alpha.47`。
