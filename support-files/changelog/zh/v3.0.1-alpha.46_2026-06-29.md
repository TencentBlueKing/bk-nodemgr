## [Version: v3.0.1-alpha.46] - 2026-06-29

Full Changelog: [v3.0.1-alpha.45...v3.0.1-alpha.46](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.45...v3.0.1-alpha.46)

**发布范围**

- Agent: 新增带 proxy 支持的直连 SSH 安装能力，并支持兼容老旧 Windows SSH 服务的 SSH MAC 算法。
- Backend/Control Plane: 新增 correct-agent-id、dynamic-agent-id 同步流程，新增租户维度 GSE event data ID，基于 CMDB 的节点带外信息管理，并更新 GSE 版本正则。
- Plugin: 修正插件卸载与升级时的 installer endpoint 选择，调整插件策略创建页配置项。
- Frontend: 优化 Agent 状态展示覆盖范围、agent/proxy 状态统计过滤、包管理默认版本提醒以及带外信息展示。
- Installer/Deployment: Helm chart、服务镜像、mock-server 镜像对齐到本次发布版本。

**功能新增**

- 新增带 proxy 支持的直连 SSH 安装，覆盖更多节点安装场景。
- 新增租户维度 GSE event data ID。
- 新增兼容老旧 Windows SSH 服务的 SSH MAC 算法支持。
- 新增 correct-agent-id 同步流程，以及对更新主机的 dynamic agent id 同步。
- 新增基于 CMDB 的节点带外信息管理，包含 zone、city 等信息。
- 包管理中未设置默认版本时新增前端提醒。

**功能优化**

- 更新 GSE 版本正则，提升版本识别范围。
- 调整插件策略创建页的配置项。
- 对齐 agent 与 proxy 状态统计的过滤条件，修复 proxy 状态列表分页切换问题。

**缺陷修复**

- 修复插件卸载与升级时的 installer endpoint 选择问题。
- 修复 wmiexec 与 jinja2_exec 临时二进制路径自愈问题。
- 前端 Agent 状态展示覆盖完整的 backend NodeStatus 取值。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本不改变 Agent / Plugin 运行时最低版本要求。
- 存量节点无需额外升级动作。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
- 本版本针对节点运行时字段同步 API Gateway resources，并将 API Gateway release metadata 更新为 `2.15.2 / v3.0.1-alpha.46`。
