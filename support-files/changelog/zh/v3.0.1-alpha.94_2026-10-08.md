## [Version: v3.0.1-alpha.94] - 2026-10-08

Full Changelog: [v3.0.1-alpha.93...v3.0.1-alpha.94](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.93...v3.0.1-alpha.94)

**发布范围**

- Frontend: 更新前端依赖元数据，用于处理 npm security alerts。
- Installer/Deployment: 修复 Helm chart 启动校验中的 MongoDB 连通性检查。

**功能优化**

- 增加前端 npm Dependabot security alerts 的处理覆盖。

**缺陷修复**

- 修复 Helm initContainer MongoDB 检查生成缺少 URI scheme 的 MongoDB 连接串，导致 `mongosh` 拒绝连接的问题。

**Agent / Plugin / Package compatibility**

- 本版本不修改 Agent、Plugin 或 Package 包格式。

**组件依赖与升级前置条件**

- 使用 Helm 部署并执行内置 MongoDB readiness checks 时，启动校验将使用修正后的 MongoDB URI 格式。
