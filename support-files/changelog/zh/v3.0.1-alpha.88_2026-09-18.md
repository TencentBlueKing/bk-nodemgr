## [Version: v3.0.1-alpha.88] - 2026-09-18

Full Changelog: [v3.0.1-alpha.87...v3.0.1-alpha.88](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.87...v3.0.1-alpha.88)

**发布范围**

- Frontend: Plugin、Package、节点列表、拓扑授权展示与 Plugin 无权限处理调整。
- Backend/Control Plane: Deploy Policy 目标渲染、拓扑授权、Package Event 过滤、IAM v4 授权日志、CMDB 管控区域删除处理与存活进程同步检查。
- Installer/Deployment: Helm 可选 Grafana、Tempo 与 OpenTelemetry Collector Gateway 能力，并更新 Helm Chart 构建目标与依赖。
- Developer docs: 项目 skill 资产迁移到 `.agents/skills` 目录结构，并新增虚拟用户缓存排障文档。

**新增功能**

- Helm Chart 新增可选 Grafana 支持，用于节点管理自监控场景。
- 内置 Tempo 与 OpenTelemetry Collector Gateway Helm 能力切换为官方上游 Chart。

**功能优化**

- 优化 Plugin 与 Plugin 二进制工具包管理页面，包括简化 Plugin 页面交互与调整包列表展示。
- 优化 Plugin 页面无权限处理。
- Deploy Policy 目标渲染时应用子配置模板。
- Agent 与 Proxy 授权展示改为使用行级业务上下文。
- 新增 Helm Chart 构建目标，并对齐发布打包使用的内置 Helm Chart 依赖。

**缺陷修复**

- 修复 CMDB 管控区域场景下的云区域删除处理。
- 同步存活进程前检查 Agent 状态，避免同步无效进程状态。
- 修复 NetworkUnit 创建时的区域权限校验。
- 忽略空 Package Event 模糊条件，避免生成无效查询过滤条件。
- 增加 IAM v4 授权请求 body 日志，便于排查授权请求问题。

**Agent / Plugin / Package compatibility**

- 本版本不改变 Agent / Proxy、Plugin 或 Package 包格式。

**组件依赖与升级前置条件**

- Grafana、Tempo、Prometheus 与 OpenTelemetry Collector Gateway 为 Helm 可选能力，默认不启用。
- 本版本不引入强制升级前置条件。
