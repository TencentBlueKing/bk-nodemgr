## [Version: v3.0.1-alpha.31] - 2026-05-26

Full Changelog: [v3.0.1-alpha.30...v3.0.1-alpha.31](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.30...v3.0.1-alpha.31)

**发布范围**

- Agent: 新增按主机 ID 快速搜索，便于故障定位。
- Proxy: 支持在安装策略中按 Proxy 标签筛选主机，优化策略配置与执行路径。
- Plugin: 优化插件安装中继节点选择逻辑，并增强 v2 插件兼容安装路径。
- Package: 本版本不涉及 Agent / Plugin / Package 包格式变更。
- Backend/Control Plane: 优化调度触发同步与并发控制，移除 process v2 存储表与相关流程依赖。
- API / Gateway: 新增主机分布查询相关接口字段与文档对齐，接口定义与 swagger 同步更新。
- Installer/Deployment: Helm chart、appVersion 与镜像 tag 对齐到 v3.0.1-alpha.31。

**新增功能**

- 支持按主机 ID 快速搜索。
- 支持按 Proxy 标签进行主机查询与安装策略筛选。

**功能优化**

- 优化 Proxy 安装策略展示信息与操作侧边栏交互。
- 优化插件安装中继节点选择逻辑，提升安装链路稳定性。
- 优化调度工作流触发同步与并发处理路径。

**缺陷修复**

- 调整 v2 插件安装兼容模式触发逻辑，降低历史兼容场景下的安装失败风险。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- process v2 存储能力已移除，相关流程切换到现有插件安装与配置处理链路。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
- 使用 Helm 部署时，bk-nodemgr 与 mock-server 的 chart 版本、appVersion 与镜像 tag 需对齐到 v3.0.1-alpha.31。
