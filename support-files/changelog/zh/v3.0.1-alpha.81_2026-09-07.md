## [Version: v3.0.1-alpha.81] - 2026-09-07

Full Changelog: [v3.0.1-alpha.80...v3.0.1-alpha.81](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.80...v3.0.1-alpha.81)

> 重要提示

- IAM v4 默认关闭，升级不会自动切换现有 IAM v3 鉴权。启用前需完成 IAM v4 权限模型与授权配置，并验证鉴权、授权范围和权限申请流程。

**发布范围**

- Plugin: 调整进程启动超时，修复老插件接管时的停止流程。
- Backend/Control Plane: 新增可选的 IAM v4 运行时鉴权能力。
- Installer/Deployment: 新增 IAM v4 system 迁移工具；Helm、镜像版本与 API Gateway release metadata 对齐到 v3.0.1-alpha.81。

**新增功能**

- 新增 IAM v4 运行时适配，支持单次与批量鉴权、授权资源范围查询、权限申请链接和独立资源回调，沿用现有 Action/Resource 权限模型。
- 新增 IAM v4 system 模板渲染与迁移工具，支持预检查及 system 注册/更新。

**功能优化**

- Plugin v2/v3 工作流的进程启动步骤超时由 1 分钟延长至 5 分钟，为启动较慢的插件预留更多等待时间。

**缺陷修复**

- 修复老插件在节点管理中缺少进程记录时跳过停止的问题，接管时按 GSE 实际运行状态停止插件。

**Agent / Plugin / Package compatibility**

- 本版本不涉及 Agent / Proxy、Plugin 与 Package 包格式变更。
- 接管老插件时，优先使用运行版本的插件包生成停止参数；无法获取时回退到用户指定版本。请确保对应插件包可用，并核对回退版本的停止命令与配置路径是否适用于运行中的插件。

**组件依赖与升级前置条件**

- 仅启用 IAM v4 时需要 IAM v4 网关及已注册的权限模型和授权。配置 Backend `iamV4` 的网关连接、`systemID` 与 `callbackPath`，并确保 IAM 可访问 `/api/v3/iam/v4/resource` 回调。
- `iamV3.enable` 与 `iamV4.enable` 不能同时为 `true`；启用 IAM v4 时必须关闭 IAM v3。不切换的环境保持 `iamV4.enable=false`。
- IAM v4 迁移工具仅支持 `upsert_system`，不处理资源类型、操作、角色或授权迁移。执行前先运行 `--dry-run`；执行中断不会回滚已完成操作，重跑前需检查远端状态。切换前仍需另行完成权限配置与迁移验证，不能仅通过开启配置完成迁移。
