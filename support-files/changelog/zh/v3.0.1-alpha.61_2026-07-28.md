## [Version: v3.0.1-alpha.61] - 2026-07-28

Full Changelog: [v3.0.1-alpha.60...v3.0.1-alpha.61](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.60...v3.0.1-alpha.61)

**发布范围**

- Agent: Agent、Plugin、Package 包格式保持兼容。
- Backend/Control Plane: Host exact-IP 查询条件、Proxy unit assignment、host ScanAll index performance 和 Agent version diagnostic log 安全性得到优化。
- API Gateway: Backend topo host exact-condition 请求 schema 同步到 API Gateway release `2.18.2`，并刷新 APIGW resource descriptions。
- API Documentation: 补充缺失的 APIGW API 文档。
- Developer Experience: mise toolchain configuration 和 ScanAll index 文档得到更新。
- Installer/Deployment: 部署资产需使用 v3.0.1-alpha.61。

**新增功能**

- 新增 topo host exact inner IP / IPv6 查询条件，调用方可按精确内网 IP 值筛选主机。
- Unit assignment 支持 proxy tag，Proxy 分配流程会携带对应 tag 信息。

**功能优化**

- APIGW API 文档补充 NodeAgent、NodeProxy、Sync、Topo 资源缺失的 API reference 页面。
- APIGW resource descriptions 同步为最新资源文档描述。
- 新增 host ScanAll 查询索引，提升 host list 查询性能。
- mise toolchain configuration 和 ScanAll index 使用说明更新为当前开发环境配置。

**缺陷修复**

- Agent version diagnostic logs 增加安全处理，避免暴露不安全的原始诊断内容。
- Proxy unit assignment 在分配 Proxy 单元时传递必要参数。
- Config policy preview debug logs 从 Control Plane 流程中移除。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- Exact host IP 查询能力仅变更 Backend/API Gateway request schema，不改变包格式契约。

**组件依赖与升级前置条件**

- 升级部署资产时需使用 v3.0.1-alpha.61。
- Backend API Gateway resources 同步为 `2.18.2 / v3.0.1-alpha.61`。
