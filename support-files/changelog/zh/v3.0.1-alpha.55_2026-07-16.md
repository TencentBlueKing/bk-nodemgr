## [Version: v3.0.1-alpha.55] - 2026-07-16

Full Changelog: [v3.0.1-alpha.54...v3.0.1-alpha.55](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.54...v3.0.1-alpha.55)

**发布范围**

- Agent: Agent、Plugin、Package 包格式保持兼容；Windows Agent 部署新增 SSH 安装方式。
- Backend/Control Plane: Application service 新增 Host / Process distinct 缓存，主机同步增强 Proxy 服务 IP 修复与 Agent ID 去重。
- Frontend: Agent、Proxy 与 Plugin 页面适配 Host / Process distinct 请求字段。
- Installer/Deployment: Helm chart、服务镜像、API Gateway sync 镜像、mock-server 镜像对齐到 v3.0.1-alpha.55。

**新增功能**

- Windows Agent 部署支持选择 SSH 安装方式，原有 WMI 安装路径保持可用。
- Agent / Proxy 配置策略新增 BT 监听 IP 或网卡配置项，默认禁用并保持原有运行行为。

**功能优化**

- Application service 为 Host / Process distinct 查询新增按租户内存缓存，减少重复 Backend / MongoDB 查询。
- Proxy 主机服务 IPv4 / IPv6 缺失时，主机同步根据内网 IP 自动补全并写回同步结果。

**缺陷修复**

- Agent 信息与状态同步前对 Agent ID 去重，避免重复 ID 导致批量同步失败。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- Application Host distinct 请求改为使用 `role_type`，Process distinct 请求新增可选 `plugin_name`；仓库内 Frontend 调用已同步适配，外部 Application API 调用方需同步检查请求字段。

**组件依赖与升级前置条件**

- 升级部署资产时，Helm chart、服务镜像、API Gateway sync 镜像、mock-server 镜像需使用 v3.0.1-alpha.55。
- 本版本不涉及 Backend API Gateway resources 同步，API Gateway release metadata 保持 `2.17.1 / v3.0.1-alpha.52`。
