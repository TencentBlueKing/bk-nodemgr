## [Version: v3.0.1-alpha.23] - 2026-05-11

Full Changelog: [v3.0.1-alpha.22...v3.0.1-alpha.23](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.22...v3.0.1-alpha.23)

**发布范围**

- Agent: 新增安装 compatibility mode 参数，优化安装预览与策略展示体验，修复网络区域名称显示异常。
- Proxy: 新增通过 Excel 模板导入安装能力，并优化安装、重装页面关闭确认逻辑。
- Plugin: 新增 compatibility mode 安装能力，支持插件进程停止、重启与前端重装入口。
- Package: 支持按多平台查询发布包插件配置变量。
- Backend/Control Plane: 补强安装接口参数一致性、插件进程同步、公告周期请求、作业触发和主机登录用户回退等后台链路。
- Installer/Deployment: 无独立安装器发布形态调整，兼容性增强通过现有安装与发布链路生效。

**新增功能**

- NodeAgent、NodeProxy 和 Plugin 安装 API 新增 compatibility mode 参数，支持兼容安装场景统一传递安装配置。
- Plugin 安装链路新增 plugin config overwrite action，支持 compatibility mode 下覆盖插件配置。
- Proxy 新增通过 Excel 模板导入安装能力，便于批量导入节点后直接进入安装流程。
- Plugin 新增进程停止与重启 API，支持对指定主机上的插件进程发起运维控制。
- Plugin 前端新增重装入口，选中已有插件进程后可带入主机与版本信息进入重装流程。
- Package 新增发布包插件配置变量的多平台查询能力，便于按目标平台获取差异化配置。

**功能优化**

- Plugin 后台优化进程同步流程，减少进程状态同步链路中的异常情况。
- Plugin 安装配置页面优化配置渲染稳定性，降低配置变量表单渲染失败概率。
- Plugin 前端优化安装、重装、升级、停止与重启的操作流程，支持按已选主机平台回填版本和配置。
- Plugin 前端优化批量卸载、停止与重启确认弹窗，展示待操作进程并减少误操作风险。
- Agent 策略页面优化排序和预览交互，提升策略展示可读性。
- Agent 节点展示新增受损节点颜色区分，提升异常状态识别效率。
- Host Mongo 表新增索引，改善相关查询性能。

**缺陷修复**

- 安装链路修复 install-check 与 install API 的 IP 列表参数不一致问题，避免安装预览与实际安装请求出现偏差。
- Proxy 安装、重装页面修复关闭确认逻辑，减少误操作后状态丢失。
- 全局业务选择器修复刷新后已选业务不显示的问题。
- 插件进程列表修复 Agent/Proxy 查看权限过滤不一致的问题，避免无权限节点进入插件操作范围。
- 公告模块修复公告请求未按周期触发的问题。
- 作业触发链路修复 order trigger handler 逻辑异常。
- 主机信息链路修复登录用户回退异常。
- Source tracing 修复 instance id 未按配置读取的问题。
- 网络区域列表修复名称过长时显示溢出的问题。

**Agent / Plugin / Package compatibility**

- compatibility mode 相关增强覆盖 NodeAgent、NodeProxy 和 Plugin 安装链路，升级后调用端需要按新增参数对接对应 API。
- 发布包插件配置变量现支持按多平台返回结果，多平台发布场景需按目标平台重新确认配置下发结果。

**组件依赖与升级前置条件**

- Proxy 通过 Excel 模板导入安装依赖现有模板导入链路和安装接口，升级后需同步使用新版本前端与 Backend 接口。
- Plugin 进程停止、重启及 compatibility mode 参数依赖对应 API 和协议定义同时升级，避免前后端或调用端版本不匹配。
