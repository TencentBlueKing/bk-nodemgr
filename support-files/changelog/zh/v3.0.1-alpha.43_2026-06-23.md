## [Version: v3.0.1-alpha.43] - 2026-06-23

Full Changelog: [v3.0.1-alpha.42...v3.0.1-alpha.43](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.42...v3.0.1-alpha.43)

**发布范围**

- Agent: 优化 Proxy 自身 Relay 预检查，并统一 SSH 安装流程动作。
- Backend/Control Plane: 新增 Plugin policy 配置能力，保护 NetworkUnit 删除，并优化主机拓扑同步。
- Frontend: 优化跨页选择、表格排序和节点操作预览流程。
- File Service: 新增临时文件垃圾回收能力。
- Installer/Deployment: Helm chart 和镜像版本对齐到本次发布版本，并修复 Helm chart job 异常。

**新增功能**

- 新增 Plugin policy 配置能力。
- File Service 新增临时文件垃圾回收能力。
- Proxy 操作前新增自身 Relay 预检查。
- 新增 NetworkUnit 删除保护。

**功能优化**

- 优化前端表格跨页全选行为和排序体验。
- 统一 Proxy SSH 安装流程动作，使部署流程更一致。

**缺陷修复**

- 修复 Helm chart job 异常。
- 修复主机拓扑同步时 set 和 module 关系未保留 `set_id`、`module_id` 的问题。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本不改变 Agent / Plugin 运行时最低版本要求。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
- 本版本未更新 backend gateway resources，API Gateway resource metadata 保持不变。
