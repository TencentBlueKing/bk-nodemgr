## [Version: v3.0.1-alpha.60] - 2026-07-28

Full Changelog: [v3.0.1-alpha.59...v3.0.1-alpha.60](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.59...v3.0.1-alpha.60)

**发布范围**

- Agent: Agent、Plugin、Package 包格式保持兼容。
- Backend/Control Plane: Windows SSH P-Agent 检测、Mongo fuzzy 查询转义、CMDB host pagination sort 稳定性得到优化。
- Frontend: 节点历史日志、Proxy 安装页面初始化请求编排和插件进程页管控区域展示得到优化。
- Installer/Deployment: 部署资产需使用 v3.0.1-alpha.60。
- CI/Developer Experience: fork PR checkout 安全策略和 testsuite support skill 得到更新。

**新增功能**

- 新增 relay Windows SSH P-Agent detect-info 流程，支持在 Windows SSH 安装 P-Agent 前进行检测信息采集。

**功能优化**

- 前端节点历史日志、安装 Proxy 和重装 Proxy 页面优化初始化任务编排，减少串行请求等待。
- 插件进程页补充管控区域名称展示，避免相关筛选或侧滑内容缺少管控区域信息。
- testsuite support skill 补充 package-level integration tests 的 Mongo、Redis 和 Docker-backed source 使用指引。

**缺陷修复**

- Mongo fuzzy 查询值会进行 regex literal 转义，避免用户输入中的正则元字符改变查询语义。
- CMDB host pagination sort 查询参数稳定化，提升分页排序场景的兼容性。
- fork PR 的 GitHub Actions checkout 流程加强安全约束，降低不受信任代码在 CI 中被直接执行的风险。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- Windows SSH P-Agent 检测能力作为安装流程扩展，不改变既有 Agent、Plugin、Package 包格式契约。

**组件依赖与升级前置条件**

- 升级部署资产时需使用 v3.0.1-alpha.60。
- 本版本不涉及 Backend API Gateway resources 同步，API Gateway release metadata 保持 `2.18.1 / v3.0.1-alpha.56`。
- CI workflow 安全策略更新后，fork PR 相关流水线会按新的 checkout guard 执行。
