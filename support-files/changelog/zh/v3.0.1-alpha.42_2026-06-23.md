## [Version: v3.0.1-alpha.42] - 2026-06-23

Full Changelog: [v3.0.1-alpha.41...v3.0.1-alpha.42](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.41...v3.0.1-alpha.42)

**发布范围**

- Agent: 补充 Linux 默认部署常量和节点部署配置使用的区域字段。
- Backend/Control Plane: 优化 Proxy 安装策略标签、Proxy 状态可视化，以及 Package / Plugin 操作反馈。
- Frontend: 优化 IP 选择、业务选择快捷键、业务全选能力、Package / Plugin 执行结果展示。
- Installer/Deployment: Helm chart 和镜像版本对齐到本次发布版本。

**新增功能**

- 节点部署场景补充 Linux 默认部署常量和区域元数据支持。

**功能优化**

- 优化 IP Selector，并支持在业务筛选后通过 Enter 快捷键选择业务。
- 业务选择补充全选能力，并恢复 Agent / Proxy 重启确认弹窗。
- Proxy 状态页补充数据统计，便于查看 Proxy 状态分布。
- Package / Plugin 操作过程中更清晰地展示插件包场景和下发错误。

**缺陷修复**

- 修正 Proxy 安装策略标签，便于识别安装策略选项。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本不改变 Agent / Plugin 运行时最低版本要求。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
- 本版本不涉及 backend gateway resources 变更，API Gateway resource metadata 保持不变。
