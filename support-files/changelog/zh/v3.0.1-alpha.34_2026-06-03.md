## [Version: v3.0.1-alpha.34] - 2026-06-03

Full Changelog: [v3.0.1-alpha.33...v3.0.1-alpha.34](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.33...v3.0.1-alpha.34)

**发布范围**

- Agent: 本版本不涉及 Agent 运行时行为变更。
- Plugin: 优化从 Agent / Proxy 状态页进入插件进程操作页时的插件名称展示与操作入口行为。
- Package: 本版本不涉及 Agent / Plugin / Package 包格式变更。
- Backend/Control Plane: 新增定时同步主机拓扑关系操作，优化离线安装配置输出格式。
- API / Gateway: 本版本不涉及对外 API 契约、Swagger 或 API Gateway 资源定义变更。
- Frontend: 优化拓扑图布局、区域包围盒、连线避让与拖拽性能。
- Installer/Deployment: 修复 Helm chart 中 apigw-sync 镜像仓库与 tag 渲染错误，并对齐 Helm chart、appVersion 与镜像 tag 到 v3.0.1-alpha.34。

**新增功能**

- 新增定时同步主机拓扑关系操作，通过既有工作流按业务同步 CMDB 主机拓扑关系数据。

**功能优化**

- 插件进程操作页在从 Agent / Proxy 状态页进入时展示插件名称，并保持对应入口下的安装操作语义。
- 离线安装配置输出改为格式化 JSON，提升配置内容可读性。
- 拓扑图优化区域高度/宽度计算、连线路径避让与拖拽交互性能，降低复杂拓扑下的遮挡和卡顿。

**缺陷修复**

- 修复 Helm chart apigw-sync job 镜像渲染错误，支持独立 repository，并在 imageTag 为空时回退使用根镜像 tag。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本不引入新的 Agent / Plugin 包升级前置条件。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
- 主机拓扑关系同步依赖既有 CMDB 集成与后台工作流调度能力。
