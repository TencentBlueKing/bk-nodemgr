## [Version: v3.0.1-alpha.72] - 2026-08-20

Full Changelog: [v3.0.1-alpha.71...v3.0.1-alpha.72](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.71...v3.0.1-alpha.72)

**发布范围**

- Agent: 补充 NodeAgent Windows 自动安装说明；Installer 与 Relay 执行链路保持既有 Agent 包格式兼容。
- Plugin: Plugin control 支持 debug command 元数据；Plugin 子配置升级渲染与主配置选择逻辑得到修正。
- Package: 新增面向 Plugin V3 包的 Package 导入 workflow，并补充 package deployment storage 支撑。
- Backend/Control Plane: 新增 continuous profiling、多租户 bk_token 经 API Gateway 路由、Package workflow API、process config 查询链字段与 target URL request 能力。
- Installer/Deployment: 对齐 Helm、API Gateway release metadata 与镜像版本到 v3.0.1-alpha.72。

**新增功能**

- Package 导入 workflow 支持通过 Backend package workflow API 拉取、发布、隐藏和启用导入的 Plugin V3 包。
- Backend、File、Relay 与 Application 服务支持开启 continuous profiling。
- REST client 支持按调用方指定 target URL 发起请求，适用于需要绕过默认服务端点的场景。
- Plugin control 数据补充 debug command 元数据，支撑 Plugin 操作调试场景。

**功能优化**

- 多租户 bk_token 请求经 API Gateway 路由，并补充 gateway header 处理。
- Process config 记录持久化 template name 与查询链字段，提升配置读取精度。
- Plugin 安装参数渲染只传递主配置名称，减少配置选择歧义。
- 补充 BKRepo 资源使用与第三方权限文档，便于部署前准备。

**缺陷修复**

- Plugin 升级时重新渲染子配置，确保升级后的 Plugin 实例获得预期 subconfig 内容。
- UserManager client 正确解析 bk-user data-only 响应。
- 横向滚动固定列时，筛选面板位置保持对齐。

**Agent / Plugin / Package compatibility**

- Agent / Proxy 包版本随系统版本对齐到 v3.0.1-alpha.72。
- Plugin 与 Package 包格式保持兼容。
- 新增 Package 导入 workflow 扩展 Package 操作能力，不改变既有包发布兼容性。

**组件依赖与升级前置条件**

- API Gateway release version / comment 对齐为 `3.0.1-alpha.72`。
- Helm chart version、appVersion、server image tag、apigw-sync image tag、mock-server image tag 对齐到 `v3.0.1-alpha.72`。
- 本版本更新 Go module 依赖，不要求新增运行时组件。
