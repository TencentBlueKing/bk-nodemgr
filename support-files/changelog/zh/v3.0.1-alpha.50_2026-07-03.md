## [Version: v3.0.1-alpha.50] - 2026-07-03

Full Changelog: [v3.0.1-alpha.49...v3.0.1-alpha.50](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.49...v3.0.1-alpha.50)

**发布范围**

- Agent: 新增 Windows SSH 节点安装 workflow 支持，Agent、Plugin、Package 包格式保持兼容。
- Backend/Control Plane: 调整 CMDB 主机业务关系回填逻辑，并补齐 Windows SSH 安装 action 与 operation 编排。
- Frontend: 修复安装、插件、策略和 Proxy 相关页面交互问题。
- Documentation/Tooling: 新增版本管理概念文档和 bk-nodemgr Go code style skill。
- Installer/Deployment: Helm chart、服务镜像、API Gateway sync 镜像、mock-server 镜像对齐到本次发布版本。

**新增功能**

- Windows SSH 节点安装流程支持通过 Windows-compatible SSH client 完成 profile 探测、installer 传输、安装脚本生成和远程启动，并接入现有安装等待与同步链路。
- 新增版本管理概念文档，说明版本格式、递增规则、tag 规则和适用范围。
- 新增 bk-nodemgr Go code style skill，沉淀项目内 Go 代码风格与分层约束。

**功能优化**

- 前端安装表格、配置模板、操作弹窗、插件页、策略页和 Proxy 安装页交互修复后，页面展示与操作反馈更稳定。

**缺陷修复**

- 修复 CMDB 主机业务关系回填逻辑，按主机聚合拓扑关系并校验同一主机的业务归属一致性。
- 修复前端多处安装、插件、策略和 Proxy 相关页面问题。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本不改变 Agent / Plugin 运行时最低版本要求。
- Windows SSH 安装能力通过新增 workflow 生效，既有安装链路保持兼容。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
- 本版本未更新 backend swagger 文件，不涉及 API Gateway resources 同步；API Gateway release metadata 保持不变。
