## [Version: v3.0.1-alpha.36] - 2026-06-05

Full Changelog: [v3.0.1-alpha.35...v3.0.1-alpha.36](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.35...v3.0.1-alpha.36)

> 重要提示
- REST 服务监听协议现在按配置显式使用 IPv4 或 IPv6。双栈部署如需同时暴露 IPv4/IPv6，请同时配置 `IP` 与 `IPV6`，不要依赖单个监听地址的隐式 dual-stack 行为。

**发布范围**

- Agent: 本版本不涉及 Agent 运行时行为变更。
- Plugin: 本版本不涉及 Plugin 配置或运行时行为变更。
- Package: 本版本不涉及 Agent / Plugin / Package 包格式变更。
- Backend/Control Plane: 修复共享 REST server 在 IPv4/IPv6 双栈环境下的监听行为，避免服务隐式绑定到非预期网络协议。
- API / Gateway: 本版本不涉及对外 API 契约、Swagger 或 API Gateway 资源定义变更。
- Frontend: 本版本不涉及前端页面变更。
- Installer/Deployment: 本版本不涉及部署参数变更。

**缺陷修复**

- 修复 Backend/Control Plane HTTP 服务启动时使用 Go 默认 `tcp` 监听可能触发隐式 dual-stack 绑定的问题，IPv4 与 IPv6 现在分别通过 `tcp4` 和 `tcp6` 监听。
- 修复双栈配置下 HTTP 与 HTTPS 监听行为不一致或端口被隐式占用的风险，降低服务启动失败和非预期暴露地址的可能性。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- REST 服务监听行为更严格：需要双栈访问的部署应显式配置 IPv4 和 IPv6 监听地址；仅配置单一地址时只按该协议族监听。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
- 升级前请确认 Backend/Control Plane 相关服务的 `IP` / `IPV6` 配置符合期望的暴露协议族，并在双栈环境完成启动检查。
