## [Version: v3.0.1-alpha.65] - 2026-08-04

Full Changelog: [v3.0.1-alpha.64...v3.0.1-alpha.65](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.64...v3.0.1-alpha.65)

**发布范围**

- Agent: Agent、Plugin、Package 包格式保持兼容。
- Plugin: Config policy 增加 logger path support，便于通过配置策略管理 Agent 和 Proxy 日志路径。
- Package: Agent、Plugin、Package 包格式保持兼容。
- Backend/Control Plane: Try reuse agent id host result guard、CMDB integration testsuite support 和 Windows SSH install documentation 得到更新。
- Frontend: Control area list page 在创建或删除后的 table refresh 行为得到修复。
- API Gateway: 本版本不涉及 Backend API Gateway resources 同步，release version 更新为 `3.0.1-alpha.65`。
- Developer Experience: GitHub Actions checkout 升级到 v5，并新增 CMDB integration testsuite support。
- Installer/Deployment: 部署资产需使用 v3.0.1-alpha.65。

**新增功能**

- Config policy 支持 Agent 和 Proxy logger path option，扩展日志路径配置能力。
- Windows SSH install method 文档得到补充，帮助运维人员按 SSH 方式安装 Windows node。

**功能优化**

- GitHub Actions checkout action 升级到 v5，保持 CI workflow 依赖版本一致。
- CMDB integration testsuite support 在 `pkg/thirdparty/cmdb` 和 `testsuite/support` 下得到补充，便于后续集成测试复用。
- Installer downloader 和 system info 日志级别下调，减少安装过程中的运维日志噪声。

**缺陷修复**

- Control area list page 在创建或删除 control area 后会刷新 table，避免页面继续展示旧数据。
- Relay Windows SSH client error reporting 得到修复，Windows SSH 安装失败时返回更明确的错误信息。
- Backend try reuse agent id host result 增加 guard，避免异常 host result 影响复用流程。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本更新 config policy、Backend、Relay、Frontend、Installer、documentation 和 Developer Experience，不改变包格式契约。

**组件依赖与升级前置条件**

- 升级部署资产时需使用 v3.0.1-alpha.65。
- 本版本不涉及 Backend API Gateway resources 同步，API Gateway release version 更新为 `3.0.1-alpha.65`。
- 本版本不为 Agent、Plugin、Package rollout 引入新的组件前置条件。
