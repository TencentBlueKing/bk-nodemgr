## [Version: v3.0.1-alpha.93] - 2026-09-29

Full Changelog: [v3.0.1-alpha.92...v3.0.1-alpha.93](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.92...v3.0.1-alpha.93)

**发布范围**

- Backend/Control Plane: 增强跨 Backend 文件复制能力，同步 CMDB 网络区域变更，并修复 Relay SSH 连接释放问题。
- Frontend: 调整前端权限检查与插件操作权限控制。
- Installer/Deployment: 优化节点管理镜像构建、安装依赖与不支持平台的安装包处理，移除 legacy mock-server 和旧测试脚手架。

**新增功能**

- 支持跨 Backend FileGroup 复制文件，便于在文件服务间复用制品内容。

**功能优化**

- 优化节点管理镜像打包与前端构建上下文，减少镜像构建过程中的无关输入。
- TencentOS 4 部署改用官方 MongoDB Shell tarball 安装方式。
- 不支持 UPX 的安装器平台会跳过 UPX 压缩，避免打包流程被平台能力阻断。

**缺陷修复**

- 修复网络区域变更后未同步到 CMDB 的问题。
- 修复 Relay 通过 SSH 探测或安装时未及时关闭 SSH client 的问题。
- 修复插件操作权限校验漏洞，并调整前端权限检查逻辑。
- 升级 `amqp091-go`、`go-archive`、`grpc-go`、`opentelemetry-go` 和 `quic-go` 以修复安全漏洞。

**Agent / Plugin / Package compatibility**

- 本版本不修改 Agent、Plugin 或 Package 包格式。

**组件依赖与升级前置条件**

- 安装部署链路已移除 legacy mock-server 和旧测试脚手架；依赖这些本地调试入口的环境需要改用当前仓库保留的测试与调试方式。
