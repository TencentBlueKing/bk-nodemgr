## [Version: v3.0.1-alpha.112] - 2026-11-16

Full Changelog: [v3.0.1-alpha.111...v3.0.1-alpha.112](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.111...v3.0.1-alpha.112)

**发布范围**

- Backend/Control Plane：V3 插件仅安装不启动、旧版 V2 插件进程批量停止，以及插件子配置下发修复。
- File 服务：无绑定关系的过期包文件按需清理 API。
- Frontend：权限申请弹窗申请链接为空时的回退处理。
- Deployment：新增产品用户 Wiki 链接配置，SSH 连接失败日志附带排查指引链接。

**新增功能**

- 新增 V3 插件仅安装不启动 API：批量下发并安装插件包、完成配置渲染，但不启动插件进程；若目标主机上插件进程正在运行，会先停止该进程，任务结束后进程保持停止状态。接口返回 `workflow_id`，执行结果需查看工作流记录。
- 新增旧版 V2 插件进程批量停止 API：按主机与插件名批量停止 V2 插件进程。接口返回 `workflow_id`，执行结果需查看工作流记录。
- File 服务新增按需清理 API：可分别清理当前租户的过期上传文件、安装包文件和导出文件，回收无绑定关系的存储空间。
- SSH 连接失败的探测日志附带本地化排查指引链接；新增 `backend.wiki` 配置项指定产品用户 Wiki 来源，当前支持 GitHub 模式，默认指向官方仓库。

**缺陷修复**

- 修复插件自定义配置渲染上下文变更后子配置未重新下发的问题：现在上下文内容变化也会触发对应主机子配置的重新渲染与下发，不再只补齐缺失的子配置。
- 修复权限申请弹窗在 `apply_url` 为空时无跳转入口的问题，改为回退到 IAM 首页。

**Agent / Plugin / Package compatibility**

- 本版本不变更 Agent、Plugin 或 Package 格式。
- 新增 2 个插件操作 API 与 3 个 File 服务清理 API；既有 API 路径及请求／响应结构未调整。

**组件依赖与升级前置条件**

- 使用 API Gateway 的环境需同步本版本资源后再调用新增插件 API。新增插件 API 均为异步执行，接口成功不代表插件已安装或进程已停止，需通过工作流记录确认结果。
- `backend.wiki` 配置有默认值，存量部署无需额外配置即可升级；如需指向私有文档仓库，可在 Helm values 中调整。
