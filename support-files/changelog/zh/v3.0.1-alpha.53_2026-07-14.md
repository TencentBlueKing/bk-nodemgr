## [Version: v3.0.1-alpha.53] - 2026-07-14

Full Changelog: [v3.0.1-alpha.52...v3.0.1-alpha.53](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.52...v3.0.1-alpha.53)

**发布范围**

- Agent: Agent、Plugin、Package 包格式保持兼容；默认版本提示仅在 running 状态展示，减少非运行进程误提示。
- Backend/Control Plane: 优化主机拓扑过滤、主机同步写入与主机列表去重查询性能。
- Frontend: 插件进程侧滑页的非默认版本提示更聚焦当前运行进程。
- Installer/Deployment: Helm chart、服务镜像、API Gateway sync 镜像、mock-server 镜像对齐到 v3.0.1-alpha.53；服务镜像改为 Docker 多阶段构建前端静态资源。

**新增功能**

- 服务镜像构建流程支持在 Docker multi-stage build 中生成前端静态资源，减少本地打包流程对预构建 `dist` 的依赖。

**功能优化**

- 主机 distinct 查询合并为单次 MongoDB aggregate，减少多字段筛选时的查询次数。
- 主机同步写入调整为非有序批量写入，并降低同步批量大小，提升同步链路稳定性。
- MongoDB 写入确认调整为 `w:1`，降低同步类操作的复制确认等待成本。
- 插件进程非默认版本提示仅在 running 状态展示，避免停止或异常状态下的误导提示。

**缺陷修复**

- 修复空主机拓扑过滤条件仍参与查询的问题，避免生成无效筛选条件。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本不变更 Agent / Plugin / Package 协议或包格式。

**组件依赖与升级前置条件**

- 升级部署资产时，Helm chart、服务镜像、API Gateway sync 镜像、mock-server 镜像需使用 v3.0.1-alpha.53。
- 本版本不涉及 API Gateway resources 同步，API Gateway release metadata 保持 `2.17.1 / v3.0.1-alpha.52`。
