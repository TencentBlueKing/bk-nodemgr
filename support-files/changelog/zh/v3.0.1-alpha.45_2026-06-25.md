## [Version: v3.0.1-alpha.45] - 2026-06-25

Full Changelog: [v3.0.1-alpha.44...v3.0.1-alpha.45](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.44...v3.0.1-alpha.45)

**发布范围**

- Agent: 优化 Proxy 安装预置插件的管控区域分配与任务状态刷新体验。
- Plugin: 优化插件重启入口与操作流程。
- Backend/Control Plane: 调整 Proxy 预置插件安装时的管控区域分配参数传递。
- Frontend: 优化 IP selector 业务/集群/模块请求、分配单元表格默认视图、批量重试后的状态刷新和 request ID 生成兼容性。
- Installer/Deployment: Helm chart、服务镜像、mock-server 镜像对齐到本次发布版本。

**功能优化**

- IP selector 调整业务、集群、模块数据请求方式，提升相关选择场景的数据加载一致性。
- 插件重启操作流程优化，插件列表与进程侧栏补齐重启相关交互。
- 管控区域分配表默认视图与安装表保持一致，减少安装与分配流程间的视图差异。
- 批量重试后任务状态自动刷新体验优化，降低任务详情页状态更新延迟。

**缺陷修复**

- 修复 Proxy 安装预置插件时管控区域分配参数缺失的问题。
- 修复前端 request ID UUID 生成在部分协议或浏览器环境中的兼容性问题。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本不改变 Agent / Plugin 运行时最低版本要求。
- 本版本变更集中在安装任务参数传递、前端交互与请求兼容性，不要求存量节点额外升级动作。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
- 本版本未更新 backend swagger 文件，不涉及 API Gateway resources 同步；API Gateway release metadata 保持不变。
