## [Version: v3.0.1-alpha.38] - 2026-06-10

Full Changelog: [v3.0.1-alpha.37...v3.0.1-alpha.38](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.37...v3.0.1-alpha.38)

**发布范围**

- Agent: 补充节点控制模式和网络单元相关文档，安装与运维流程保持兼容。
- Plugin: 新增 Plugin compatibility policy，用于约束插件安装、升级与配置下发时的兼容策略。
- Package: Agent / Plugin / Package 包格式保持兼容。
- Backend/Control Plane: 新增业务主机数量、业务实例拓扑与拓扑主机筛选能力；拆分 Proxy upgrade 与 reconfig workflow。
- API / Gateway: 同步 node_agent、node_proxy、plugin、topo 相关 Swagger、API Gateway resources 与 API 文档。
- Frontend: 优化 IP Selector、拓扑图与控制单元分配相关交互。
- Installer/Deployment: 修复 Relay workspace 目录与文件系统处理逻辑。

**新增功能**

- 新增业务主机数量 API，支持按业务维度获取主机统计。
- 新增业务实例拓扑 API，补齐业务拓扑查询能力。
- 拓扑主机查询支持按集群、模块过滤，便于运维定位目标节点。
- 新增 Plugin compatibility policy，支持按策略控制插件兼容模式。

**功能优化**

- 拆分 Proxy upgrade 与 reconfig workflow，升级和重配置操作使用独立流程执行。
- 优化 IP Selector 跨页全选、拓扑层级展示和控制单元分配页面交互。
- 补充节点控制模式、主机与网络单元文档，降低部署和接入理解成本。

**缺陷修复**

- 修复 Relay workspace 目录处理问题，避免 workspace 路径异常影响文件处理。
- 修复 Relay 文件系统 helper 相关问题，提升目录读写稳定性。
- 优化任务详情中的业务过滤影响展示和用户名转换默认值处理。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- Plugin compatibility policy 按本版本规则执行，插件安装、升级与配置下发会使用更新后的兼容判断。
- Proxy upgrade 与 reconfig 拆分后，升级和重配置动作需按对应 workflow 执行。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
- API Gateway resources 与 apidocs 已随本版本接口变更同步。
- 升级前请确认 Relay workspace 目录具备正确读写权限。
