## [Version: v3.0.1-alpha.98] - 2026-10-16

Full Changelog: [v3.0.1-alpha.97...v3.0.1-alpha.98](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.97...v3.0.1-alpha.98)

**发布范围**

- Backend/Control Plane：新增共享插件包导入能力，支持通过 KMS 解密配置中的凭据，并修复预排序插件安装失败结果的返回问题。
- Frontend：优化 Agent 列表的搜索值校验提示及公告条出现时的用户信息面板位置。
- Operations/Deployment：Helm chart 新增基于 External Secrets Operator（ESO）的 KMS 凭据集成配置。

**新增功能**

- 插件包导入接口 `/api/v3/package/workflow/import/v3/plugin`、`/api/v3/package/workflow/import/v2/plugin`、`/api/v3/package/workflow/import/v2/external_plugin` 新增可选请求参数 `is_shared`，用于将导入的包发布为共享包；仅 `system` 租户请求生效，其他租户忽略该参数。
- 服务启动时支持通过 KMS 解密凭据信封，并覆盖相关凭据配置项。
- Helm chart 新增 `kms` 配置，启用后通过 ESO 为全局及 application、backend、file 模块拉取 KMS 凭据，私钥以环境变量注入，凭据信封以文件挂载。

**功能优化**

- Agent 列表搜索时，对未匹配任何搜索条件项的输入给出提示并移除该输入项；对不符合 IP 格式的 `ip`、`area_ip` 搜索值给出提示。
- 公告条显示时，用户信息面板随导航整体下移。

**缺陷修复**

- 修复预排序插件安装动作失败结果未正确返回的问题。

**Agent / Plugin / Package compatibility**

- 本版本不修改 Agent、Plugin 或 Package 包格式。
- 导入接口新增的 `is_shared` 为可选参数，未传入时保持原有行为。

**组件依赖与升级前置条件**

- `kms.enabled` 默认为 `false`；启用 KMS 凭据集成需要集群已部署 External Secrets Operator，并按实际 KMS 注册结果配置 `kms.server` 及各模块的 `path`、`role`、`credential`。
