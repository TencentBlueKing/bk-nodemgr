## [Version: v3.0.1-alpha.63] - 2026-07-30

Full Changelog: [v3.0.1-alpha.62...v3.0.1-alpha.63](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.62...v3.0.1-alpha.63)

**发布范围**

- Agent: Agent、Plugin、Package 包格式保持兼容。
- Backend/Control Plane: IAM system token cache、config policy update、host query indexes 和 GSE zone id 映射得到优化。
- Frontend: Plugin install parameter configuration 支持复制和粘贴。
- API Gateway: 本版本不涉及 Backend API Gateway resources 同步，release metadata 保持 `2.18.2 / v3.0.1-alpha.61`。
- Developer Experience: Go toolchain、architecture judgment skill、domain glossary 和 control-flow guidance 得到更新。
- Installer/Deployment: 部署资产需使用 v3.0.1-alpha.63。

**新增功能**

- Plugin install parameter configuration 支持复制和粘贴，配置多个插件安装参数时可复用已填写内容。
- Installer plugin debug 支持跳过 callback，便于调试场景减少外部回调依赖。
- 新增 architecture judgment skill 和 domain glossary，帮助后续架构评审、术语对齐和设计沟通。

**功能优化**

- Go toolchain 升级到 1.25.12，并同步更新 lint、build、setup 和 compile 相关配置。
- IAM system token 增加内存缓存，减少重复 token 获取带来的第三方 IAM 调用开销。
- Host query indexes 与当前查询条件对齐，提升 host list 查询性能。
- GSE zone id 命名与 CMDB idc area 语义对齐，减少跨系统字段理解差异。
- Control-flow guidance 补充 non-arrow flow 规则，降低后续 Go 代码维护复杂度。

**缺陷修复**

- Config policy update 修复字段更新漂移问题，避免未变更字段在更新流程中产生额外差异。
- GSE zone id 与 CMDB idc area 映射保持一致，修正节点部署和插件配置流程中的区域字段传递。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本涉及 Backend、Frontend、Installer 和 Developer Experience 更新，不改变包格式契约。

**组件依赖与升级前置条件**

- 升级部署资产时需使用 v3.0.1-alpha.63。
- 本版本不涉及 Backend API Gateway resources 同步，API Gateway release metadata 保持 `2.18.2 / v3.0.1-alpha.61`。
- 本版本不为 Agent、Plugin、Package rollout 引入新的组件前置条件。
