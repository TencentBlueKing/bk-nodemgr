## [Version: v3.0.1-alpha.35] - 2026-06-04

Full Changelog: [v3.0.1-alpha.34...v3.0.1-alpha.35](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.34...v3.0.1-alpha.35)

> 重要提示
- 本版本收敛 Relay 插件可配置项；升级前请确认是否依赖已移除的 Tracing、CallbackServer、DownloadServer 以及服务地址/认证自定义字段。升级后这些自定义项不再作为 Relay 配置渲染入口生效。

**发布范围**

- Agent: 本版本不涉及 Agent 运行时行为变更。
- Plugin: 调整 Relay 插件配置定义与配置模板，减少可配置项并固定部分服务监听、认证与 tracing 行为。
- Package: 本版本不涉及 Agent / Plugin / Package 包格式变更。
- Backend/Control Plane: 新增 Proxy 文件缓存目录部署配置，并按网络单元为文件拓扑渲染 Proxy group tag。
- API / Gateway: 本版本不涉及对外 API 契约、Swagger 或 API Gateway 资源定义变更。
- Frontend: 本版本不涉及前端页面变更。
- Installer/Deployment: Helm values 新增 `proxyFileCacheDir` 配置入口，用于 Linux Proxy 节点文件缓存目录默认值。

**新增功能**

- Proxy 节点支持通过部署配置指定文件缓存目录，并在未命中自定义配置策略时作为 `file.cache.dirs` 默认值渲染。
- 文件拓扑新增按网络单元渲染的 Proxy group tag，用于将文件传输范围限制在同一网络单元内。

**功能优化**

- Relay 插件配置项收敛为发布所需的最小集合，CallbackServer 和 DownloadServer 改为使用节点动态端口与 Advertise IP，InfoServer 和 AdminServer 保持本地监听。
- Relay 配置模板对端口和日志数量类字段进行整数渲染，减少配置类型歧义。
- 插件包构建指南同步 Relay 配置定义，保持文档示例与实际插件定义一致。

**缺陷修复**

- 修复节点部署配置渲染并发写入同一配置对象的风险，改为顺序渲染逻辑配置与自定义配置。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- Relay 插件升级后不再支持通过插件自定义配置覆盖 Tracing、CallbackServer、DownloadServer 以及已收敛的服务地址/认证字段。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
- 如需启用 Proxy 文件缓存目录默认值，请在部署配置或 Helm values 中设置 `proxyFileCacheDir`，并按环境完成灰度验证。
