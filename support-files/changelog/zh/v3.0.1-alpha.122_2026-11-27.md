## [Version: v3.0.1-alpha.122] - 2026-11-27

Full Changelog: [v3.0.1-alpha.121...v3.0.1-alpha.122](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.121...v3.0.1-alpha.122)

> 重要提示

- Backend 和 Relay 的 WMI 执行改为复用本地服务；使用 WMI 时须确保配置范围内有可用的回环监听端口，默认 `28160–28169`，无需对外开放。

**发布范围**

- Backend/Control Plane：WMI 命令执行与文件传输。
- Application/Frontend：平台管理中的定时任务、系统配置只读页面及配套查询接口。
- Installer/Deployment：WMI 本地端口和链路追踪配置。

**新增功能**

- 定时任务页面支持查询当前租户的周期工作流、筛选和分页查看调度配置，并查看执行记录、实例状态及步骤日志；页面及新增 Application 接口仅提供只读查询，不提供启停、编辑或重试操作。
- 系统配置页面展示命中的 Backend 实例启动时加载的业务配置白名单，包括租户模式、部署环境、IAM 开关、默认事件 Data ID、默认直连管控单元自动创建设置及 GSE 安装默认值；不返回凭据、连接端点或内部观测参数，不支持在线修改，也不代表所有副本配置一致或目标主机的实际状态。

**功能优化**

- WMI 命令执行与文件传输按进程复用内嵌服务，避免每次调用重复初始化 Python；不同目标可并发执行，同一目标的请求串行处理，并增加链路追踪和请求指标。

**Agent / Plugin / Package compatibility**

- 本版本不变更 Agent、Plugin 或 Package 格式。

**组件依赖与升级前置条件**

- 使用新版只读页面时，配套更新 Application 和 Frontend，并使用提供相应查询接口的 Backend。访问沿用现有登录认证和 `system_access` 校验；定时任务查询需 `platform_resource/scheduler_workflow` 的 `platform_manage` 权限，系统配置查询需 `platform_resource/system_config` 的 `platform_manage` 权限。
- WMI 调用端支持 Linux amd64 和 arm64，须允许执行本地临时文件；目标 Windows 主机仍须提供 WMI/DCOM 和 SMB 访问。
- Backend 和 Relay 可通过 `wmi.portRange` 配置本地端口范围；Helm 中 Backend 对应 `backend.config.wmi.portRange`。端口须在 1–65535，结束端口不得小于起始端口；范围内全部端口不可用时，WMI 内嵌服务无法启动。
- WMI `traceSampleRate` 默认 `0`；使用 Helmfile 且 Gateway 启用时，未显式配置的 Backend WMI 采样率设为 `1`，显式配置保持优先。
- WMI 请求的超时或取消会关闭该请求的连接，不等同于远程命令未执行。执行失败不会自动重试，重新发起前应核实远端结果；内嵌服务退出后，下一次调用重新启动服务，不会自动重放当次失败请求。
