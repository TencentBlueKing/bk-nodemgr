## [Version: v3.0.1-alpha.106] - 2026-11-06

Full Changelog: [v3.0.1-alpha.105...v3.0.1-alpha.106](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.105...v3.0.1-alpha.106)

> 重要提示

- File 服务 basic server 的默认 `authIdentity` 由 `none` 调整为 `rest-server`。使用默认 values 或自定义 values 未覆盖该项的部署，升级后 basic server 将启用 rest-server 身份认证；需保持旧行为的环境请在自定义 values 中显式设置 `authIdentity: none`。

**发布范围**

- Backend/Control Plane：Unix sudo 安装支持、Windows 防火墙全流程配置、插件进程 V2 检索接口、插件 V2 进程与主配置独立持久化及存活进程定时同步、源插件与目标子配置组合工作流。
- Application/Frontend：sudo 安装入口、配置策略操作人筛选与已删除主机展示、浏览器本地缓存按用户隔离、权限弹窗与权限校验修复。
- Installer/Deployment：Windows 防火墙配置生效时机扩展、File 服务 basic server 默认认证身份调整。

**新增功能**

- Agent/Proxy 安装接口及安装页面新增可选参数 `is_sudo`：登录用户为非 root 且已配置免密 sudo 时置为 true，安装器命令通过 `sudo -n` 提权执行；默认 false，仅对类 Unix 系统生效。
- Windows 防火墙配置扩展至安装、升级、重配置、卸载等安装器完整命令流程（此前仅在安装前生效）；仅 Windows 安装器应用，端口由安装器按启用功能计算。
- 新增插件进程检索接口 `Process_ListV2ProcessesCompatible`（含 API Gateway 资源与中英文文档），支持插件 V2 进程列表兼容查询。
- 插件 V2 进程与主配置持久化至独立集合，插件流程记录进程变更，并新增存活插件进程信息的定时同步。
- 新增源插件与目标子配置的组合（compose）执行工作流。
- 配置策略列表支持操作人筛选，并展示已删除主机。
- 浏览器本地缓存（localStorage）按用户隔离，避免同一浏览器多用户间数据串扰。

**缺陷修复**

- 修复 Agent/Proxy 重启操作误触发权限校验错误的问题。
- 修复权限弹窗复现问题：多选业务变更时权限复检遗漏、403 页面权限明细残留导致申请弹窗内容不相关；拓扑管理模块补齐业务权限数据加载。
- 修复从 MongoDB 读取进程配置自定义 context 时的数据规范化问题。
- 修复网络单元删除事件在异步记录前未快照、可能记录不完整的问题。
- 修正 Proxy 安装提示的文案与展示。

**Agent / Plugin / Package compatibility**

- 本版本不变更 Agent、Plugin 或 Package 格式。
- `is_sudo` 为可选参数，默认 false，已有安装请求行为不变。

**组件依赖与升级前置条件**

- 使用 `is_sudo` 安装需目标主机已为登录用户配置免密 sudo（`sudo -n` 可正常执行）。
- 插件 V2 进程与主配置使用独立的 MongoDB 集合存储并随 Backend 升级启用，不涉及历史数据迁移。
