## [Version: v3.0.1-alpha.64] - 2026-08-03

Full Changelog: [v3.0.1-alpha.63...v3.0.1-alpha.64](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.63...v3.0.1-alpha.64)

**发布范围**

- Agent: Agent、Plugin、Package 包格式保持兼容。
- Plugin: Plugin configuration 和 CMDB zone id 处理得到优化。
- Package: 新增 package import proto definition，用于 Backend API contract。
- Backend/Control Plane: Tenant initialization、Windows SSH install、scheduled agent state sync、stopped operation handling 和 CMDB host zone id compatibility 得到更新。
- Frontend: 包含 log viewer filter 和相关页面缺陷修复。
- API Gateway: 本版本不涉及 Backend API Gateway resources 同步，release metadata 保持 `2.18.2 / v3.0.1-alpha.61`。
- Developer Experience: Docker SDK、Dependabot configuration、PR template 和 Agent Go toolchain documentation 得到更新。
- Installer/Deployment: 部署资产需使用 v3.0.1-alpha.64。

**新增功能**

- Tenant initialization 增加 adminclient support，为 Backend administration 的租户初始化流程做准备。
- 新增 package import proto definition，用于 package import API 能力建设。
- Windows node installation 支持 SSH 作为 install method。

**功能优化**

- Scheduled agent state sync 跳过未变化的状态更新，减少重复 workflow 和 storage 操作。
- Stopped operation polling 和 storage handling 得到更新，提升 stop operation 生命周期跟踪能力。
- Frontend log viewer 支持 log level filtering，并默认隐藏 DEBUG 日志。
- Docker SDK 和 Dependabot configuration 得到更新，并新增 PR template，保持 contributor workflow 一致。
- Agent Go toolchain documentation 与当前开发环境配置保持一致。

**缺陷修复**

- CMDB host zone id 处理支持 numeric values，保持节点部署和插件配置流程与 CMDB 数据兼容。
- Frontend page fixes 改善 node list、footer、layout、copy IP 和 custom deploy configuration 行为。
- Installer log reporter 降低 attempt log severity，减少运维日志噪声。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 本版本涉及 Backend、Frontend、Installer、Developer Experience 和 package import API definition 更新，不改变包格式契约。

**组件依赖与升级前置条件**

- 升级部署资产时需使用 v3.0.1-alpha.64。
- 本版本不涉及 Backend API Gateway resources 同步，API Gateway release metadata 保持 `2.18.2 / v3.0.1-alpha.61`。
- 本版本不为 Agent、Plugin、Package rollout 引入新的组件前置条件。
