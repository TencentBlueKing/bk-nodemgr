## [Version: v3.0.1-alpha.89] - 2026-09-18

Full Changelog: [v3.0.1-alpha.88...v3.0.1-alpha.89](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.88...v3.0.1-alpha.89)

**发布范围**

- Installer/Deployment: Helm 自监控、Grafana 数据源配置与 Chart 依赖解析。

**新增功能**

- Helm 新增可选 Prometheus 自监控配置，采集 application、backend 与 file 服务的 `/metrics` 指标。
- Grafana 自动配置已启用的 Prometheus 与 Tempo 数据源；启用 Prometheus 时将其设为默认数据源。

**功能优化**

- Helm 配置示例统一使用 IP 占位符。

**缺陷修复**

- Helm Chart 依赖改为使用仓库内置 Chart，依赖构建时无需从外部 Chart 仓库下载这些依赖。

**Agent / Plugin / Package compatibility**

- 本版本不改变 Agent / Proxy、Plugin 或 Package 包格式。

**组件依赖与升级前置条件**

- Prometheus 与 Grafana 默认关闭，按需启用；启用 Grafana 时须同时启用 Tempo 或 Prometheus。
- Prometheus 持久化默认关闭；需要保留监控数据时，须显式启用 `prometheus.server.persistentVolume.enabled` 并配置持久卷。
- 修改内嵌数据源地址或端口后，须重启 Grafana。
