## [Version: v3.0.1-alpha.32] - 2026-05-28

Full Changelog: [v3.0.1-alpha.31...v3.0.1-alpha.32](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.31...v3.0.1-alpha.32)

**发布范围**

- Agent: 本版本不涉及 Agent 行为变更。
- Plugin: 新增 stop plugin v2 操作能力，优化插件 v2 compatibility 安装流程，并补齐进程未存活场景下的默认版本回退逻辑。
- Package: 本版本不涉及 Agent / Plugin / Package 包格式变更。
- Backend/Control Plane: 新增 stop plugin v2 分支动作，补充 relay 回调代理过滤逻辑，并增强 installer 轮询与重启校验链路稳定性。
- API / Gateway: 本版本不涉及 API/Gateway 合同字段变更。
- Frontend: 任务历史新增 stop plugin v2 类型展示与文案。
- Installer/Deployment: Helm chart、appVersion 与镜像 tag 对齐到 v3.0.1-alpha.32。

**新增功能**

- 新增 stop plugin v2 操作，可为插件 v2 创建停止任务并进入统一工作流执行链路。
- 新增进程未存活场景的补偿动作，统一回退到默认版本并完成流程收敛。
- 任务历史支持 stop plugin v2 类型展示，便于识别与追踪该类任务。

**功能优化**

- 优化插件 v2 compatibility 安装流程，仅对开启 compatibility 模式的部署项进入对应安装链路。
- 优化 relay 回调代理筛选逻辑，过滤 dedicated relay 代理，避免误入后续流程。
- 优化 installer 轮询与重启验证链路，提升节点安装/升级/重装相关流程稳定性。

**缺陷修复**

- 修复兼容安装场景下流程收敛路径，降低重复执行后续动作导致的不稳定风险。
- 修复 fetch v2 process 动作在进程未运行场景下的版本回填路径，避免后续动作使用异常版本信息。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 插件 v2 compatibility 安装链路保持现有接口与参数语义，新增 stop plugin v2 作为增量操作类型。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
