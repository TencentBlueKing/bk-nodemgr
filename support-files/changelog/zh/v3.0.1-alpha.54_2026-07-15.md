## [Version: v3.0.1-alpha.54] - 2026-07-15

Full Changelog: [v3.0.1-alpha.53...v3.0.1-alpha.54](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.53...v3.0.1-alpha.54)

**发布范围**

- Agent: Agent、Plugin、Package 包格式保持兼容；新增通过 Windows SSH 安装 Proxy Agent 的链路。
- Backend/Control Plane: 新增 Windows SSH Proxy Agent 安装编排，优化 Trigger 分类查询索引和主机列表操作时间排序。
- Relay: 支持识别 Windows SSH 环境并执行 Proxy Agent 安装。
- Frontend: 管控单元基础部署路径变更时增加风险提示。
- Installer/Deployment: Helm chart、服务镜像、API Gateway sync 镜像、mock-server 镜像对齐到 v3.0.1-alpha.54。

**新增功能**

- 新增 Windows SSH 安装 Proxy Agent 的后台编排和 Relay 执行链路，支持通过 Windows SSH 环境完成 Proxy Agent 安装。
- 管控单元下已有 Agent 节点时，前端在修改基础部署路径前提示卸载、重装、升级等后续操作风险。

**功能优化**

- Trigger 分类查询新增 active/alive partial index，提升按分类筛选触发器的查询效率。
- 主机列表按业务操作时间排序时移除通用更新时间兜底排序，并精简相关索引，降低排序查询成本。

**缺陷修复**

- 修正 Proxy 管控单元默认 Relay callback/download 端口，确保默认端口与 Relay 服务配置一致。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- Windows SSH Proxy Agent 安装能力为新增链路，不改变既有 Agent / Proxy 包格式。

**组件依赖与升级前置条件**

- 升级部署资产时，Helm chart、服务镜像、API Gateway sync 镜像、mock-server 镜像需使用 v3.0.1-alpha.54。
- 本版本不涉及 API Gateway resources 同步，API Gateway release metadata 保持 `2.17.1 / v3.0.1-alpha.52`。
