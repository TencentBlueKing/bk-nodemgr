## [Version: v3.0.1-alpha.69] - 2026-08-14

Full Changelog: [v3.0.1-alpha.68...v3.0.1-alpha.69](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.68...v3.0.1-alpha.69)

**发布范围**
- Agent: 刷新 Agent / Proxy 批量分配管控区域与拓扑相关 API schema，数值型 `int64` 字段与 proto 合约保持一致。
- Plugin: 本版本不涉及 Plugin 包格式变更，既有 Plugin 发布兼容性保持不变。
- Package: 本版本不涉及 Package 发布语义或包格式变更。
- Backend/Control Plane: 同步生成的 proto 与 Swagger 资源，修正 OpenAPI schema 中拓扑、管控区域、主机等 ID 字段类型。
- Installer/Deployment: 对齐 Helm、API Gateway release metadata 与镜像版本到 v3.0.1-alpha.69，并更新 downloader `allowHosts` 示例值。

**功能优化**
- 刷新生成的 proto 与 Swagger 资源，保持 API 文档、客户端生成输入与后端合约一致。
- Helm values 中 downloader `allowHosts` 示例调整为 `127.0.0.1`，便于本地或最小化部署场景直接参考。

**缺陷修复**
- 修正生成的 OpenAPI schema 中多个 `int64` ID 字段被描述为 string 的问题，包括拓扑、管控区域、主机以及批量分配管控区域请求项。

**Agent / Plugin / Package compatibility**
- Agent / Proxy 包版本随系统版本对齐到 v3.0.1-alpha.69。
- Plugin 与 Package 包格式保持兼容。
- 依赖 OpenAPI schema 生成客户端的对接方，建议基于本版本 schema 重新生成客户端以获取正确的整数类型定义。

**组件依赖与升级前置条件**
- API Gateway release version / comment 对齐为 `3.0.1-alpha.69`。
- Helm chart version、appVersion、server image tag、apigw-sync image tag、mock-server image tag 对齐到 `v3.0.1-alpha.69`。
- 本版本不引入新增组件依赖。
