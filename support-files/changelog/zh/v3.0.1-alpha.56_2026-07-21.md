## [Version: v3.0.1-alpha.56] - 2026-07-21

Full Changelog: [v3.0.1-alpha.55...v3.0.1-alpha.56](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.55...v3.0.1-alpha.56)

**发布范围**

- Agent: Agent、Plugin、Package 包格式保持兼容；离线 Plugin 升级新增无需 callback 或 download URL 的升级路径。
- Backend/Control Plane: 主机同步支持从 CMDB 同步流程批量创建主机，Plugin 升级流程支持离线包，SyncData retry backoff 分散执行，ORM 慢查询日志记录 filter 信息。
- Frontend: 修复记录、部署目标、拓扑选择器相关页面交互问题。
- Documentation: 扩充 Package、PluginWorkflow、Process、NodeConstant、Cipher API 文档与 Plugin v2 到 v3 迁移说明。
- Installer/Deployment: Helm chart、服务镜像、API Gateway sync 镜像、mock-server 镜像对齐到 v3.0.1-alpha.56。

**新增功能**

- CMDB 同步流程支持一次创建多台主机。
- 离线 Plugin 升级支持无需 callback 或 download URL 的包，原有在线升级路径保持可用。

**功能优化**

- SyncData retry 使用错峰 backoff，降低集中重试带来的瞬时压力。
- ORM 慢查询日志记录查询 filter，提高 MongoDB 慢查询排查上下文完整性。
- Package、PluginWorkflow、Process、NodeConstant、Cipher 与 Plugin 迁移文档补充 API 调用和升级操作说明。

**缺陷修复**

- 修正 disabled preordered Plugin 条件判断。
- 修复 Frontend 记录、部署目标、拓扑选择器相关交互问题。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 离线 Plugin 升级为新增支持路径，不改变既有包格式契约。

**组件依赖与升级前置条件**

- 升级部署资产时，Helm chart、服务镜像、API Gateway sync 镜像、mock-server 镜像需使用 v3.0.1-alpha.56。
- 同步 Backend API Gateway resources，release metadata 更新为 `2.18.1 / v3.0.1-alpha.56`。
