## [Version: v3.0.1-alpha.30] - 2026-05-23

Full Changelog: [v3.0.1-alpha.29...v3.0.1-alpha.30](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.29...v3.0.1-alpha.30)

**发布范围**

- Agent: 本版本不涉及 Agent 包格式变更。
- Proxy: 补齐 Proxy 安装请求在 API Gateway 资源中的运行时文件保留控制字段。
- Plugin: 本版本不涉及 Plugin 包格式变更。
- Package: 本版本不涉及 Package 格式变更。
- Backend/Control Plane: 修正 try stop process 场景中的进程名称，避免停止流程匹配错误。
- API / Gateway: 补齐 NodeProxyInstallHost 的 renew_gse_task 与 renew_gse_proc 请求 schema 字段，并对齐网关发布版本备注。
- Installer/Deployment: Helm chart、appVersion 与镜像 tag 对齐到 v3.0.1-alpha.30。

**新增功能**

- 本版本不包含新增功能。

**功能优化**

- 补齐 Proxy 安装请求在 API Gateway 资源中的运行时文件保留字段，保持 swagger 与网关资源一致。

**缺陷修复**

- 修正 try stop process 使用的进程名称，降低进程停止动作匹配错误风险。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- renew_gse_task 与 renew_gse_proc 为已有请求 schema 字段的网关资源同步补齐，不改变调用语义。

**组件依赖与升级前置条件**

- 本版本不引入新增组件依赖。
- 使用 Helm 部署时，bk-nodemgr 与 mock-server 镜像 tag 需与 v3.0.1-alpha.30 对齐。
