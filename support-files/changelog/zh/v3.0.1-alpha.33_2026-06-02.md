## [Version: v3.0.1-alpha.33] - 2026-06-02

Full Changelog: [v3.0.1-alpha.32...v3.0.1-alpha.33](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.32...v3.0.1-alpha.33)

**发布范围**

- Agent: 本版本不涉及 Agent 行为变更。
- Plugin: 将 compatibility 模式过滤收敛到 ensurePluginV2 阶段，避免前置链路误过滤。
- Package: 本版本不涉及 Agent / Plugin / Package 包格式变更。
- Backend/Control Plane: 为 jinja2_bin、wmi_bin 增加 go build tag，按构建目标裁剪依赖与产物。
- API / Gateway: 本版本不涉及对外 API 契约变更。
- Frontend: 本版本不涉及前端行为变更。
- Installer/Deployment: Helm chart、appVersion 与镜像 tag 对齐到 v3.0.1-alpha.33。

**新增功能**

- 无。

**功能优化**

- 将 plugin v2 compatibility 模式过滤移动到 ensurePluginV2，使前置安装链路判断更集中、可维护。
- 为 jinja2_bin、wmi_bin 增加 go build tag，支持按平台/场景选择性编译相关能力。

**缺陷修复**

- 修复 compatibility 模式过滤时机过早导致部分插件 v2 安装路径被误跳过的问题。

**Agent / Plugin / Package compatibility**

- Agent、Plugin、Package 包格式保持兼容。
- 插件 v2 compatibility 安装语义不变，仅调整过滤执行位置。

**组件依赖与升级前置条件**

- 本版本不引入新增外部组件依赖。
