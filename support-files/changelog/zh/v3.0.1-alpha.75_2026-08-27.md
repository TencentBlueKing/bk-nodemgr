## [Version: v3.0.1-alpha.75] - 2026-08-27

Full Changelog: [v3.0.1-alpha.74...v3.0.1-alpha.75](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.74...v3.0.1-alpha.75)

**发布范围**

- Agent: Agent / Proxy 包格式保持兼容。
- Plugin: Package workflow API 描述更新，覆盖 Plugin / Package 导入导出操作。
- Package: Package workflow 文档补充异步导入导出结果与临时下载地址说明。
- Backend/Control Plane: tenant provider 改为基于 storage 数据，tenant sync diff 纳入 disabled tenants，并对齐 enabled tenant API 命名。
- Installer/Deployment: file service exporter HTTP 配置、tracing global fallback、biz-scoped node event data ID 配置、Helm 版本、API Gateway release metadata 与镜像版本对齐到 v3.0.1-alpha.75。

**新增功能**

- Backend 与 application 服务支持 storage-backed tenant provider。
- 节点部署渲染支持按业务配置 node event data ID。
- File service 支持 exporter HTTP server 配置。

**功能优化**

- application、backend、file 与 relay 服务支持 tracing global fallback 配置。
- Package workflow API 描述补充导入导出工作流行为与结果查询用法。
- tenant storage 与相关服务路径对齐 enabled tenant list 命名。

**缺陷修复**

- 修复 tenant sync diff 计算未纳入 disabled tenants 的问题。

**Agent / Plugin / Package compatibility**

- Agent / Proxy 包版本随系统版本对齐到 v3.0.1-alpha.75。
- Plugin 与 Package 包格式保持兼容。

**组件依赖与升级前置条件**

- API Gateway release version / comment 对齐为 `3.0.1-alpha.75`。
- API Gateway PackageWorkflow resource description 已同步 backend swagger summary 更新。
- Helm chart version、appVersion、server image tag、apigw-sync image tag、mock-server image tag 对齐到 `v3.0.1-alpha.75`。
