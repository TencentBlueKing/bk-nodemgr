## [Version: v3.0.1-alpha.99] - 2026-10-19

Full Changelog: [v3.0.1-alpha.98...v3.0.1-alpha.99](https://github.com/TencentBlueKing/bk-nodemgr/compare/v3.0.1-alpha.98...v3.0.1-alpha.99)

**发布范围**

- Backend/Control Plane：插件安装接口支持不传插件版本并安装默认版本；插件 Jinja2 系统配置中的多租户标识改为以字符串渲染。

**新增功能**

- 插件安装接口 `/api/v3/plugin/install` 的 `plugin` 列表项中，`version` 字段改为可选。未传入时，安装与目标主机 Agent generation、操作系统和 CPU 架构匹配的插件包默认版本。

**缺陷修复**

- 修复插件配置文件 Jinja2 系统配置中的多租户标识以布尔值渲染的问题，现统一以字符串 `"true"` 或 `"false"` 渲染。

**Agent / Plugin / Package compatibility**

- 本版本不修改 Agent、Plugin 或 Package 格式。
- 插件安装接口对已指定 `version` 的请求保持兼容，行为不变。
- 在 Jinja2 中引用多租户标识的插件配置模板，现获得字符串值（`"true"` 或 `"false"`），不再是布尔值。
