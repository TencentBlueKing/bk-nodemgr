# NetworkUnit Tenant Collection Migration

This runbook migrates documents from the shared MongoDB collection `networkunit` to tenant-scoped collections named `networkunit_<tenant_id>`.

The application keeps `networkunit_id` globally unique by continuing to use the existing `networkunit` counter key. Do not create tenant-specific counter keys.

## Preconditions

- Stop writes that create, update, or delete network units for the duration of the migration.
- Back up the `networkunit` and `counter` collections.
- Run the migration against the same MongoDB database used by bk-nodemgr.
- Review tenant IDs before execution because each tenant ID becomes part of a collection name.

## Pre-migration checks

Record the source totals and maximum ID per tenant:

```javascript
db.networkunit.aggregate([
  {
    $group: {
      _id: "$data.tenant_id",
      total: { $sum: 1 },
      alive: { $sum: { $cond: [{ $eq: ["$basic.is_deleted", false] }, 1, 0] } },
      max_networkunit_id: { $max: "$data.networkunit_id" },
    },
  },
  { $sort: { _id: 1 } },
]);
```

Confirm that every document has a non-empty tenant ID:

```javascript
db.networkunit.countDocuments({
  $or: [
    { "data.tenant_id": { $exists: false } },
    { "data.tenant_id": "" },
    { "data.tenant_id": null },
  ],
});
```

The result must be `0` before proceeding.

## Migration

Set the tenant list explicitly from the pre-migration report:

```javascript
const tenantIDs = ["TENANT_ID_1", "TENANT_ID_2"];
```

Copy each tenant's complete documents, including soft-deleted records and the `basic` envelope:

```javascript
tenantIDs.forEach((tenantID) => {
  const target = `networkunit_${tenantID}`;

  db.networkunit.aggregate([
    { $match: { "data.tenant_id": tenantID } },
    {
      $merge: {
        into: target,
        on: "_id",
        whenMatched: "replace",
        whenNotMatched: "insert",
      },
    },
  ]);
});
```

Create the indexes generated by `pkg/dao/mongo/base.Orm.EnsureIndexes` and `pkg/dao/mongo/networkunit.GetIndexes`:

```javascript
tenantIDs.forEach((tenantID) => {
  const collection = db.getCollection(`networkunit_${tenantID}`);

  collection.createIndex(
    { "data.networkunit_id": 1 },
    { partialFilterExpression: { "basic.is_deleted": false } },
  );
  collection.createIndex(
    { "data.networkunit_id": 1, "data.networkarea_id": 1 },
    { unique: true },
  );
  collection.createIndex({ "basic.is_deleted": -1 });
});
```

Do not change the existing counter document with `data.key: "networkunit"`. New records continue to allocate IDs from that global namespace.

## Verification

Compare source and target totals per tenant:

```javascript
tenantIDs.forEach((tenantID) => {
  const sourceFilter = { "data.tenant_id": tenantID };
  const target = db.getCollection(`networkunit_${tenantID}`);

  printjson({
    tenant_id: tenantID,
    source_total: db.networkunit.countDocuments(sourceFilter),
    target_total: target.countDocuments({}),
    source_alive: db.networkunit.countDocuments({
      ...sourceFilter,
      "basic.is_deleted": false,
    }),
    target_alive: target.countDocuments({ "basic.is_deleted": false }),
  });
});
```

Confirm that target collections contain only their named tenant:

```javascript
tenantIDs.forEach((tenantID) => {
  const target = db.getCollection(`networkunit_${tenantID}`);
  printjson({
    tenant_id: tenantID,
    mismatched_documents: target.countDocuments({
      "data.tenant_id": { $ne: tenantID },
    }),
  });
});
```

Every `mismatched_documents` result must be `0`, and source/target totals must match.

## Cutover and rollback

1. Deploy the application version that routes NetworkUnit operations to `networkunit_<tenant_id>`.
2. Re-enable NetworkUnit writes.
3. Keep the shared `networkunit` collection unchanged until the deployment is verified.

To roll back, stop NetworkUnit writes and deploy the previous application version. The previous version resumes using the unchanged shared collection. Reconcile any writes made after cutover before reopening traffic.
