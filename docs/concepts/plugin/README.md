## 概念对照表

| 维度               | 插件包（Package）                            | 插件（Plugin）                                 | 进程（Process）                                  |
| ------------------ | -------------------------------------------- | ---------------------------------------------- | ------------------------------------------------ |
| **是否有版本**     | 有（每个插件包都有明确的版本）               | 无（插件本身不携带版本）                       | 有（进程的生命周期随实例产生）                   |
| **租户范围**       | **全局**——所有租户共享插件包                 | **分租户**——插件本身是业务概念，天然是分租户的 | 进程作为插件的实例，受插件的租户约束             |
| **是否有生命周期** | 无（仅是静态资源）                           | **无**（业务对象不随运行而变化）               | **有**（创建 → 运行 → 停止/销毁）                |
| **是否唯一实例**   | 一个插件包对应唯一的资源集合（可有多个版本） | 同一租户下，插件是唯一的                       | **每台主机上**同一插件只能拥有 **一个** 进程实例 |
