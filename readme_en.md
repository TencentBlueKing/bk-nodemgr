## Features
* Cloud Area Management: Flexibly divide management units, with multi-level proxy bridging control across multiple cloud areas and multi-access-point management.
* Node Management: Provides control services for GSE Agent on managed nodes, including installation, upgrade, configuration reload, restart, and uninstallation.
* Strategy Management: Supports flexible configuration strategies, offering multi-condition custom GSE Agent configuration combinations and orchestration.
* Plugin Management: Supports basic plugin operations and deployment strategies, enabling plugin lifecycle control across large-scale nodes.
* Package Management: Supports version management and control of GSE Agent / Proxy / Plugin packages.
