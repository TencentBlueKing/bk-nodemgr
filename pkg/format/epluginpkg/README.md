# epluginpkg

## 设计意图
提供外部插件包的命名格式化和文件命名功能，用于生成标准化的外部插件包名称和工具文件名。

## 功能边界
1. 此包负责：外部插件包名称格式化、二进制文件名生成、配置文件模板命名
2. 此包不负责：插件包内容验证、插件运行逻辑、包文件创建

## 设计考量
采用与官方插件包相似的命名规范，通过 releaseType 区分不同类型的外部插件包，支持跨平台架构标识，确保命名一致性和可读性。

## 使用限制
- 仅支持 external_plugin 类型的插件包命名
- 需要有效的 releaseType 和 version 参数
- 平台信息仅在非原始外部插件包中包含

## 演进方向
- 支持更多插件包格式扩展
- 增加插件包元数据提取功能
