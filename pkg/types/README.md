# types

## 设计意图
提供系统核心类型定义的统一来源，确保跨包通信的数据结构一致性。通过集中管理类型定义，减少重复代码，降低类型转换成本，并保留数据的上下文信息，从而提高系统的可靠性和开发效率。

## 功能边界
1. 此包负责：
    - 定义系统通用的数据结构和接口
    - 提供类型安全的转换和验证工具
    - 实现类型的序列化和反序列化标准方法
2. 此包不负责：
    - 特定存储层或API层的数据转换实现
    - 业务逻辑处理和规则验证
    - 特定场景的性能优化逻辑

## 使用限制
1. 类型定义属于系统内部契约，不应直接暴露给外部系统
2. 应避免引入特定领域的业务逻辑，保持类型的中立性
3. 不应直接引入第三方依赖的数据结构，需进行适配转换
