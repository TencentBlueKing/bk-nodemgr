# client

## 设计意图
1. 提供统一的 HTTP 客户端接口，简化服务间通信和接口调用。
2. 提供默认的 HTTP Client 配置，降低使用门槛和配置复杂度。

## 功能边界
1. 此包负责：
    - 设置默认的 HTTP Client 非业务相关配置，包括超时、重试、连接池等。
    - 统一封装 TLS 证书校验逻辑，提高代码复用性。

2. 此包不负责：
    - HTTP 请求的 header、body 等具体实现细节。
    - 业务逻辑的处理与实现。

## 设计考量
1. HTTP 的超时、连接池等设置通常修改频率较低，定制化需求有限。
2. TLS 证书校验是通用需求，统一封装可避免重复实现，提高安全性和可维护性。

## 使用限制
1. 仅提供基础 HTTP 客户端功能，特定业务场景可能需要额外扩展。
2. 默认配置适用于大多数场景，但高性能场景可能需要定制化配置。

## 演进方向
1. 增强请求指标采集能力，支持性能监控和分析。
2. 支持更多协议和传输格式的客户端实现。
3. 提供更灵活的中间件机制，便于扩展功能。
