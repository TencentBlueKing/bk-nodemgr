# server

## 设计意图

1. 统一管理中间件的注册
2. 统一处理接受请求的日志记录
3. 统一处理返回响应的日志记录
4. 统一处理错误日志
5. 统一验证 Context 的相关信息

## 功能边界

1. 此包负责：
    - 中间件注册
    - 日志记录
    - 错误处理
2. 此包不负责：
    - 业务逻辑
    - 路由管理
    - 数据存储

## handler



### Handler
标准处理函数
会将请求的结果，自动按照预设格式进行包装，返回给客户端。

### StreamHandler
流式传输处理函数
### FileHandler
文件传输处理函数，返回值是一个文件
