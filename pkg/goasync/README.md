# goasync

## 设计意图
提供基于 goroutine 池的异步任务执行能力，解决高并发场景下的任务调度和性能优化问题。

## 功能边界
1. 此包负责：异步任务的池化管理、分布式追踪集成、上下文传播
2. 此包不负责：具体的业务逻辑实现、持久化任务存储

## 设计考量
采用 ants goroutine 池实现高效的并发控制，集成 OpenTelemetry 追踪确保任务执行的可观测性，使用 contextx 统一上下文管理。

## 使用限制
1. 任务函数必须是 `func(contextx.IContext) error` 类型
2. 处理器创建时必须提供有效的 OpenTelemetry Tracer
3. 池大小和每池大小必须为正整数

## 演进方向
1. 支持任务优先级调度
2. 增加任务执行状态查询能力
