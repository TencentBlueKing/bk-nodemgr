# pluginworkflow

## 设计意图
提供pluginworkflow的数据库操作原子接口

## 功能边界
1. 此包负责：
    - pluginworkflow的数据库操作
    - pluginworkflow的存储结构设计
2. 此包不负责：
    - 具体的业务关系和逻辑

## 设计考量
该包将数据库操作和表结构屏蔽在内，对外提供基于pkg/types类型的接口

## 使用限制
1. 数据库结构设计应考虑变更和迁移兼容性
2. 只提供原子接口，复杂的业务场景逻辑查询应放在上层处理
3. 支持多租户隔离，不同租户的数据存储在不同的表中（表名格式：plugin_workflow_{tenantID}）

## 演进方向
1. 按需丰富数据字段
2. 考虑进一步增加索引
3. 支持租户级别的数据迁移和管理
