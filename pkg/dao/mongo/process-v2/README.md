# processv2

## 设计意图

提供节点管理 V2 兼容模式插件进程（`plugin_v2`）的 DAO 层操作，主要用于对 MongoDB 的操作。
表 `process_v2_<tenant_id>` 与 V3 的 `process` 表结构一致，隔离存储后再由 V3 服务端读取，避免 V3 进程表被 V2 兼容进程覆盖。

## 功能边界

1. 此包负责：
    - V2 兼容插件进程的 DAO 层操作
    - V2 兼容插件进程的存储结构设计
2. 此包不负责：
    - 具体的业务关系和逻辑
    - 进程状态的同步策略（由定时任务调用本包的批量更新接口）

## 设计考量

该包将数据库操作和表结构屏蔽在内，对外提供基于 pkg/types 类型的接口。
唯一键为 `{host_id, name}`，与 V3 进程表保持一致；V2 兼容模式下进程名即插件名。

## 使用限制

1. 数据库结构设计应考虑变更和迁移兼容性
2. 仅提供原子接口，复杂的业务场景逻辑查询应放在上层处理

## 演进方向

1. 按需丰富数据字段
2. 按需补充过滤条件与聚合查询
