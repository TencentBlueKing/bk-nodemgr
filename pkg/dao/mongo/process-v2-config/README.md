# processconfig

## 设计意图

提供process v2 config的DAO层操作，主要用于对MongoDB的操作。该表仅用于记录使用nodeman的插件安装结构安装的插件进程的配置文件。

## 功能边界

1. 此包负责：
    - process v2 config的DAO层操作
    - process v2 config的存储结构设计
2. 此包不负责：
    - 具体的业务关系和逻辑

## 设计考量

该包将数据库操作和表结构屏蔽在内，对外提供基于pkg/types类型的接口。

## 使用限制

1. 数据库结构设计应考虑变更和迁移兼容性
2. 仅提供原子接口，复杂的业务场景逻辑查询应放在上层处理

## 演进方向

1. 按需丰富数据字段
2. 考虑进一步增加索引
