# counter

## 设计意图
本包提供一个全局递增sequence数字的安全维护方式

## 功能边界
1. 此包负责：
    - 提供针对不同key的全局sequence数字维护
    - 返回递增前的值
    - 支持一次性批量预留N个连续数字 (`GenerateN`)
2. 此包不负责：
    - 业务规则处理与业务流程控制

## 接口说明
- `Generate(key)`: 生成单个递增序号, 返回递增前的值
- `GenerateN(key, n)`: 一次性原子递增n, 返回递增前的值; 调用方可使用 `[返回值+1 .. 返回值+n]` 区间

## 设计考量
- 需要自增主键的dao可以在创建时先调用counter来获取一个合法的递增sequence
- 需要批量分配连续序号时(如批量设置优先级), 使用 `GenerateN` 只需一次DB调用, 避免循环N次 `Generate`

## 使用限制
1. 新的KEY的sequence数字为0
2. 在一些特殊场景中, 如果要保留0给内置资源, 需要调用方手动处理
3. `GenerateN` 的 n 必须大于0
