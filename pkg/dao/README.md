## Package 定位

`dao` 层主要负责提供针对单一数据表的基本 CRUD(创建、读取、更新、删除)操作,以及一些通用的查询操作,如分页查询、排序查询等。

`dao` 层还提供数据表结构与运行时数据之间的转换能力,屏蔽数据表结构的变化对上层逻辑的影响。

`dao` 层的行为是同步的,不支持异步调用方式。

`dao` 层不允许跨表查询、跨库查询和跨库事务操作。

`dao` 层的代码结构大致如下(以 `business` 表为例):

- `business.go`: 定义 `business` 表的具体操作行为,此处的结构体与数据库表结构一一对应。
- `table.go`: 定义 `business` 表的元数据信息,如表名、表结构、表主键等。
- `handler.go`: 定义运行时数据与表结构之间的转换方法,如将运行时数据转换为表结构,将表结构转换为运行时数据等。同时提供一些原子的操作方法,如新增、删除、更新、复杂场景下的查询操作、条件添加、监听等。
- `handler_test.go`: 定义一些单元测试用例(必要)。

## 通用命名约定

- Get: 查询
- List: 分页查询
- Count: 计数
- Upsert: 新增或更新
- Delete: 删除
- Exists: 是否存在
