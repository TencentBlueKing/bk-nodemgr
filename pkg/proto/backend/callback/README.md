# v3

## 设计意图
提供callback接口的protocol协议相关的全部内容。

## 功能边界
1. 此包负责：
    - 定义接口协议，包括请求体结构、返回体结构，一般从proto文件自动生成pb.go文件
    - 提供接口数据校验、组织校验失败信息
    - 提供数据转换，负责proto数据到内部数据的相互转换和初始化
2. 此包不负责：
    - 接口流程逻辑
    - 非nodemgr接口的protocol协议内容，如其他第三方的协议内容 

## 设计考量
将protocol数据的生命周期限制在这个包内，在逻辑层面不应该直接使用这个包中定义的类型，而是在使用前通过内置convert方法转换为types中的内容，再使用。
在接口返回前，也应该通过convert方法，将types中的内容转换为protocol数据。

## 使用限制
1. pb.go文件由proto文件自动生成，严格禁止任何手动修改
2. 其余的go文件为pb.go的补充，在生成的类型基础上完善各种方法，尽量避免新声明类型
3. 一些需要手动处理的默认零值，应当在AutoConvert()中做手动处理，将其设置为真正的默认值。如一些id=0是有意义的，当其为nil时应当手动指定为id=-1，避免因为proto的Get方法自动拿到零值。
