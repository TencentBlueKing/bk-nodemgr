# scheduler

## 设计意图

scheduler 包提供一个轻量级的任务调度器，用于定期执行后台任务，支持任务超时控制和并发执行防重。

## 功能边界

1. 此包负责：定时触发任务、管理任务生命周期、防止任务重复执行
2. 此包不负责：任务的具体业务逻辑实现、任务失败后的重试策略

## 设计考量

采用 singleflight 模式防止同一任务的重复执行，通过 context 实现超时控制。调度器使用简单的时间间隔检查模式，适合低频次且对精确调度时间要求不高的场景。

## 使用限制

1. 任务执行时间可能超过设定的超时时间，此时任务会被中断但不会自动重试
2. 调度精度取决于调度器的检查间隔，默认为 1 秒
3. 任务执行失败只会记录日志，不会自动重试，需要等待下一个调度周期

## 演进方向

1. 增加任务失败自动重试机制和更灵活的调度策略（如 cron 表达式支持）
2. 添加任务执行指标收集和监控能力，以便更好地观察任务执行情况
