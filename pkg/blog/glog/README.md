# glog

## 设计意图
从glog修改而来，提供基础的文件日志服务

## 功能边界
1. 此包负责：
    - 日志内容格式处理
    - 日志等级划分处理
    - 日志文件滚动
2. 此包不负责：
    - 业务逻辑
    - 业务日志中包含的信息处理

## 设计考量
内聚日志处理，提供通用的文件日志能力，和基于配置的日志行为控制。

## 使用限制
1. 应直接使用blog.LogConfig，不要直接使用glog
2. 应在所有打日志的地方之前完成初始化
3. 程序退出前应该CloseLogs，以将缓存中的内容刷到磁盘上

## 演进方向
1. 提供更精简的通用日志信息
