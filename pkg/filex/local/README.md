# local

## 设计意图

通过 `LocalDir` 和 `LocalFile` 将本地目录、文件适配为 `fileiface.FileGroup` 和 `fileiface.File`，供调用方统一读取、写入和复制文件。

## 功能边界

- 提供本地文件读取、目录查询与创建、文件写入、复制和删除能力。
- 本地文件组之间使用原生文件系统复制；复制到 BKRepo 时使用`transfer.CopyStream` 流式复制流程。
- 文件上传、发布和租户策略由上层服务负责。

## 构造与目录操作

| 入口 | 行为 |
| --- | --- |
| `NewLocalDir` | 打开已有目录，不创建目录 |
| `NewLocalFile` | 打开已有文件，计算包含 MD5 的元数据快照 |
| `IsDir` | 查询节点是否为目录；缺失时返回可匹配 `fs.ErrNotExist` 的错误 |
| `GetSubGroup` | 获取已有子目录；`.` 查询当前目录的实际状态 |
| `EnsureSubGroup` | 创建目标目录及缺失的父目录；`.` 确保当前目录存在 |

文件内容变化后，应重新获取 `LocalFile`，以获得最新元数据。

## 复制规则

1. 本地复制使用本地相对路径，在写入前确定实际目标，拒绝复制到同一文件（包括硬链接别名）及源、目标目录重叠。
2. 跨后端复制使用相对于文件组的 `/` 分隔路径。源必须指向组内节点；`.` 只能作为目标组根目录。
3. 目标目录合并、空目录保留及覆盖规则见 [跨后端复制说明](../transfer/README.md)。

## 文件流与写入

- 每次调用 `LocalFile.Content` 都打开一个新文件流，由调用方负责关闭。
- `LocalDir.Store` 仅借用输入流，只关闭自己打开的目标文件。
- `overwrite=false` 使用独占创建，目标文件已存在时失败；`overwrite=true` 会截断已有文件后写入。
- 写入失败可能留下部分内容，复制失败不会回滚之前已写入的文件或目录。

## 使用限制

1. `IsDir`、`GetSubGroup` 和 `EnsureSubGroup` 拒绝解析路径上的符号链接和特殊文件；`AllFiles` 保留跟随普通文件符号链接的行为，并在构造文件对象前拒绝特殊文件。
2. 路径检查假设目录树不会被不可信进程并发替换，不提供并发修改下的文件系统隔离保证。
3. `Store` 和 `GetFile` 不使用上述目录方法的路径校验，调用方应按对应方法的约定提供路径。
