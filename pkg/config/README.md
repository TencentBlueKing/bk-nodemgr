# config

## 设计意图
提供标准的服务配置类型，描述各个service的完整启动配置。启动服务前需要参照该包的内容，提供所需的配置信息。

## 功能边界
1. 此包负责：
    - 定义标准的、通用的配置类型
    - 描述服务的启动参数配置
    - 提供服务配置的检查
2. 此包不负责：
    - 使用配置的具体业务逻辑

## 设计考量
尽量内聚配置类型，抽象通用配置项并重复使用。例如同一个HTTP Server的yaml结构，定义一次，在多个服务中使用，使得不同位置的相同类型配置结构一样。

## 使用限制
1. 在外部使用该包提供的配置时，应尽量避免直接修改

## 演进方向
1. 进一步完善从envrionment读取配置的能力并规范化
