# wmix

`wmix` 是供 Linux 服务端连接 Windows 主机的共享远程执行组件，封装 WMI/DCOM 命令执行和 SMB 文件传输。

此包只提供传输与执行能力，不定义上层业务策略，也不判定远程任务的业务结果。

调用端支持 Linux amd64 和 arm64，目标端为 Windows。执行依赖目标主机开放相应的 WMI/DCOM 与 SMB 访问，以及调用端可执行临时文件。

每个 Go 进程按需启动并共享一个内嵌 HTTP Server，通过 `127.0.0.1` 通信，不再为每次调用重新初始化 Python。各请求独立传递凭据与超时；执行请求失败时不会自动重试。Server 退出后，下一次调用重新启动。

默认端口范围为 `28160–28169`，Backend 和 Relay 可通过 `wmi.portRange` 配置。端口仅用于本地进程通信，无需对外开放。服务关闭时应调用 `Close` 释放内嵌进程。
